# nanobanana-deji — Gemini図解スライド生成スキル

認証キー不要。`GEMINI_API_KEY` 環境変数のみで動作する図解スライド生成スキル。

## セットアップ確認（初回のみ）

```bash
# APIキーの確認
echo $GEMINI_API_KEY

# ライブラリの確認
cd "C:/Users/Tatsu/.claude/skills/nanobanana-deji"
python -c "from google import genai; print('OK')"
```

APIキーがない場合: 「❌ GEMINI_API_KEY が設定されていません」と表示して停止。

## ワークフロー

### Phase 1: スライド構成を計画する

ユーザーのテーマ・内容を受け取り、以下のフォーマットでスライド構成を設計する。

**スライド構成テンプレート:**
```
Slide 1: タイトル + 全体概要（イントロ）
Slide 2: キーポイント①
Slide 3: キーポイント②
Slide 4: キーポイント③
Slide 5: まとめ + 結論
```

枚数はユーザー指定があればそれに従う。指定なしは5枚。

### Phase 2: 各スライドのプロンプトを作成する

見本スライドのスタイルに合わせてプロンプトを設計する。詳しいパターンは `references/slide-style.md` を参照。

**スライドタイプの選択（必ず `references/slide-style.md` を読んでから選ぶ）:**
| スライド内容 | 使うType |
|---|---|
| 最初のタイトル・イントロ | Type F |
| 概念を比喩で説明 | Type A |
| ステップ・手順 | Type B |
| 2つを比較・対比 | Type C |
| 誤解 vs 正しい理解 | Type C（赤/青）|
| プロセス・フロー | Type D |
| まとめ・結論（最後） | Type E |

**プロンプト構造（必ず守る）:**
```
[レイアウト指定] + [タイトルテキスト（日本語で具体的に）] + [各テキスト要素（日本語で具体的に）] + [イラスト・アイコン要素] + [デザイン指定]
```

**プロンプト品質のポイント:**
- テキストは「〇〇と表示」のように**日本語の文字列を直接書く**（「キャッチコピー」のような抽象表現は避ける）
- アイコンは「チェックマーク」「フォルダアイコン」など**具体的な形を指定**する
- 連続スライドでは**全枚に同じカラーパレット指定**を末尾に付ける（`references/slide-style.md` の色統一ルール参照）
- まとめスライド（最後）は**特に視覚インパクトを強調**する指示を加える
- **「または」「もしくは」は使わない** — 選択肢を与えると曖昧な出力になる。一意に決める
- **サイズは必ず数値・比率で指定** — 「大きく」ではなく「画像高さの50〜60%」のように書く

**各プロンプトの冒頭に必ず書く（コーポレートPPT風を防ぐ）:**
```
【スタイル指定】教育用インフォグラフィック／解説イラスト風。
コーポレートプレゼン風・箇条書きレイアウト・グラデーション背景・全幅カラー帯ヘッダー・3Dエフェクト・影は禁止。
```

**各プロンプトの末尾に必ず書く（パンチライン帯）:**
```
【パンチライン帯・必須ルール】
画像の最下部に画像幅いっぱいの黄色い帯（背景色: #FFD700）を配置すること。
帯の高さは画像全体の約12〜15%。
帯の中にパンチライン「[1文]」を配置。
フォントは画像中で最大・極太（extra bold）・文字色は黒（#000000）。
この帯より下には何も配置しないこと。
```

### Phase 3: 画像を生成する

各スライドを順番に生成する。出力先はユーザー指定がなければ `./slides/` ディレクトリ。

```bash
cd "C:/Users/Tatsu/.claude/skills/nanobanana-deji"
python scripts/generate.py \
  --prompt "[Phase 2で作成したプロンプト]" \
  --output "[出力パス]/slide_01.png" \
  --aspect landscape
```

生成後、すぐに次のスライドに進む（待機不要）。

### Phase 4: 完了レポート

全スライド生成後に報告:
```
✅ 完了: X枚のスライドを生成しました
📁 保存先: [出力ディレクトリ]
  - slide_01.png: [タイトル]
  - slide_02.png: [タイトル]
  ...
```

## エラー対処

- `GEMINI_API_KEY not set` → 環境変数を確認するよう伝える
- `model not found` → モデル名 `gemini-3.1-flash-image-preview` を確認
- 画像データなし → プロンプトを短縮・シンプル化して再試行
- `google-genai not installed` → `pip install google-genai` を実行
