# Instagramリール動画制作スキル (Instagram Reel Producer)

## 概要

このスキルは、1投稿に対して1企業の求人情報を発信するInstagramアカウント（@tenshoku_nocareer）のリール動画制作素材を自動生成します。企業名を入力するだけで、求人調査からキービジュアル取得、台本・キャプション・カバーキャッチコピーまでを一括で作成します。

## 入力

- **企業名**（必須）: 対象企業名（指定がない場合はStep 1で自動ピックアップ）

## 前提情報

- **発信者**: 45歳男性。キャリアコンサルタントで人事経験20年のプロフェッショナル。
- **ターゲット**: 転職活動をしている30代。
- **トーン**: 説得力のある落ち着いた雰囲気。
- **アカウント**: @tenshoku_nocareer

## ワークフロー

### Step 1: 企業検索（対象企業のピックアップ）

※企業名が指定されている場合はこのステップをスキップします。

1. `browser`ツールで転職求人サイト（doda、エン転職、マイナビ転職）にアクセスします。
2. 以下の条件で求人を検索します：
   - **勤務地**: 東京、神奈川、大阪
   - **雇用形態**: 正社員
   - **未経験歓迎**であること
3. 条件に合致する企業をピックアップし、対象企業を決定します。

---

### Step 2: ディープリサーチ（企業情報の収集）

`browser`ツールで対象企業の求人情報を中心に、以下の情報を詳細に調査します。

#### 調査項目

- **待遇面の詳細（数字で説得力を演出）**
  - 給与・ボーナス：具体的な金額、平均年収や賞与は◯ヶ月分など
  - 福利厚生：年間休日、有給取得日数、住宅関連（寮・社宅の家賃負担）、食堂、ポイント制度など

- **働きやすさの証明**
  - 離職率の低さ、健康経営優良法人認定、残業時間の少なさ

- **企業の強み・特徴の提示**
  - 「世界シェアナンバーワン製品」や「社員が高待遇すぎる穴場ホワイト企業」など
  - 事実に基づく企業の優位性を具体的に示す

- **企業の事業内容・実績**
  - 歴史（創業年、事業展開）、具体的な市場シェア、グローバル展開状況など

- **リアルな課題・デメリット（信頼性向上）**
  - 「よくある退職理由」を示す

### Step 3: キービジュアル画像の取得

対象企業の公式HPからキービジュアル画像を20枚取得します。

#### 3-1. 公式HPの特定

1. `browser`ツールで企業名を検索し、公式HPのURLを特定します。
2. 公式HPのトップページにアクセスし、サイト構造を把握します。

#### 3-2. サイト巡回と画像URL収集

1. **トップページ**の画像を収集します。
2. サイト内の主要ページを巡回して、さらに画像を収集します。巡回対象：
   - サービス・事業内容ページ
   - ニュース・お知らせページ
   - コラム・レポート・ライブラリページ
   - 採用情報ページ
   - 企業情報・会社概要ページ
   - IR情報ページ
   - その他コンテンツページ
3. 以下の**除外対象**をフィルタリングします：
   - ロゴ画像（ファイル名に `logo` を含むもの）
   - アイコン画像（ファイル名に `icon` を含むもの、またはサイズが極端に小さいもの）
   - ヘッダー・フッター背景画像（ファイル名に `bg_header`, `bg_footer` を含むもの）
   - 関連サイト・外部リンクのバナー（ファイル名に `relation` を含むもの）
   - SNSアイコン・シェアボタン画像
   - 1px×1px のトラッキングピクセル
   - SVGファイル（装飾用が多いため）

#### 3-3. キービジュアルの選定基準

1. **解像度が高い画像を優先**: 幅800px以上、または高さ400px以上の画像を優先
2. **コンテンツ性のある画像**: メインビジュアル、バナー、記事サムネイル、サービス紹介画像、イベント画像など
3. **多様性の確保**: 同じページからの画像ばかりにならないよう、複数ページからバランスよく収集
4. **重複排除**: 同一画像（URLベース）は1枚のみ

#### 3-4. 画像のダウンロード

1. 保存先ディレクトリを作成します：
   ```bash
   mkdir -p /home/ubuntu/instagram_reel/[企業名]/images/
   ```
2. 選定した20枚の画像をダウンロードし、わかりやすいファイル名で保存します。
   - ファイル名の命名規則: `[カテゴリ]_[連番].[拡張子]`
   - 例: `kv_01.jpg`, `topics_01.jpg`, `banner_01.png`, `service_01.jpg`
3. ダウンロードに失敗した場合は、予備の画像URLから補充して必ず20枚を確保します。

#### 3-5. ZIP圧縮

```bash
zip -j /home/ubuntu/instagram_reel/[企業名]/kv_images.zip /home/ubuntu/instagram_reel/[企業名]/images/*
```

### Step 4: 台本作成（45秒リール動画用）

Step 2のディープリサーチ情報を元に、以下の構成で45秒の台本（セリフのみ）を作成します。

#### シーン構成（45秒・6シーン）

| シーン | 秒数 | 内容 |
|--------|------|------|
| 1. フック | 0-3秒 | ネガティブ訴求のワンフレーズ |
| 2. フック補足 | 3-8秒 | フックの理由を具体数字で提示 |
| 3. 待遇①（給与・ボーナス） | 8-18秒 | 年収、賞与、具体的な金額 |
| 4. 待遇②（福利厚生・働きやすさ） | 18-28秒 | 休日数、残業、離職率、認定 |
| 5. 強み・未経験OKポイント | 28-38秒 | シェア、中途採用比率、研修 |
| 6. 企業名明かし | 38-45秒 | 「その会社は、○○。」 |

**各シーンの秒数は厳守すること。** 台本にはシーン番号と秒数を明記する。

#### シーン詳細

**シーン1: フック（0-3秒）**
- 冒頭でネガティブ訴求。ワンフレーズ厳守。
- 以下の6パターンをローテーションで使用する（複数企業を制作する場合は順番に回す）

   **パターンA：「入社禁止」パターン**
   - 例）「ここに絶対入社しないで。」

   **パターンB：「警告」パターン**
   - 例）「この会社、調べないでください。」

   **パターンC：「後悔」パターン**
   - 例）「この会社を知ってしまった人、ご愁傷様です。」

   **パターンD：「閲覧注意」パターン**
   - 例）「転職する気がない人、今すぐスワイプして。」

   **パターンE：「罪悪感」パターン**
   - 例）「この動画、同僚には絶対見せないで。」

   **パターンF：「禁止」パターン**
   - 例）「今の仕事が好きな人は、この先見ないでください。」

**シーン2: フック補足（3-8秒）**
- フックの理由を具体的な数字で。
- 例）「なぜなら、賞与が138万円。待遇が良すぎて、もう他の会社に転職する気が無くなります。」

**シーン3: 待遇①（8-18秒）**
- 給与・ボーナスの具体的な金額
- 平均年収、賞与○ヶ月分 or ○○万円

**シーン4: 待遇②（18-28秒）**
- 年間休日、有給取得日数、残業時間
- 住宅関連（寮・社宅の家賃負担）、食堂、ポイント制度
- 離職率の低さ、健康経営優良法人認定

**シーン5: 強み・未経験OKポイント（28-38秒）**
- 企業の優位性（「世界シェアNo.1」「穴場ホワイト企業」など）
- 30代未経験でも応募しやすい情報（中途採用比率、研修制度）

**シーン6: 企業名明かし（38-45秒）**
- 「その会社は、○○。」で社名を提示
- ここまでは絶対に社名を伏せること

#### テロップ文字数ルール（厳守）

- **1ページあたり最大48文字**（12文字×4行）
- 1シーン内で複数ページに分けてもよいが、1ページの上限は必ず守ること
- 台本の各セリフは、テロップ1ページ単位で改行して記載する
- 1行あたり12文字を超える場合は改行位置を明示する
- 数字・記号も1文字としてカウントする

**テロップページ数の目安:**

| シーン | 秒数 | テロップページ数 |
|--------|------|-----------------|
| 1. フック | 3秒 | 1ページ |
| 2. フック補足 | 5秒 | 1〜2ページ |
| 3. 待遇① | 10秒 | 2〜3ページ |
| 4. 待遇② | 10秒 | 2〜3ページ |
| 5. 強み | 10秒 | 2〜3ページ |
| 6. 企業名 | 7秒 | 1ページ |

#### ナレーション口調ルール（全シーン共通）

- **トーン**: 断定・煎り系。言い切る。迷わない。
- **語尾**: 「〜だ。」「〜する。」「〜やばい。」「〜すぎる。」（「〜です」「〜ます」は使わない）
- **テンポ**: 1文は短く。句読点で区切る。体言止めを多用する。
- **パワーワード必須**: 「人生イージーモード」「勝ち組」「驚愕の」「ガチで」「えぐい」「神待遇」などの感情を動かす言葉
- **わかりやすさ**: 小学校低学年でも分かる簡単な表現を使う
- **禁止事項**:
  - 丁寧語（です・ます調）
  - 回りくどい説明
  - 曖昧な表現（「〜かもしれない」「〜らしい」）
  - 1文が20文字を超える長いフレーズ

#### 台本作成の補足ルール

- シーン6までは社名は伏せること
- セリフだけの構成にすること（ト書き・演出指示は別セクションで）
- 30代未経験でも採用される情報があれば入れること
- 内容は事実のみを記載すること
- 待遇面はリサーチ情報から作成すること
- 具体的な数字にする（例：賞与額なら〇か月分ではなく〇〇万円のように具体的に）

#### 出力フォーマット

台本はテロップページ単位で記載する。各ページは `[P1]` `[P2]` …で区切り、12文字×4行（最大48文字）以内であることを明記する。

```
# [企業名] リール台本（45秒）

ガチでえぐい。
```

#### 出力

台本は以下の**2ファイル**を保存する：

1. **`台本.txt`** — シーン構成・ページ番号 `[P1]`・文字数付き（テロップ編集用）
2. **`台本_セリフのみ.txt`** — ナレーションのセリフだけを抽出したもの（読み上げ・収録用）。シーン番号、ページ番号、文字数カウント、見出しは一切含めない。セリフの間は空行で区切る。

```
/home/ubuntu/instagram_reel/[企業名]/台本.txt
/home/ubuntu/instagram_reel/[企業名]/台本_セリフのみ.txt
```

8. **固定の著作権表記**
9. **固定ハッシュタグ**

### Step 6: カバー画像のキャッチコピー作成

#### 役割

プロのSNSマーケター兼コピーライターとして、求職者の「不安」を取り除き、「欲望」を刺激する言葉選びを行います。

#### 制約条件

1. **構成**: 中央に配置する「2行」の構成にすること
2. **文字数**: 1行あたり全角6〜10文字程度（スマホで視認性を高めるため短く）
3. **トーン**: 驚き、羨望、意外性を強調する「週刊誌の見出し」のようなトーン
4. **禁止事項**: 平凡な表現（例：「良い会社です」「働きやすい」）は禁止

#### 使用テクニック（必須）

- **数字の強調**: 具体的な金額、日数、年数を入れる（例：200万、150日、1.8%）
- **パワーワード**: 「脅威の」「禁断の」「世界一」「まさかの」「神待遇」などを使用
- **ギャップ（意外性）**: 「○○なのに××」という構造（例：世界一なのに高卒OK、激務業界なのに残業ゼロ）

#### 参考事例（トーン＆マナー）

- 家賃補助200万!? ／ 100年黒字経営
- ボーナス年に4回 ／ 大量採用
- 世界一なのに ／ 150日も休み
- 禁断の顔採用 ／ 1日7時間勤務
- 倍率 超低い ／ 36年連続黒字

#### 出力形式

以下の形式で**5案**出力します：

```
【案1：数字インパクト重視】
1行目：
2行目：
（解説：なぜこの言葉を選んだか）

【案2：ギャップ・意外性重視】
1行目：
2行目：
（解説：なぜこの言葉を選んだか）

【案3】〜【案5】も同様
```

#### 出力

キャッチコピーをテキストファイルとして保存します：
```
/home/ubuntu/instagram_reel/[企業名]/カバーキャッチコピー.txt
```
