# 全成果物一覧

## 概要

nagame-dev が各フェーズで生成する成果物の完全カタログ。
コア成果物20件 + v2.0追加成果物6件 = 合計26件。

例え話：家を建てる時の書類一式と同じ。設計図、確認申請書、施工計画書、
検査証明書など、全ての書類が揃って初めて「完成」と言える。

## 3. 各成果物の詳細

### D-21: Finding Ledger（指摘事項台帳）

レビューで発見された全ての指摘事項を追跡する台帳。

**必須項目:**
- Finding ID（一意識別子）
- 発見日時
- 発見者（Codex / Opus / 社長）
- 優先度（Blocker / Must / Should / Later）
- 判定（ACCEPT / MODIFY / REJECT / HOLD / ESCALATE）
- 対応状況（Open / In Progress / Resolved / Won't Fix）
- 対応内容と完了日

**更新タイミング:** レビューの各ラウンド終了時

---

### D-22: Reproposal Log（再提案履歴）

社長が提案を却下し、修正して再提案した履歴。

**必須項目:**
- 元の提案内容
- 却下理由（社長のフィードバック）
- 修正内容
- 再提案結果（承認 / 再却下）

**目的:** 同じ理由で何度も却下されることを防ぐ。過去の却下理由をパターン化し、提案の精度を上げる。

---

### D-23: Test Integrity Log（テスト信頼性ログ）

テスト自体の信頼性を検証した記録。「テストが正しくテストしているか」の確認。

**必須項目:**
- テスト ID
- 検証方法（ミューテーションテスト / 手動検証 / 偽陽性チェック）
- 検証結果
- テストの修正内容（必要な場合）

**目的:** AI が生成したテストが「常に PASS する無意味なテスト」でないことを保証する。

---

### D-24: Autonomy Boundary Spec（自律境界仕様）

AI が自律的に判断してよい範囲と、社長承認が必要な範囲を定義する文書。

**必須項目:**
- 自律判断可能な操作の一覧
- 社長承認必須の操作の一覧
- グレーゾーンの判断基準
- エスカレーションフロー

**参照:** escalation.md のプロジェクト固有版として機能する。

---

### D-25: Loop Stop Criteria（ループ停止条件）

自動処理（CI/CD、自動投稿、バッチ処理等）の停止条件を定義する文書。

**必須項目:**
- 各自動処理の停止条件（エラー率、実行回数上限、時間上限）
- 停止時の通知先と通知方法
- 停止後の復旧手順

**目的:** 自動投稿暴走やコスト暴走を防ぐ（Layer C リスク対策）。

---

### D-26: Review Role Charter（レビュー役割憲章）

Codex⇄Opus レビューの役割を定義する文書。

**必須項目:**
- Codex の責任範囲と義務
- Opus の責任範囲と義務
- 馴れ合い防止ルール
- イテレーション上限

**参照:** codex-opus-protocol.md のプロジェクト固有版として機能する。

## 4. 成果物品質チェックリスト

全成果物に共通して適用する品質基準。

### 4-1: 内容の品質

- [ ] **根拠がある**: 全ての判断・仕様に根拠（一次ソース or 調査結果）が明示されている
- [ ] **テスト可能**: 合格基準が機械判定可能な形式で記述されている
- [ ] **矛盾がない**: 他の成果物との記述が矛盾していない
- [ ] **最新である**: 最新の変更が反映されている（ドリフトがない）
- [ ] **スコープ内**: MVP の範囲内に収まっている（過剰設計でない）

### 4-2: 形式の品質

- [ ] **フォーマット準拠**: プロジェクトの文書フォーマットに従っている
- [ ] **変更履歴**: 変更履歴が記録されている
- [ ] **バージョン**: 文書バージョンが明示されている
- [ ] **参照先**: 関連成果物への参照が正しい
- [ ] **読みやすさ**: 高校生説明レベルの平易さで書かれている

### 4-3: 安全性の品質

- [ ] **秘密情報なし**: APIキー・パスワード等がハードコードされていない
- [ ] **個人情報なし**: 個人情報が不必要に含まれていない
- [ ] **パス表記**: 絶対パスではなく相対パスで記述されている（cross-machine-paths 準拠）
- [ ] **コミット除外**: 環境変数ファイル・.local/ がコミット対象外になっている
