# Organized Inputs

抽出・要約・タグ付け済みのインプットを保存する場所。

## 役割

`conversations/` や `references/` などの原本を、そのままではなく活用しやすい形に整理して保存する。

## 保存するもの

- 予定・約束
- TODO候補
- 決定事項
- 人物情報
- プロジェクト関連メモ
- 会話ログの要約
- 参考資料の要点
- 重複排除済みのアクション候補

## ルール

- 原文そのものではなく、後から判断に使える形で整理する
- 可能な限り日付、出典、関連プロジェクト、優先度を付ける
- TODO候補はそのまま日別TODOに入れず、確認・優先順位付け後に反映する
- 事実、推測、ユーザー発言、AI判断を混ぜない
