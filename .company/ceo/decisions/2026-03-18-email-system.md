# 意思決定: メール送信システムの構築

## 背景
資料送付・問い合わせ対応などのメール業務を効率化するため、テンプレートベースのメール送信システムが求められた。現状は手動でメールを作成・送信しており、定型業務の工数が大きい。

## 判断内容
Python + Flask による WebUI ベースのメール送信システムを構築する。

### 技術仕様
- **フレームワーク**: Python + Flask（WebUI）
- **メール送信**: SMTP（さくらメール等の独自ドメイン）
- **テンプレート管理**: YAML ファイルで定義
- **SMTP認証情報**: `.env` ファイルで管理
- **送信履歴**: CSV ログで記録

### テンプレート（4種類）
1. **資料送付** - ドキュメント・リソースの送付用
2. **お礼・フォローアップ** - 商談後のお礼やフォロー
3. **初回ご案内** - 新規顧客への初回案内
4. **オンライン商談案内** - オンライン商談の日程・URL案内

### 宛先管理
- CSV リストからの一括読み込み
- 手動入力にも対応

### 添付ファイル
- テンプレートごとにデフォルトの添付ファイルを設定
- 送信時に変更可能

## 振り分け先
| 部署 | 指示内容 |
|------|---------|
| 開発（engineering） | システム設計・実装（Flask WebUI、SMTP連携、テンプレートエンジン、CSV送信ログ） |
| 営業（sales） | テンプレート文面の要件定義・作成、宛先リストの整備 |

## 理由
- 定型メール業務の自動化により工数を削減できる
- Python + Flask は軽量で個人開発に適しており、迅速に構築可能
- YAML テンプレート + .env 管理により、設定変更が容易
- CSV ログで送信履歴を簡易的に追跡でき、将来的な分析にも対応可能
