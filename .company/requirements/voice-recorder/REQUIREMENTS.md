# 要件定義書 — 音声録音Webアプリ（voice-recorder）

作成日: 2026-05-30

---

## ゴール

インストール不要のブラウザ完結型音声録音Webアプリを、バニラJavaScript単体（外部依存なし）で実装し、
録音・再生・リスト管理・永続保存の基本サイクルをユーザーがローカル環境で即座に利用できる状態にする。

---

## スコープ

### やること
- 単一ページ構成（index.html / style.css / app.js）の実装
- 録音操作：開始 / 停止 / 一時停止 / 再開
- 録音中のリアルタイム波形 or 音量メーター表示（Web Audio API AnalyserNode）
- 経過時間タイマー表示（mm:ss 形式）
- 録音完了後のインライン再生プレーヤー
- 録音リスト管理：再生 / ダウンロード（WebM）/ リネーム / 削除
- IndexedDB による録音Blob＋メタデータ（名前・日時・長さ）の永続保存
- リロード後も録音一覧が復元されること
- マイク権限拒否・未接続・ブラウザ非対応時の日本語エラーメッセージ表示
- 日本語UI・レスポンシブレイアウト・ダークモード対応
- README.md（日本語）：概要・起動手順・使い方・対応ブラウザ・既知の制約

### やらないこと（スコープ外）
- サーバーサイド処理・バックエンドAPI・クラウド保存
- 外部ライブラリ・フレームワーク・ビルドツールの使用
- WebM以外のフォーマット変換（WAVダウンロードは任意加点扱い・スコープ外として扱う）
- 音声編集・トリミング・ミキシング機能
- ユーザー認証・ログイン機能
- PWA化（Service Worker / オフラインキャッシュ）
- マイクデバイス選択UI（複数デバイス対応は任意加点扱い・スコープ外として扱う）
- IE / 旧Edgeサポート

## 完了条件（チェックリスト）

### ファイル構成
- [ ] `voice-recorder/index.html` が存在すること
- [ ] `voice-recorder/style.css` が存在すること
- [ ] `voice-recorder/app.js` が存在すること
- [ ] `voice-recorder/README.md`（日本語）が存在すること
- [ ] 外部CDN・npmパッケージ等の外部依存が一切ないこと

### 録音機能
- [ ] 「録音開始」ボタン押下でマイク権限リクエストが発火し、許可後に録音が始まること
- [ ] 録音中に「停止」ボタンが表示され、押下で録音が終了すること
- [ ] 録音中に「一時停止」ボタンが機能し、再押下（再開）で録音が継続されること
- [ ] 録音中、波形 or 音量メーター（canvas or SVG）がリアルタイムに更新されること
- [ ] 経過時間が mm:ss 形式で録音中に更新表示されること

### 再生・リスト管理
- [ ] 録音完了後、録音リストに新しい項目が追加されること
- [ ] 各リスト項目に「再生」ボタンがあり、インブラウザ再生できること
- [ ] 各リスト項目に「ダウンロード」ボタンがあり、WebMファイルがDLできること
- [ ] 各リスト項目のファイル名をリネームできること（UI上で編集・確定）
- [ ] 各リスト項目を削除できること（削除後はリストと IndexedDB から除去される）

### 永続保存
- [ ] ページをリロードした後も録音リストが復元されること
- [ ] IndexedDB に録音Blob・名前・録音日時・録音長さが保存されていること

### エラーハンドリング
- [ ] マイク権限を拒否した場合、日本語の案内メッセージが表示されること
- [ ] マイクデバイスが見つからない場合、日本語のエラーメッセージが表示されること
- [ ] MediaRecorder / Web Audio API 非対応ブラウザで日本語の警告が表示されること

### UI/UX
- [ ] UIのテキストがすべて日本語であること
- [ ] モバイル幅（375px）〜デスクトップ幅（1280px）でレイアウトが崩れないこと
- [ ] OS/ブラウザのダークモード設定に追従してカラーテーマが切り替わること（`prefers-color-scheme`）

### ドキュメント
- [ ] README.md に概要・ローカル起動手順（`python -m http.server` 等）・使い方が記載されていること
- [ ] README.md に対応ブラウザ・既知の制約（セキュアコンテキスト必須）が記載されていること

## 工程判断

本タスクは以下の理由から **単一工程** で実施する。

- 中間成果物が分かれない（HTML/CSS/JS/READMEはすべて同時に完成して初めて検証可能）
- IndexedDB・MediaRecorder・Web Audio API の統合は実装→ブラウザ動作確認が一体不可分
- 前後工程に品質依存関係がない
