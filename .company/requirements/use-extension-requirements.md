# 要件定義書：Claude Code の導入および設定

ユーザーから指定された「Claude Code」（Anthropic提供のCLIエージェントツール）について、Windows環境で使用できるようにするための導入・設定を行います。

## 1. ゴール
ローカルのWindows環境（PowerShell）にて、`claude` コマンドが正常に起動し、Claude Code を使用したコード操作や対話が可能な状態にする。

## 2. スコープ
### 対象とする範囲
* Node.js / npm のインストール状況の確認と、未導入時のインストール案内（または簡易導入）。
* Claude Code（`@anthropic-ai/claude-code`）のグローバルインストールおよび動作確認。
* Anthropic APIキーの設定状況の確認および環境変数（`ANTHROPIC_API_KEY`）の設定手順の案内。
* 初回起動・ログインの動作テスト。

### スコープ外とする範囲
* ユーザー固有の Anthropic アカウントの契約や、APIキーの新規発行手続き（これらはユーザー側で行う必要があります）。
* Claude Code の詳細なユースケースに応じた複雑なスクリプト開発（今回は「起動して使用可能にする」までをゴールとします）。

## 3. 完了条件
* ターミナル（PowerShell）にて、`claude` コマンドが認識され、ヘルプや初期セットアップ画面が起動すること。
* APIキーが正しく認識され、Claude Code が利用可能であることを確認すること。
* 今後の起動手順および基本的なコマンド解説がドキュメントとして整理されること。

## 4. 品質基準
1. **環境への非破壊性**: 既存のNode.js環境や他のグローバルパッケージに悪影響を与えない方法で導入する。
2. **わかりやすさ**: APIキーの登録方法など、ユーザー手動が必要な部分の手順を画像やコードブロックで分かりやすく提示する。
3. **セキュリティ**: APIキーなどの機密情報が公開リポジトリやログに露出しないよう、適切に環境変数で管理する。

## 5. 工程分割
* **工程1: 環境調査（Node.js, npm, APIキー設定）**
  * 現在の環境で Node.js, npm, `claude` コマンド、`ANTHROPIC_API_KEY` の有無を確認する。
* **工程2: インストールとセットアップ（実行フェーズ）**
  * 未インストールの場合は `npm i -g @anthropic-ai/claude-code` 等を実行。
  * APIキーの設定（ユーザー手動部分の案内と自動設定の試行）。
* **工程3: 起動テストとドキュメント作成**
  * `claude` 起動テストの実施と、基本的な使い方ガイドの作成。
