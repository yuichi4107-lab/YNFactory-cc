# 要件定義：Claude Code (claude CLI) の利用開始サポート

## 1. ゴール
ユーザーが自身の Windows 環境で Claude Code をスムーズに起動し、ログインして利用開始できるようにする。

## 2. スコープ
- **対象**: ユーザーの Windows 環境における `claude` CLI の利用サポート。
- **実施内容**:
  - 現状のインストール状況（既にインストール済みであること）の報告。
  - PowerShell / コマンドプロンプトからの起動方法および初回ログイン手順の説明。
  - トラブルシューティング（パスが通っていない場合などの対策）の提示。
- **スコープ外**:
  - 新規のインストール手順の解説（既に `C:\Users\fcmdt\.local\bin\claude.exe` にインストール済みのため不要）。

## 3. 完了条件
1. ユーザーに対し、既に `claude` バージョン `2.1.114` がインストール済みであることを報告する。
2. PowerShell 等で起動するためのコマンド（`claude`）を提示する。
3. 初回起動時の OAuth 認証（ログイン）プロセスについて説明する。
4. ユーザーが実際に `claude` コマンドを実行し、起動およびログインが完了したことを確認する（または案内により手順が明確になり、ユーザーからクローズの了承を得る）。

## 4. 品質基準
- **正確性**: 実際の調査結果（Windows 2026-05-20時点のパス）に基づいた説明であること。
- **明瞭性**: 初心者でも迷わず初回ログインに進めるよう、具体的な手順が箇条書き等で整理されていること。
- **簡潔性**: 既にインストールされているため、余計なセットアップ手順を省き、最短で起動できる案内になっていること。

## 5. 工程分割
- **工程1**: インストール状況の報告および起動・ログインガイドの提示（回答文の出力）
- **工程2**: ユーザーからの動作確認フィードバック対応（エラー等が発生した場合のトラブルシューティング）
