## outfit_presets 設計方針

### character_defs.json の拡張

現行の `character_defs.json` は `キャラ名: "外見説明文字列"` の flat 構造。
これを拡張し、`outfit_presets` オブジェクトを追加する。

```json
{
  "キャラ定義（既存）": "...",
  "outfit_presets": {
    "misaki_casual": {
      "character": "ミサキ",
      "description": "ボーダー柄（白と紺）のカットソーにデニムパンツ、白いスニーカー（自宅・外出の普段着）",
      "scenes": ["自宅", "外出", "カフェ", "公園"]
    },
    "misaki_work_home": {
      "character": "ミサキ",
      "description": "グレーのスウェット上下、素足（在宅作業・深夜集中タイム）",
      "scenes": ["在宅作業", "深夜", "早朝"]
    }
  }
}
```

- outfit_id は `{キャラ名snake_case}_{シーン略称}` の形式
- `scenes` は原稿スキャン時に自動抽出したシーン種別を紐付け（参考情報）
- 1キャラあたり2〜4プリセットを目安（多すぎると管理コスト増）

`outfit_id` 列自体は CSV の管理カラムであり、Codex の `gen_manga_bundle.py` が読み込む際に
`character_defs.json` の `outfit_presets` を参照して展開する想定とする。

### vol2 との整合性

vol2 は 30字制限・4列 CSV で生成中であり、これは変更しない。
vol3/vol4 は 50字目安・5列 CSV に更新する。
シリーズ内でフォーマットが異なるが、**画像生成品質（読みやすさ）は向上する** ためオーナー了承済み。
