# Manus連携

## 役割
Manus（AIブラウザエージェント）へのタスク受け渡しを管理する。
Claude Codeでは対応できないブラウザ操作・外部サービス操作をManusに委託する。

## フォルダ構成

```
manus/
├── CLAUDE.md
├── _template.md
├── queue/          # 未着手タスク（Claude Codeがここに配置）
├── in-progress/    # Manus作業中
├── done/           # Manus完了報告（Claude Codeが巡回して処理する）
└── archive/        # 処理済み（進捗反映後に移動）
```

## 運用ルール

### タスクの流れ
1. **Claude Code** が `queue/` に指示書を作成
2. **オーナー** が Manus を開き、指示書の内容を渡す
3. 作業開始時にファイルを `in-progress/` に移動
4. **Manus** が完了後、結果報告を `done/` に保存
5. **Claude Code** が `done/` を巡回 → プロジェクト進捗に反映 → `archive/` に移動

### done/ 巡回ルール（Claude Code向け）
- **巡回タイミング**: `/company` 起動時、および定期cronジョブ
- **巡回時にやること**:
  1. `done/` 内のファイルをすべて読む
  2. 各タスクの結果を確認し、関連プロジェクトの進捗を更新:
     - `DASHBOARD.md` の該当プロジェクトの進捗率・ステータス・次のアクションを更新
     - 必要に応じてPMのプロジェクトファイルやチケットを更新
     - CEOのdecisionsにログを残す（重要な意思決定が含まれる場合）
  3. 処理済みファイルを `done/` → `archive/` に移動
  4. オーナーに結果サマリーを報告

### ファイル命名規則
`YYYY-MM-DD-task-name.md`

### 指示書テンプレート
すべての指示書は `_template.md` のフォーマットに従う。

### ステータス管理
- `queue/` にある = 未着手
- `in-progress/` にある = Manus作業中
- `done/` にある = Manus完了・Claude Code未処理
- `archive/` にある = 処理済み（進捗反映完了）

### Manusへの渡し方
Manusに以下のように伝える：
> 「以下の指示書の内容を実行してください。完了したら結果を報告してください。」
> （指示書の内容を貼り付け）

### Claude Codeが指示書を作るタイミング
- デプロイ作業が必要なとき
- 外部サービスのアカウント作成・設定が必要なとき
- ブラウザでのGUI操作が必要なとき
- API連携の設定（OAuth認証など）が必要なとき
