# 要件定義書: ebook-to-manga 改修版 実動作テスト（vol1 冒頭5ページ）

## ゴール

gpt-image-2 全面移行済みの `ebook-to-manga` スキル（skill.md）が、`manga-career-restart` vol1 の冒頭5ページを対象に全8工程エラーなく完走し、旧版（NanoBanana2 出力）と比較して視覚的品質が同等以上であることを確認する。

---

## スコープ

### やること

- `ebook-to-manga` スキルの **Step 1〜8 全工程を通しで実行**する
  - Step 1: ソース分析（`manga-career-restart` のメタ情報・章構成を読み込む）
  - Step 2: マンガ用シナリオ作成（vol1 冒頭5ページ分のシナリオのみ）
  - Step 3: キャラクターデザイン（既存の `manuscript/characters/` を流用可。再生成も可）
  - Step 4: コマ割りCSV作成（5ページ分のみ）
  - Step 5: 画像生成ハイブリッドQCループ（gpt-image-2 + Blind-OCR + Pillowフォールバック）
  - Step 6: 表紙生成（1枚）
  - Step 7: EPUB製本（5ページ + 表紙でミニEPUBを生成）
  - Step 8: メタデータ生成（書籍情報.md / ジャンル・キーワード.md / 書籍紹介文_HTML.html）
- **出力先**: 新規ディレクトリ `03_成果物/outputs/ebooks-manga/manga-career-restart-validation/` に出力する（既存 vol1 データへの上書きは禁止）
- 旧版（NanoBanana2 出力）の `page_001〜005` と新規出力を並列で目視比較する
- 各工程完了後に工程単位で品質チェックを実施する

### 対象ページの定義

vol1 の CSV（`comicle_output.csv`）の構成:
- page 1: テキストページ（目次）
- page 2: テンプレ1（登場人物紹介）
- page 3: テンプレ1（本文）
- page 4: テンプレ4（本文）
- page 5: テンプレ6（本文）

**テスト対象**: page_001〜page_005（計5ページ）

### やらないこと

- 既存 `manga-career-restart/vol1/` 配下のデータへの上書き・変更
- 6ページ目以降の画像生成（コスト削減のため）
- vol2〜vol4 への影響確認
- 本番用 EPUB の差し替え（テスト出力のみ）
- `skill.md` の追加修正（バグが発見された場合は別タスクとして起票する）
- 旧版の再生成・上書き

## リスク管理

| リスク | 対策 |
|---|---|
| 既存 vol1 データの上書き | 出力先を `-validation/` サフィックスの新規ディレクトリに限定する |
| API レートリミット | Step 5 バッチサイズ: 5ページ（小規模のため1バッチで完了）。バッチ間 5 秒待機を維持 |
| コスト超過 | 上限 $5.00。ページ増加や iter 増加が上限を超えそうな場合は手前で停止 |
| Step 7 glob パターンのバグ | 改修後は `page_*.png` を収集するはず。テスト中に `.jpg` を拾っていたらバグ確認 |
| 長時間処理 | 5ページ程度なら 10〜15 分以内で完走する見込み |
| キャラクター統一性 | 既存 `manuscript/characters/` のリファレンス画像（ミサキ.png / ケンタ.png / タクヤ.png 等）を流用することで旧版との外見一貫性を保つ |

## 備考

- **出力先の命名**: 既存の `manga-career-restart/` と紛らわしいため、必ず `manga-career-restart-validation/` とする。vol1 サブディレクトリも作成する（`manga-career-restart-validation/vol1/pages/` 等）
- **キャラクター画像の方針**: 既存の `manga-career-restart/manuscript/characters/` の PNG（ミサキ.png / ケンタ.png / タクヤ.png 等）を流用可。再生成する場合は gpt-image-2 を使用すること
- **テキストページ（page_001 = 目次）**: 画像生成スキップ対象。EPUBにはテキストとして直接レンダリングされる
- **page_001 は旧版に存在しない**: 旧版の pages ディレクトリは page_002 から始まる（page_001 はテキストページのため生成なし）。この差異は正常
- **スキル実行の起点**: `manga-career-restart` のソースフォルダ（`03_成果物/outputs/ebooks/manga-career-restart/`）と出力フォルダ（`03_成果物/outputs/ebooks-manga/manga-career-restart-validation/`）を明示してスキルを起動する
- **ページ数上限の指示**: スキル起動時に「目標ページ数=5」を明示し、工程D のCSVが5ページで止まるよう指示する
