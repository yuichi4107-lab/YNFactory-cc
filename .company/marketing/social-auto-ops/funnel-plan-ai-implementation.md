# AI活用・AI導入 集客ファネル設計

## 1. 基本戦略

AI活用・AI導入商材は、短文だけで即申し込みに結びつけるより、読者の不安を解消しながら信頼を作る導線が向いている。

そのため、X / Threads / Instagram は入口、noteは理解と信頼形成、LPは申し込みの受け皿として役割を分ける。

## 2. 媒体別役割

| 媒体 | 役割 | 主な誘導先 | 投稿頻度 |
|---|---|---|---|
| X | 問題提起、気づき、短い事例 | note / プロフィールLP | 1日2〜3投稿 |
| Threads | 少し長めの考え方、体験談、チェックリスト | note / プロフィールLP | 1日1〜2投稿 |
| Instagram | 図解、カルーセル、視覚的な理解 | note / プロフィールLP | 週3〜5投稿 |
| note | 深い解説、失敗例、導入ステップ、信頼形成 | LP | 週2本 |
| LP | 相談、資料請求、申し込み | なし | 常設 |

## 3. 週間運用リズム

| 曜日 | note | X | Threads | Instagram |
|---|---|---|---|---|
| 月 | AI導入系の記事を完成 | 告知2〜3本 | 告知1本 | 図解1本 |
| 火 | なし | 気づき2本 | 体験談1本 | なし |
| 水 | なし | チェックリスト2本 | 長め投稿1本 | 図解1本 |
| 木 | AI活用事例の記事を完成 | 告知2〜3本 | 告知1本 | 図解1本 |
| 金 | なし | 失敗例2本 | 補足1本 | なし |
| 土 | 任意 | 軽め1〜2本 | 任意1本 | 任意1本 |
| 日 | 翌週準備 | 反応が良かった投稿再編集 | まとめ投稿 | 任意 |

## 4. 投稿カテゴリ

AI導入商材につながる投稿カテゴリを6つに分ける。

| カテゴリ | 目的 | noteテーマ例 | LP導線 |
|---|---|---|---|
| A. 小さな業務効率化 | まず試せる感を作る | ChatGPTで提案書骨子を5分で作る手順 | 業務効率化相談 |
| B. 導入前の不安解消 | 相談前の心理的ハードルを下げる | AI導入はツール選びより社内説明の1枚から始める | AI導入診断 |
| C. 失敗例と立て直し | 専門家に頼む理由を作る | 社内でAIエージェントを導入して失敗した3つ | 導入伴走 |
| D. 社内定着・ルール | 法人向けの導入感を作る | AIに渡す仕事は先に決裁ラインを決める | 社内研修 / 運用設計 |
| E. 営業・問い合わせ対応 | 直接的な収益改善に寄せる | 営業ロープレ相手にClaudeを使った1週間 | 営業支援AI |
| F. コンテンツ作成支援 | SNS運用・発信支援へつなげる | AIで投稿作成を続けるための型 | 投稿運用支援 |

## 5. 媒体別テンプレート

### X

目的:

- スクロール中に気づきを作る。
- 詳細はnoteへ誘導する。
- プロフィールLPからの直接流入も残す。

型:

```text
AI導入で最初に決めるべきなのは、
「どのツールを使うか」ではなく、
「何をAIに任せて、何を人が決めるか」です。

ここが曖昧だと、便利なのに現場で止まります。

詳しくはnoteで整理しました。
```

### Threads

目的:

- Xより少し深く、導入前の判断材料を渡す。
- noteへの橋渡しをする。

型:

```text
AI導入でよくある失敗は、ツールを入れたのに誰も使わなくなることです。

理由は単純で、使い方の研修不足だけではありません。

・どの業務で使うか
・誰が最終判断するか
・失敗したとき誰が直すか
・社内でどう説明するか

このあたりを決めずに始めると、現場は「便利そうだけど怖い」で止まります。

noteで、導入前に決める3つの線引きをまとめました。
```

### Instagram

目的:

- 図解で一瞬で理解させる。
- 保存される投稿を作る。
- プロフィールLPとnoteへ誘導する。

投稿案:

- AI導入で最初に決める3つの線引き
- AIに任せていい仕事 / 任せない仕事
- AI導入で失敗する会社の共通点
- 中小企業のAI活用は大きなDXより小さな定型業務から

CTA:

```text
詳しい考え方はnoteにまとめています。
AI活用・導入の相談はプロフィールのリンクからどうぞ。
```

### note

目的:

- 信頼形成の中心。
- 課題、具体例、失敗例、判断基準、導入ステップを丁寧に伝える。
- LPへ自然に誘導する。

標準構成:

1. 読者の課題
2. 結論
3. 具体例
4. 失敗しやすいポイント
5. 明日から試せる一歩
6. AI導入相談へのCTA

CTAテンプレート:

```text
AIを使ってみたいけれど、自社のどの業務から始めればいいか分からない。
ツールは触っているけれど、社内での使い方やルールづくりで止まっている。

そんな場合は、現在の業務を整理したうえで「最初にAI化する1業務」を一緒に決めるところから始められます。
ご相談・導入診断はLPから受け付けています。
```

### Instagram

```text
仕事で使うAI活用メモ

AI導入・活用相談はこちら
{LP_URL}
```

### note

```text
AIに詳しくない人でも、明日の仕事で1つ試せるAI活用を届けます。
中小企業・個人事業主向けに、生成AIの導入、業務効率化、社内定着の考え方を具体例で整理します。
AI導入・活用相談: {LP_URL}
```
