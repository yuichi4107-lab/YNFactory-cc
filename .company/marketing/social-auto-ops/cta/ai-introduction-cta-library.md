# AI活用・AI導入 CTAライブラリ

現在のLP URL: https://sites.google.com/yn-factory.com/ai-lp

独自ドメイン候補: https://ai.yn-factory.com

注記: `ai.yn-factory.com` は2026-05-28 18:53 JST時点では未接続のため、SNSプロフィールやnote本文では当面Google Sites公開URLを使う。

## 1. 主CTA

初期運用の主CTAは「無料AI導入診断」とする。

理由:

- X / Threads / Instagram / note から来た読者にとって、いきなり有料申込より心理的ハードルが低い。
- AI活用・AI導入は、業務内容を聞かないと提案しづらい。
- 診断を入口にすると、チャットボット構築、業務自動化、導入伴走、社内研修へ自然につなげられる。


## 3. note記事末尾CTA

### 標準

```text
AIを使ってみたいけれど、自社のどの業務から始めればいいか分からない。
ツールは触っているけれど、社内での使い方やルールづくりで止まっている。

そんな場合は、まず「最初にAI化する1業務」を決めるところから始めるのがおすすめです。
無料AI導入診断では、現在の業務を整理し、AI化しやすい業務と人が判断すべき業務を一緒に切り分けます。
```

### 柔らかめ

```text
もし「うちの場合は、どこからAIを使えばいいんだろう」と感じたら、無料AI導入診断をご利用ください。
いきなり大きなDXを目指すのではなく、まずは日々の業務の中から、小さく試せる1つを一緒に探します。
```

### 法人向け

```text
社内でAI活用を進めたいけれど、説明、ルール作り、現場定着で止まっている場合は、無料AI導入診断で現在地を整理できます。
部署ごとの業務を確認し、最初にAI化する業務、必要なルール、導入後の運用方法まで一緒に設計します。
```
