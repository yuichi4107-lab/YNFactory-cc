# Instagramリール動画 制作ワークフロー

## 概要

転職系Instagramアカウント（@tenshoku_nocareer）のリール動画を、再現性のある標準フローで制作するためのガイド。

## 制作フロー全体図

```
① 企業選定 → ② リサーチ → ③ 画像収集 → ④ 台本作成 → ⑤ キャプション作成
     → ⑥ カバーキャッチコピー → ⑦ 動画編集 → ⑧ 投稿・公開
```

## 各工程の詳細

### ① 企業選定

- **担当**: リサーチ部署
- **ツール**: 転職サイト（doda、エン転職、マイナビ転職）
- **選定基準**:
  - 勤務地: 東京、神奈川、大阪
  - 雇用形態: 正社員
  - 未経験歓迎の求人あり
  - 数字でインパクトが出せる企業（高年収、低残業、高有給取得率など）
- **成果物**: 対象企業リスト

### ② ディープリサーチ

- **担当**: リサーチ部署
- **スキル**: `/instagram-reel-producer` の Step 2
- **調査項目**:
  - 待遇面（年収、賞与、福利厚生）
  - 働きやすさ（離職率、残業時間、認定）
  - 企業の強み（シェア、独自性）
  - 事業内容・実績
  - リアルな課題・デメリット
- **成果物**: `research.md`

### ③ キービジュアル画像の取得

- **担当**: クリエイティブ部署
- **スキル**: `/instagram-reel-producer` の Step 3
- **基準**: 企業公式HPから20枚、解像度800px以上優先
- **成果物**: `images/` フォルダ + `kv_images.zip`

### ④ 台本作成

- **担当**: マーケティング部署
- **スキル**: `/instagram-reel-producer` の Step 4
- **標準仕様**:
  - **尺**: 45秒
  - **構成**: 6シーン（下記参照、CTAシーンなし）
  - **口調**: 断定・煎り系（統一ルール適用）
  - **フック**: 6パターンローテーション
  - **テロップ**: 1ページ最大48文字（12文字×4行）厳守
- **成果物**: `台本.txt`（テロップページ単位で記載）

#### シーン構成（45秒）

| シーン | 秒数 | 内容 | ポイント |
|--------|------|------|----------|
| 1. フック | 0-3秒 | ネガティブ訴求の一言 | 離脱防止。ワンフレーズ厳守 |
| 2. フック補足 | 3-8秒 | フックの理由を具体数字で提示 | 「なぜなら、賞与○○万円。」 |
| 3. 待遇① | 8-18秒 | 給与・ボーナスの詳細 | 具体的な金額で説得力を出す |
| 4. 待遇② | 18-28秒 | 福利厚生・働きやすさ | 休日数、残業時間、離職率など |
| 5. 強み | 28-38秒 | 企業の特徴・未経験OK情報 | シェア、中途採用比率など |
| 6. 企業名明かし | 38-45秒 | 「その会社は、○○。」 | ここまで社名は伏せる |

### ⑤ キャプション作成

- **担当**: マーケティング部署
- **スキル**: `/instagram-reel-producer` の Step 5
- **標準仕様**:
  - 400字以内
  - 固定CTA・固定著作権表記・固定ハッシュタグ使用
  - 回答例フォーマット準拠
- **成果物**: `キャプション.txt`

### ⑥ カバーキャッチコピー

- **担当**: クリエイティブ部署
- **スキル**: `/instagram-reel-producer` の Step 6
- **標準仕様**: 2行構成×5案、パワーワード必須
- **成果物**: `カバーキャッチコピー.txt`

### ⑦ 動画編集（手動工程）

- **担当**: オーナー
- **入力**: 台本 + キービジュアル画像
- **ツール**: CapCut / Canva / その他
- **チェック項目**:
  - [ ] テロップが台本と一致しているか
  - [ ] BGMのテンポが合っているか
  - [ ] 画像の切り替えタイミングが自然か
  - [ ] 50秒以内に収まっているか
  - [ ] カバー画像にキャッチコピーが入っているか

### ⑧ 投稿・公開

- **チェック項目**:
  - [ ] キャプションをコピー＆ペースト済み
  - [ ] カバー画像を設定済み
  - [ ] 投稿時間は最適か（平日12:00-13:00 or 20:00-22:00推奨）
  - [ ] ストーリーズでシェア済み

## 一括制作フロー（複数企業まとめて制作する場合）

1. 対象企業リストを作成（秘書室TODOに登録）
2. `/instagram-reel-producer` を企業ごとに実行
3. フックパターンは企業ごとにA→B→C→D→E→F→A…とローテーション
4. 全社分の成果物がそろったら⑦動画編集へ
5. 投稿スケジュールをカレンダーに登録
