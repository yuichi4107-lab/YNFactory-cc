## 工程A: スコアリング関数再設計

### 背景・問題
前回の評価関数 `勝率×0.4 + PF×0.3 + 月利×0.2 + (1-DD/10)×0.1` は勝率に過剰な重みを置いた結果、TP<SLで期待値がマイナスになるパラメータ（例: bb_reversion 勝率57% / PF 0.95 / 月利-0.17%）が選ばれた。

### 設計方針
- **期待値（EV）を主軸**にする: `EV = 勝率 × 平均利益 - (1-勝率) × 平均損失`
- PF ≥ 1.5 未満は問答無用で失格（足切り）
- 月利がマイナスのパラメータはスコア=0（失格）
- DD > 30% のパラメータはスコア=0（失格）

### 推奨スコアリング関数（たたき台）

```python
def score_v2(stats: dict) -> float:
    """
    期待値ベーススコアリング関数 v2
    Returns: 0.0〜1.0（高いほど良い）。失格条件に引っかかれば0.0
    """
    pf = stats["profit_factor"]
    monthly_return = stats["monthly_return_pct"]
    max_dd = stats["max_drawdown_pct"]
    win_rate = stats["win_rate_pct"] / 100
    avg_win = stats.get("avg_win_pct", 0)
    avg_loss = stats.get("avg_loss_pct", 0)

    # 失格条件（ハードフィルター）
    if pf < 1.5:
        return 0.0
    if monthly_return < 0:
        return 0.0
    if max_dd > 30:
        return 0.0

    # 期待値計算（正規化）
    ev = win_rate * avg_win - (1 - win_rate) * avg_loss  # 期待値（%）

    # スコア合成（合計1.0）
    score = (
        0.40 * min(monthly_return / 10.0, 1.0)  # 月利10%を満点基準
        + 0.30 * min((pf - 1.0) / 2.0, 1.0)     # PF 3.0を満点基準
        + 0.20 * min(max(ev, 0) / 0.5, 1.0)      # EV 0.5%を満点基準
        + 0.10 * (1.0 - max_dd / 30.0)            # DD最小化
    )
    return score
```

### サーキットブレーカー仕様

| トリガー | 内容 | 動作 |
|---------|------|------|
| 連敗N回 | 同一戦略で連続N回損失（推奨: N=5） | その戦略を当日停止。翌日から再開 |
| 月次DD閾値 | 月初比ドローダウンが閾値超過（推奨: -10%/月） | 全戦略停止・ノートレードで月末を迎える |

| 月次損益確認 | 月末5日前時点でその月がマイナスの場合 | ポジション縮小モード（ロットを50%削減）に移行 |
