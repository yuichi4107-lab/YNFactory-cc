# プロジェクト: 営業自動化ツール

## 概要
企業リストの取得、メールアドレス抽出、営業メール送信、お問い合わせフォーム営業、営業状況管理などを一括で行えるWebアプリケーション。将来的にSaaSとして提供する可能性あり。

## ゴール
- 営業活動の効率化（企業リスト生成〜営業メール送信〜CRM管理を一元化）
- 1ヶ月以内にMVPを完成させる
- SaaS化を見据えた拡張性のあるアーキテクチャ

## 技術スタック（案）
- **言語**: Python 3.11+
- **Webフレームワーク**: FastAPI
- **DB**: SQLite + aiosqlite（開発）→ PostgreSQL（本番/SaaS化時）
- **ORM**: SQLAlchemy 2.0
- **スクレイピング**: BeautifulSoup4 + httpx（Playwright対応予定）
- **フロントエンド**: Jinja2 + HTMX
- **メール送信**: smtplib + テンプレートエンジン
- **タスクキュー**: Celery + Redis（非同期処理・送信間隔制御）
