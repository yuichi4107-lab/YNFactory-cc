# プロジェクト: AI投資戦略システム（チャート画像判定）

## 概要
AIを活用してビットコイン等のチャート画像から「ダブルボトム」「ダブルトップ」等のチャートパターンを自動判定し、トレード有効性をバックテストで検証するシステム。

## ゴール
1. チャートデータ取得 → 画像生成 → AI判定 → バックテストの一連パイプライン構築
2. Gemini APIによるチャートパターン判定の精度検証
3. プロンプト調整による判定精度の最適化

## マイルストーン
| # | マイルストーン | 期限 | 状態 |
|---|-------------|------|------|
| 1 | チャートデータ取得・画像生成機能 | - | 実装済み |
| 2 | Gemini API画像判定の実装 | - | 実装済み |
| 3 | 自動バックテストシステム | - | 実装済み |
| 4 | 判定基準（プロンプト）の検証・調整 | - | 実装済み（初期版） |

## マイルストーン詳細

### MS1: チャートデータ取得・画像生成機能
- BTC 4時間足等のローソク足データ取得コード
- HTML等でチャートを可視化
- 任意範囲を選択 → 正方形画像として切り出し保存

### MS2: Gemini API画像判定の実装
- Gemini APIキー取得・.env設定
- チャート画像をGeminiに渡してパターン判定
- 判定結果: 1(True) / 0(False) をJSON形式で返却

### MS3: 自動バックテストシステム
- ローソク足を一定本数（例:5本）ずつスライドして画像自動生成
- 大量画像を順次Geminiで判定
- 損益曲線、勝率、プロフィットファクター等の算出・表示

### MS4: 判定基準の検証・調整
- 判定画像+結果一覧のHTMLビューア作成
- プロンプト調整（例: 大きめローソク足のダブルボトム＋ネックライン突破）
- 精度改善のイテレーション

## 関連部署
- 開発（主担当）: システム設計・実装
- リサーチ: Gemini API調査、チャートパターン知識
- PM: 進捗管理

## 技術スタック（想定）
- データ取得: Python (ccxt等) or JavaScript
- チャート可視化: HTML + JavaScript (TradingView Lightweight Charts等)
- 画像判定: Gemini API (Gemini 1.5 Flash)
- バックテスト: Python or JavaScript
