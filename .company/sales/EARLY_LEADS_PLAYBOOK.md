## ▶ 打ち手1：士業パートナー化（最優先・コストゼロ・最大レバレッジ）

### 概要

税理士・社労士事務所を「販売先」ではなく「共催パートナー」として口説く。先生のクライアント向けに無料AIセミナーを共催し、そのクライアント（地方中小企業の経営者）を温かいSMB母集団として間接的にアクセスする。

| 項目 | 内容 |
|---|---|
| 担当 | Claude支援（DM生成・パートナー候補リストアップ）+ オーナー手動送信 |
| 所要時間 | 初期セットアップ: 3〜4時間 / 週次継続: 週0.5〜1時間 |
| 想定リード数 | 士業1事務所あたり: クライアント企業5〜30名への接点。共催ウェビナー参加者の20〜30%が商談申込 |
| コスト | ゼロ（既存メールインフラ流用、Sales OS personalizer差し替えのみ） |
| 法令順守 | 士業への勧誘メールも特電法表記を付ける（安全装置は継続適用） |

### ターゲット士業の探し方

**方法1: gBizINFO API（既存Sales OSを転用）**

`list_builder.py` の業種フィルタを「税理士業」「社会保険労務士業」に設定し、ICPの地域（地方）で抽出する。

- gBizINFO 業種コード参考: 「721 公認会計士事務所, 税理士事務所」「726 社会保険労務士事務所」
- 地域フィルタ: 首都圏4都府県（東京・大阪・愛知・福岡）を除外（STRATEGY.md §2 ICP定義に準拠）
- 従業員規模フィルタ: 今回は「1〜20名」に絞る（小〜中規模事務所の方が所長が意思決定者）

**方法2: 士業会・商工会議所名簿**

- 各都道府県の「税理士会」公式サイトには事務所名簿が公開されている（会員名簿ページ）
- 社会保険労務士会も同様
- **各サイトの利用規約・robots.txt を確認の上で実施すること。スクレイピングを禁止しているサイトには自動取得を行わず、手動コピーのみで対応する**

**方法3: Google マップ**

「[都道府県名] 税理士事務所」で検索 → 口コミ数が少ない（小規模）・Webサイトあり・メールアドレス記載 の事務所を優先する

### 提供価値・Win-Win の設計

| 提供する側 | 受け取る価値 |
|---|---|
| オーナー（YN Factory）が士業に提供 | 「先生のクライアント向け無料AIセミナーをオーナーが無料で登壇・運営する」。先生はコンテンツ準備コストゼロで付加価値提供ができる |
| 士業が YN Factory に提供 | 先生のクライアント（地方中小経営者）への集客・告知の協力。参加者はすでに先生を信頼しているため温度感が高い |

**レベニューシェアは不要（初期）**。「先生のクライアントのお役に立てれば光栄です。謝礼は不要です」というスタンスが断られにくい。

将来的に先生のクライアントが有料契約した場合の紹介料設計は、関係が温まった後で任意に提案する（強制しない）。

### Sales OS 転用の設定方針（personalizer PROMPT_TEMPLATE 差し替え）

VPS上の `sales-ops/src/tracks/c_outbound/personalizer.py` の `PROMPT_TEMPLATE` を、士業パートナー勧誘用に一時的に差し替える（または別変数として追加定義する）。

**差し替えの核心観点:**

- `target_persona` を「経営者」→「士業事務所の所長」に変更
- `value_proposition` を「AI導入の伴走支援を提案」→「共催ウェビナーによる先生への付加価値提供を提案」に変更
- `business_context` に「ご顧問先向け勉強会の共催」というコンテキストを追加
- `personalization_hint` の生成指示を「HPの特徴から事務所の専門分野・地域密着性に触れる」に変更

`list_builder.py` の業種フィルタを士業コードに変更し、抽出 → personalizer → approval_queue → sales-briefing 承認 → 送信 という既存フローをそのまま活用できる。

**ファイル変更はVPS上の作業のため、実施はオーナーが手動でSSH接続して行う。**

## ▶ 打ち手2：バリューファースト・コールドDM（既存Sales OSの改訂方針）

### 概要

「コンサルを雇って」ではなく「**無料のウェビナー席 or 無料AI活用診断**」を最初のオファーにしたDM。既存テンプレート（`dm_v1_human_resource.md` 等）はウェビナー誘導が既に組み込まれているが、「診断」という具体的な価値提供を前面化することでCV率を改善する。

| 項目 | 内容 |
|---|---|
| 担当 | 自動（VPS Sales OS + sales-briefing 承認） |
| 所要時間 | 週0.5時間（承認作業のみ）。セットアップは初回1時間 |
| 想定リード数 | 週5〜20通送信 → 返信率2% → 週0〜0.4件。7週間で最大3〜5件の返信 |

**変えること:**

1. **件名のA/Bテスト強化**: 現行件名は「人手不足」切り口のみ。以下のバリエーションを追加する。

   - 「{{location_prefecture}}の経営者へ — ChatGPTで御社の業務がどう変わるか、無料でお伝えします」

3. **複数タッチシーケンスの整備**:

| タッチ | タイミング | 内容 |
|---|---|---|
| 1通目 | Day 0 | バリューファーストDM（ウェビナーor診断の無料案内） |

**変えないこと**: 特電法表記・送信レート制限・同一ドメイン30日重複防止・未処理変数検知ブロック（既存安全装置はすべて継続）。

## ▶ 打ち手3：有料広告 → リードマグネット誘導

### 概要

Meta広告（Facebook/Instagram）またはGoogle検索広告で地方中小経営者をターゲティングし、無料ウェビナー or 無料AI活用診断のLPへ誘導してリードを獲得する。

| 項目 | 内容 |
|---|---|
| 担当 | オーナー手動（広告設定・入稿）+ Claude支援（広告文・LP文章案） |
| 所要時間 | 初期セットアップ: 3〜5時間 / 週次: 0.5〜1時間（数値確認） |
| 想定リード数 | CPL 3,000〜8,000円想定。月3万円広告費 → 月4〜10件リード |
| コスト | 月3〜5万円（テスト予算）。まず月3万円から開始して計測し、ROI次第で増減 |
| 着手タイミング | リードマグネット（打ち手4）完成後に開始（W25〜W26を目安） |

### ユニットエコノミクスと許容 CAC

| 指標 | 数値 |
|---|---|
| L1 LTV（12ヶ月継続） | 480,000円 |
| L1 LTV（6ヶ月継続中央値） | 240,000円 |
| 許容 CAC（LTV比30%） | 72,000〜144,000円 |
| 現実的ターゲット CAC | 10,000〜30,000円以内 |
| 月広告費3万円 / CPL5,000円 | 月6件リード → 商談化率20% → 月1.2件商談 |
| 月広告費5万円 / CPL5,000円 | 月10件リード → 月2件商談 |

LTV240,000〜480,000円に対して CAC30,000円以内であれば ROI 8〜16倍。広告は費用対効果が成立する。

### Meta広告の設定方針

**ターゲティング（推奨）:**

> 注意: Metaの「職業」ターゲティング（経営者・社長・代表取締役等の職業指定）は2022年末に廃止済みで、現行の広告マネージャUIには存在しない。以下の現行手法を使うこと。

- 地域: 日本全国（ただし東京都・大阪府・愛知県・福岡県を除外設定）
- 年齢: 35〜65歳
- **詳細ターゲット（興味関心）**: 「中小企業」「ビジネスオーナー」「人材採用」「業務効率化」「人工知能」「起業・経営」など（Metaの詳細ターゲット入力欄で候補が出るキーワードを複数組み合わせる）
- **カスタムオーディエンス＋類似オーディエンス（Lookalike）**: 既存の連絡先リスト（メール取得済みの見込み客）をアップロードしてLAL 1〜2%を作成。母集団が少ない間はBroad配信（ターゲット指定なし）でAdvantage+オーディエンスに最適化を委ねる方法も有効
- **Advantage+（推奨）**: ターゲット指定を絞りすぎず「地域・年齢のみ指定 + Advantage+オーディエンスON」でMetaのAIに配信最適化を任せる。小予算テスト段階では最もCPLが下がりやすい
- 除外: IT関連の詳細ターゲット（「ソフトウェアエンジニア」「プログラミング」等）

**広告クリエイティブの方針:**

- 形式: 静止画（オーナーの顔写真 + テキストオーバーレイ）または動画（30秒以内）
- コピーの核: 「人手不足の地方中小企業経営者へ — AIで月20時間を取り戻す無料診断」
- CTA: 「無料で診断を受ける」「無料ウェビナーに参加する」

## ▶ 打ち手5：意図の高いプラットフォーム（買い手が能動的に探す場）

### 概要

「AIコンサルを探している」「経営課題の相談先を探している」という意図の高い買い手が能動的に検索するプラットフォームに登録する。コールドDMと違い、向こうから問い合わせが来るため成約率が高い。

| 項目 | 内容 |
|---|---|
| 担当 | オーナー手動（登録・プロフィール設定） |
| 所要時間 | 初期登録: 各1〜2時間 / 週次: 0.5時間（問い合わせ確認）|
| 想定リード数 | 月0〜3件（低〜中）。ただし問い合わせは温かいため商談化率が高い（50〜70%） |
| コスト | ビザスク: 無料〜成功報酬型（スポット時は15〜30%）。比較ビズ: 成功報酬型。その他: 基本無料 |

### 各プラットフォームの詳細

#### プラットフォーム1: ビザスク（スポットコンサル）

- **特徴**: 「短期・スポットで専門家に相談したい」という企業の担当者・経営者が使う。インタビュー1件30分〜2時間。料金は時給5,000〜30,000円ほどを自分で設定
- **向き不向き**: 単発相談に向いている。継続顧問の直接契約には繋がりにくいが、信頼関係構築の入口として有効。L1伴走型の継続提案への橋渡しになる
- **期待値**: 月0〜2件の問い合わせ。スポット成立後に「継続顧問」提案をする
- **登録手順**:
  1. https://visasq.co.jp にアクセス → 「専門家として登録する」
  2. プロフィール: 「中小企業のAI活用 × キャリアコンサルタント国家資格」という組み合わせを前面に
  3. スキル設定: 「ChatGPT/AI活用」「人材育成・採用」「中小企業DX」「業務効率化」
  4. 時間単価: 10,000円/時間から設定（L1月4万円の単価感と整合させる）
  5. 公開後: 週1回ログインして問い合わせを確認

#### プラットフォーム2: 比較ビズ

- **特徴**: 「業務改善・IT導入・コンサル」などを探す企業のRFQ（見積もり依頼）マッチングサービス。「AIコンサルタント」「業務効率化コンサル」カテゴリで登録可
- **向き不向き**: 成功報酬型で初期コストが低い。案件の質はまちまちだが、地方中小企業からの問い合わせも来る
- **期待値**: 月0〜2件のRFQ。返答率・提案書の質で差がつく
- **登録手順**:
  1. https://www.biz.ne.jp にアクセス → 事業者登録
  2. カテゴリ: 「IT・DXコンサルティング」「業務改善コンサルティング」を選択
  3. 対応エリア: 全国（オンライン対応）を選択
  4. 自己PR: 「キャリアコンサルタント × AI活用。社員の拒絶反応ゼロで進める中小企業DX」

#### プラットフォーム3: 補助金・助成金関連マッチング

- **特徴**: 「小規模事業者持続化補助金」「IT導入補助金」の申請を検討している企業は、同時にDX支援・AI導入の相談先を探していることが多い
- **具体的なプラットフォーム**:
  - **ミラサポplus**（中小企業庁）: 専門家登録 → 無料の専門家派遣制度に登録して露出を増やす。https://mirosapo.smrj.go.jp/
  - **よろず支援拠点**（各都道府県）: 無料相談窓口への連携。直接契約ではないが信頼の入口になる
  - **IT導入補助金の支援事業者**: IT導入補助金の「IT導入支援事業者」に登録すると、補助金申請を通じて見込み顧客と繋がれる（登録には一定の要件あり）
- **期待値**: 月0〜1件。件数は少ないが、補助金活用中の企業は意思決定が早い傾向あり
- **着手手順**:
  1. ミラサポplus: 専門家登録フォームからプロフィール登録（無料）
  2. 地元のよろず支援拠点に連絡 → 専門家登録や連携相談の可否を問い合わせ

#### プラットフォーム4: Coconala / クラウドワークスのコンサルカテゴリ

- **特徴**: フリーランスマッチング。「AIコンサル」「副業コンサル」カテゴリで出品可能。単価は低めだが問い合わせ数が多い
- **向き不向き**: L1（月4万円）の単価感とはズレがある。ただし「実績なし」の段階では信頼構築の入口として使える。数件こなした後にビザスク等の高単価へシフトする
- **期待値**: 月1〜3件の問い合わせ。単価交渉が必要
- **登録手順**: Coconala（https://coconala.com）→ 「ビジネスコンサル」→「経営・戦略」「AI活用」カテゴリで出品。サービス内容を「30分無料AI活用相談」として設定 → 本契約（L1）への誘導を設計
- **規約注意**: Coconalaは出品本文・チャットでの外部URL（自社LP・ウェビナーURL等）への誘導を規約で制限している。ウェビナー案内や診断フォームのURLは出品本文に記載せず、取引成立後のメッセージ内で案内する等、最新の利用規約を確認した上で対応すること
