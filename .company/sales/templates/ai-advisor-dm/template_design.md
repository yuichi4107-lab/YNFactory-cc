# DMテンプレート設計思想・使い分けガイド

**バージョン**: 1.0  
**作成日**: 2026-04-29  
**対象**: AI活用アドバイザー 新DMテンプレート（v1/v2/v3）

---

## 1. 共通設計思想

### ポジショニング
「ツールを売る人」ではなく「伴走してくれる相談相手」として受け取ってもらうことを最優先にしている。

キャリアコンサルタント国家資格という差別化軸は、「AI＝人を奪うもの」という世間の不安に対して、「AI＝人を活かすもの」という反論を自然な説得力で行えるポジションを与える。この差別化を3バリエーション全てに盛り込んでいる。

### 「AI導入必須」の伝え方
「AI導入は必須です」と直接言わない。代わりに：

- 現場の課題を共感ベースで描写する
- 具体的な効果（時間・コスト・人材育成）を示す
- 読者が「自分にも使えるかも」と感じる具体例を置く
- CTAは「まずウェビナーへ」という軽い一歩にとどめる

読者が「自分で判断した」と感じられる構造にすることで、押しつけを回避している。

### 文字数・文体の方針
- 目安: 800〜1,200字（件名除く・署名・特電法表記含む）
- 段落は短く。1段落3〜4行を上限とする
- 改行・空行を多めにとり、スマートフォンでも読みやすくする
- 「です・ます」調で統一。馴れ馴れしくなく、でも堅すぎない
- 経営者・中小企業向けのため、専門用語・横文字を避ける

## 2. バリエーション別の設計

### v1: 人手不足対策（`dm_v1_human_resource.md`）

**想定ターゲット**
- 業種: 製造業 / 建設業 / 運輸・物流業 / 飲食・宿泊業
- 課題仮説: 採用難・離職・現場の人手不足
- 経営者の優先課題: 「今期、採用をどうするか」

**切り口の設計**
「採用しない解決策」という逆説的なフックを件名に置く。AIを「採用の代替」として提示しつつ、「人を奪う」ではなく「今いる人を活かす」という文脈で着地させる。月〇時間短縮という具体的な数字を入れることで、リアリティを出している。

**キャリアコンサルタント差別化の活用**
- 自己紹介で「人材・組織の視点」を強調
- ウェビナー紹介で「採用コスト削減」を明示

---

### v2: 既存社員のキャリアアップ（`dm_v2_career_growth.md`）

**想定ターゲット**
- 業種: 教育・学習塾 / 医療・クリニック / 介護・福祉 / 士業（税理士・社労士等）
- 課題仮説: 社員の定着・育成・モチベーション
- 経営者の優先課題: 「優秀な社員を手放したくない」「人材に投資したい」

**切り口の設計**
「社員をAI活用できる人材に育てる」という人材育成視点からのアプローチ。「AI＝怖いもの」という社員側の不安に対して、経営者が「守り育てる立場」として行動できるという文脈を作る。キャリアコンサルタント資格の説得力が最も活きるバリエーション。

**キャリアコンサルタント差別化の活用（最大活用版）**
- 自己紹介: 「人材育成×AI活用を専門に」とキャリアコンサル資格を前面に出す
- メッセージ核心: 「人材育成のプロとして断言します」という強い表現を使用
- ウェビナー紹介: 「社員向け導入事例」という社員目線のコンテンツを予告

---

### v3: 経営者の意思決定（`dm_v3_management_decision.md`）

**想定ターゲット**
- 業種: 全業種対応（業種フィルタを強くかけない場合の汎用版）
- 課題仮説: 経営者自身が作業に追われて判断時間が確保できない
- 経営者の優先課題: 「自分の時間を経営に使いたい」

**切り口の設計**
「人とAIの役割分担」という経営者目線のフレームを使う。経営者が感じる「作業に時間を取られる」という普遍的な課題を起点に、「AIを右腕にする」というわかりやすいイメージに誘導する。業種を問わず使えるため、リストの網羅性が上がる。

**キャリアコンサルタント差別化の活用**
- 「人の強みを活かす仕組みをずっと考えてきた」という資格背景を示す
- 役割分担の発想自体が、HR視点からの自然な延長として提示される

## 3. 配信ロジック（業種マッピング）

### 第一優先: 業種別マッピング

| 業種 | 送るバリエーション | 理由 |
|---|---|---|
| 製造業 | **v1** | 人手不足・現場の省力化への課題感が高い |
| 建設業 | **v1** | 採用難・技能継承への課題感が高い |
| 運輸・物流業 | **v1** | ドライバー不足・事務作業の非効率が多い |
| 飲食・宿泊業 | **v1** | 離職率が高く人手不足が深刻 |
| 教育・学習塾 | **v2** | 講師育成・教材作成でAI活用ニーズあり |
| 医療・クリニック | **v2** | スタッフの働き方改善・キャリア支援の関心が高い |
| 介護・福祉 | **v2** | 人材育成・定着が最大課題、感情的アプローチが有効 |
| 士業（税理士・社労士等） | **v2** | 専門知識とAIの組合せ、業界の変化への対応が課題 |
| 小売業 | **v3** | 業態が多様なため汎用版が安全 |
| サービス業（その他） | **v3** | 業種特性が出しにくい場合は汎用版 |
| 業種不明・混在 | **v3** | 汎用版として機能する |

### 補足ルール

- 同一企業への送信は30日ブロック（既存安全装置を継続適用）
- 1社に送るのは1バリエーションのみ（同一企業への複数バリエーション同時送信禁止）
- 業種フィルタが取れない場合はv3（汎用版）をデフォルトとする

## 4. A/Bテストの設計

### 初回本番（各バリエーション30〜50通）でのテスト観点

**件名テスト**
- 各バリエーションの件名A（数字・具体的フック）と件名E（感情・共感系）を比較
- 件名開封率を主指標とする（Gmailの場合、返信率で間接的に計測）

**本文テスト（将来的に）**
- 冒頭3行のフックを変えたバリエーションを用意
- パーソナライズ有無での返信率差異を確認

**CTA テスト**
- 「ウェビナー申込URL」のみのCTA と、「返信型（まずは返信ください）」CTAの比較
- ウェビナー参加者がゼロの場合、「返信ください」型に切替を検討する

### 判断基準

| 指標 | 基準値 | 対応 |
|---|---|---|
| 返信率 | 2%未満 | 文面全面見直しを検討 |
| 返信率 | 2〜5% | 継続。件名・パーソナライズを微調整 |
| 返信率 | 5%超 | スケールアップ（送信数を増やす） |
| ウェビナー申込率 | 0% | CTA文言・ウェビナーLP を見直す |

## 5. 初回本番の送信計画

| バリエーション | 送信数 | 対象業種 |
|---|---|---|
| v1（人手不足） | 30〜50通 | 製造業・建設業・運輸業を優先 |
| v2（キャリアアップ） | 30〜50通 | 介護・教育・医療を優先 |
| v3（意思決定） | 30〜50通 | 業種混在・業種不明企業 |
| **合計** | **90〜150通** | |

- 送信ペース: 既存安全装置に従い、1通/分・100通/日以内を厳守
- 開始条件: テスト5件のオーナー承認後（工程8の完了後）
- 初回レビュー: 送信開始から2週間後に返信率・ウェビナー申込数を確認

## 6. 今後の改善サイクル

1. 初回配信後2週間でデータ確認
2. 返信があった業種・件名パターンを記録
3. 次回配信では反応の良かった業種に絞ってv1/v2を集中投下
4. 3ヶ月後: 業種別事例切り口（v4）や採用力強化切り口（v5）を追加検討
