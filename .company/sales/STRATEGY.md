## 1. ポジショニング

**一文の価値提案:**
「採用・育成の国家資格（キャリアコンサルタント）を持つAI活用アドバイザーが、地方の中小企業経営者に対し、社員が拒絶反応を起こさない形でAIを社内に根付かせ、人手不足・採用難を乗り越える経営変革を伴走支援する。」

**差別化の核（競合との違い）:**

一般的なAIコンサル・ITコンサルは「業務効率化 / コスト削減 / DX推進」を語る。
YN Factoryの差別化は**「キャリアコンサルタント資格 × 人手不足対策 × AI活用」**の三位一体にある。

| 比較軸 | 一般的なAIコンサル | YN Factory（当サービス） |
|---|---|---|
| 訴求の核 | 業務効率化・コスト削減 | **人を活かすAI導入**（採用難・離職対策） |
| 専門バックグラウンド | IT・エンジニア系 | **国家資格キャリアコンサルタント** |
| 社員の心理への対応 | 手薄 | **「AIに仕事を奪われる」という不安を解消する専門知識**を保有 |
| 支援スタイル | 資料提出型・スポット型 | **月次伴走型（経営者と継続的に並走）** |
| 想定顧客 | 首都圏・大企業 | **地方・従業員30〜100名の中小企業**（競合が薄い市場） |

**一般的なIT/AI出身コンサルと私が違う理由（営業トーク転用可）:**

AIを使いこなすだけなら、世の中にコンサルタントは無数にいます。私が違うのは、国家資格キャリアコンサルタントとして採用・育成・評価の現場を見てきた点です。AI導入が失敗する最大の原因は「ツールの選定ミス」ではなく、「社員が使ってくれない」という人の問題です。私は経営者目線でのコスト・生産性の話と、社員目線での「AIに仕事を奪われるのでは」という不安の両方を同時に扱えます。地方の中小企業で、採用難・人手不足に悩みながらもAI導入に踏み出せていない経営者に対して、この視点から伴走できるのが私の唯一無二の強みです。

## 2. ICP（理想顧客プロファイル）

### 対象顧客

| 属性 | 定義 |
|---|---|
| **地域** | 首都圏（東京都・大阪府・愛知県・福岡県）を除く地方全域 |
| **企業規模** | 従業員 30〜100名 |
| **業種** | 士業（税理士事務所・社労士事務所）、制作会社、製造業、医療・福祉、建設・不動産、輸送・物流など。AI/IT系・大手フランチャイズは除外 |
| **課題感** | 採用難・人手不足、社員のAI活用開始への戸惑い、DXを進めたいが何から始めるかわからない |
| **予算感** | 月4万円（L1）〜月8万円（L2）の顧問料を意思決定できる経営者または役員 |
| **決裁者ペルソナ** | 代表取締役または専務・管理部長。IT担当者ではなく経営者本人が窓口。「社員のことを考えながら経営している」タイプ |

### 除外条件（ターゲット外）
- 東京都・大阪府・愛知県・福岡県に本社を置く企業
- 従業員30名未満または100名超の企業
- AI/IT系企業（同業者への支援は競合リスクがあるため除外）
- 大手フランチャイズ加盟店（意思決定が本部依存のため成約率が低い）
- 補助金申請代行のみを求める顧客（実務代行は対象外）

### リード取得ソース（優先順）
1. **gBizINFO API**（経産省公式・無料）- 法的リスクゼロ、業種・都道府県・従業員数フィルタ対応
2. **Google Maps API**（a5）- 市町村×業種の補完的な取得
3. **商工会議所公開名簿**（a4）- Phase 2以降に実装予定

- **役割**: 認知→信頼→商談化の加速装置。ウェビナー参加者は高温度リード。
