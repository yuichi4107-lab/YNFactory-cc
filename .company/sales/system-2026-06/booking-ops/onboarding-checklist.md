# オンボーディング チェックリスト

- **使用タイミング**: 成約確定（A選択/契約書返送）を受け取った瞬間から
- **担当**: オーナー（主体）+ Claude支援（書類・設定部分）
- **目標**: 契約締結後3日以内にキックオフMTGを設定し、7日以内にサービス開始

---

## フェーズ1: 契約締結（成約確認から24時間以内）

### 1-1. 契約書の送付・締結確認

- [ ] 契約書テンプレートを開いた
  - L1/L2の場合: `03_成果物/outputs/sales-content/offer-materials/contracts/contract-L1-L2-monthly.md`
  - L3の場合: `03_成果物/outputs/sales-content/offer-materials/contracts/contract-L3-project.md`
- [ ] 以下のプレースホルダーを実際の情報に差し替えた
  - `{{contract_number}}` → 契約番号（例: `2026-001`）
  - `{{contract_date}}` → 締結日（例: `2026年7月15日`）
  - `{{client_company_name}}` → 顧客の会社名
  - `{{provider_name}}` → YN Factory 中田雄一
  - `{{plan_name}}` → L1 ライト顧問プラン / L2 スタンダード顧問プラン / L3 集中導入PJ
- [ ] 契約書をPDF化した
- [ ] 顧客にメールで送付した（件名: 「【YN Factory】AI活用顧問契約書のご送付」）
- [ ] 顧客から署名済みPDFを受領した
- [ ] 受領した契約書を以下のパスに保存した:
  ```
  .company/sales/clients/contracts/{{YYYY-MM-DD}}-contract-{{company_name}}.pdf
  ```
- [ ] クライアントファイル（`.company/sales/clients/{{company_name}}.md`）のステータスを `active` に更新した

---

## フェーズ2: 初回MTG（キックオフ）の設定（3日以内）

### 2-1. 日程調整

- [ ] 顧客にキックオフMTGの日程調整メールを送った
  - 件名: 「【YN Factory】初回キックオフMTGのご案内」
  - 本文例: 「このたびはご契約いただき誠にありがとうございます。早速ですが、初回キックオフMTGの日程を調整させてください。以下のCalendlyからご都合の良い日時をお選びください。[CalendlyのURL]」
- [ ] キックオフMTGの日時が確定した
- [ ] 確定日時をカレンダーに登録した
- [ ] Zoom URLを顧客に共有した

### 2-2. キックオフMTGアジェンダ（準備）

初回MTGは以下のアジェンダで進める（60分）。

| 時間 | 内容 | 担当 |
|---|---|---|
| 0〜10分 | 自己紹介・関係構築 | オーナー |
| 10〜30分 | 詳細ヒアリング（下記ヒアリングシートを使用） | オーナー |
| 30〜45分 | 初月の活動計画の確認・合意 | オーナー |
| 45〜55分 | ツール・連絡手段の設定（Slack招待等） | オーナー |
| 55〜60分 | 次回MTGの日程調整・質疑応答 | オーナー |

## フェーズ3: キックオフMTG実施（確定日当日）

### 3-1. キックオフ詳細ヒアリングシート

以下の情報を初回MTGで確認し、クライアントファイルに記録する。

**事業・組織の詳細**
- [ ] 主要事業・サービスの詳細（商談時より詳しく）
- [ ] 社内のAI活用状況（ツール名・使用頻度・使っている人数）
- [ ] 社内のITリテラシー分布（IT得意な人・苦手な人の比率）
- [ ] 現在使用している主な業務ツール（kintone/Google Workspace/Excel等）

**優先課題の深掘り**
- [ ] 最初に取り組む業務・課題（商談時の回答を再確認し深掘り）
- [ ] その業務の現在の作業時間・頻度
- [ ] 担当者は誰か（本人 or 特定社員 or チーム）

**期待値・コミュニケーション方針**
- [ ] このサポートで3ヶ月後にどんな状態になっていたいか
- [ ] オーナーへの連絡方法の確認（メール / Slack 等）
- [ ] MTGの時間帯・頻度の好み確認

### 3-2. 初月の活動計画（プラン別）

#### L1（月1回MTG）の初月提供物

- [ ] 月次MTG（60分）の日程を設定した
- [ ] 初月のテーマを合意した（例: 「ChatGPT活用の基礎整備」「採用文書のAI自動生成設計」等）
- [ ] 月次MTGまでに顧客に「やってみてほしいこと」（宿題）を1つ伝えた

#### L2（月2回MTG）の初月提供物

- [ ] 月2回MTGの日程を設定した（例: 第1・第3水曜 14:00〜15:00）
- [ ] 初月のカスタム資料作成テーマを合意した（月3件まで）
- [ ] Slack招待を完了した（または招待メールを送った）
- [ ] 初回MTG前に「優先して取り組む業務フロー」の整理資料を作成してSlackに投稿した

#### L3（週1回MTG × 3ヶ月）の初月提供物

- [ ] 週1回MTGのレギュラー日程を3ヶ月分カレンダー登録した
- [ ] 業務分析レポートの初版作成を開始した（2週間以内に提出目標）
- [ ] 初月で取り組む業務・AI設計の範囲を合意した
- [ ] 補助金申請の可能性がある場合: 申請期限と必要書類を確認した

## フェーズ4: 環境・ツールセットアップ（キックオフ後3日以内）

### 4-1. Slack（L2/L3のみ）

- [ ] 顧客をSlackワークスペースに招待した、または招待メールを送った
- [ ] チャンネル名のルールを案内した（例: `#yn-{{会社名略称}}-general`）
- [ ] 最初の挨拶メッセージをSlackに投稿した

### 4-2. 共有フォルダ（Google Drive等）

- [ ] 顧客との共有フォルダを作成した（必要な場合）
- [ ] 共有フォルダのURLを顧客に送った

### 4-3. 月次MTGの定期リマインド設定

- [ ] 月次MTGのカレンダーイベントを繰り返し設定した
- [ ] MTGの前日・前1時間のリマインドを顧客に送る手順を確認した（Calendlyの自動リマインダーが使える場合はそちらを活用）
