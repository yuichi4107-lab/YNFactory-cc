# note 複数アカウント運用ログイン設計

## 方針

標準はブラウザプロファイル方式。

- テーマごとに投稿先noteアカウントを固定する
- アカウントごとに専用ブラウザプロファイルを作る
- パスワード、Cookie、セッション情報はファイルに保存しない
- 一度だけ手動ログインして、その後は同じプロファイルで下書き作成する
- 公開は必ずユーザー承認後に行う

## 初期アカウント

| account_id | theme_id | 用途 | ブラウザプロファイル | 状態 |
|---|---|---|---|---|
| career | 40s-career | 40代キャリア再設計 | note-career | setup-required |

## セットアップ手順

1. テーマごとのnoteアカウントを用意する。
2. `.company/outputs/note-articles/accounts.json` の `display_name` と `note_url` を埋める。
3. アカウントごとに専用ブラウザプロファイルを作る。
4. 各プロファイルでnoteに手動ログインする。
5. 2段階認証がある場合は手動で通す。
6. テスト記事はまず下書き保存までにする。
7. 下書きURLが取れたら `history.json` の `draft_url` に記録する。

## 誤投稿防止チェック

投稿前に必ず確認する。

- 予定 `account_id`
- 予定 `theme_id`
- 予定 note URL
- 現在ログイン中のnote表示名
- 現在開いている投稿先アカウントURL

一致しない場合は投稿しない。

## 将来の自動投稿ステップ

1. 対象 `account_id` のブラウザプロファイルを開く。
2. note投稿画面を開く。
3. ログイン中の表示名またはURLを確認する。
4. 見出し画像をアップロードする。
5. 本文を入力する。
6. 本文中画像を配置する。
7. 下書き保存する。
8. 下書きURLを履歴に記録する。
9. ユーザー承認後に公開する。
