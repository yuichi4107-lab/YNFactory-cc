# ChatGPTで議事録3分。私が手放した3つのムダ作業

会議が終わったあと、議事録だけで30分くらい消えていく。

しかも時間をかけたわりに、あとから読み返すと「結局、誰が何をやるんだっけ？」となる。

そんな小さな疲れが積み重なっている人は、ChatGPTの使いどころがあります。

結論から言うと、議事録は「きれいな文章」を目指すより、まずは決定事項・宿題・次の一手だけを3分で取り出すほうが実務では使いやすいです。

ChatGPTに任せるのは、会議の中身を思い出す作業ではありません。

人間がざっと書いたメモを、あとから共有しやすい形に整えてもらう作業です。

この順番に変えるだけで、議事録づくりの負担はかなり軽くなりました。

## 議事録で時間を奪っていた3つのムダ作業

私がまず手放したのは、会議の流れを最初から最後まできれいに再現しようとすることです。

たしかに、時系列の記録が必要な会議もあります。

ただ、日常の打ち合わせで本当に必要なのは、多くの場合「何が決まったか」「誰が何をやるか」「次にいつ確認するか」です。

ここを外すと、どれだけ文章が整っていても、議事録としては使いにくくなります。

2つ目に手放したのは、発言者ごとに細かくまとめることです。

発言録のように残す必要がある場面を除けば、実務では「Aさんがこう言った」より「次回までに何を確認するか」のほうが重要です。

発言者名を追いかけすぎると、会議後に記憶を掘り起こす時間が増えます。

3つ目に手放したのは、見栄えのよい文章に最初から整えることです。

会議直後は、文章を磨く時間ではありません。

記憶が新しいうちに、材料を落とす時間です。

ここを分けると、ChatGPTがかなり使いやすくなります。

## 私が使っている3分メモの型

会議が終わったら、私はまず次の5項目だけを書きます。

1. 会議の目的
2. 決まったこと
3. 決まらなかったこと
4. 宿題と担当者
5. 次回までに確認すること

この段階では、文章は雑でかまいません。

むしろ、きれいに書こうとしないほうが早いです。

たとえば、こんな感じです。

```
目的: LP改善の方向性確認
決定: ファーストビューの訴求を「無料相談」から「診断」に変更
未決: 価格表示を載せるかは保留
宿題: Aさんが競合3社のLP確認、Bさんが既存CVRを見る
次回: 金曜10時に改善案を決める
補足: 広告文とのズレが課題
```

これくらいで十分です。

このメモをChatGPTに渡して、議事録として読める形に整えてもらいます。

ポイントは、録音を丸ごと渡す前に、人間側で「今回の会議の意味」を短く決めておくことです。

AIは文章を整えるのが得意です。

一方で、現場の空気や「これは本当に重要だった」という重みづけは、人間が補ったほうが安定します。

## ChatGPTに渡すプロンプト

私がよく使う指示は、かなりシンプルです。

```
以下の会議メモを、社内共有用の議事録に整えてください。

条件:
- 冒頭に会議の目的を1行で書く
- 決定事項、未決事項、宿題、次回アクションに分ける
- 宿題は「担当者」「期限」「内容」が分かるようにする
- 不明な点は推測で埋めず、「確認事項」として残す
- 文章は簡潔に、箇条書き中心にする

会議メモ:
（ここに3分メモを貼る）
```

このプロンプトで大事なのは、「推測で埋めない」と入れていることです。

議事録でいちばん怖いのは、AIがそれっぽく補ってしまうことです。

たとえば、期限が決まっていないのに「来週まで」と書かれると、あとで小さなトラブルになります。

だから、不明点は不明点として残す。

これはAI活用というより、仕事の安全装置です。

## 3分で終わらせるために、会議中に見る場所を決める

会議後の3分を短くするには、会議中から全部を追わないことも大切です。

私は会議中、次の言葉が出たときだけメモを厚めに取ります。

「じゃあ、それでいきましょう」

「次回までに確認します」

「ここはまだ決めきれないですね」

「一度、数字を見てから判断しましょう」

このあたりは、議事録に残す価値が高い言葉です。

逆に、背景説明や雑談に近い部分は、細かく拾いすぎないようにします。

全部を記録しようとすると、会議に参加しているのか、文字起こしをしているのか分からなくなります。

議事録係でも、会議の参加者であることは変わりません。

だから、メモの役割を「全部残す」から「あとで動ける形にする」へ変える。

この意識だけでも、かなり楽になります。

## うまくいかなかった使い方

逆に、うまくいかなかった使い方もあります。

それは、文字起こしをそのまま貼って「議事録にして」とだけ頼むことです。

これでも、それっぽい文章は返ってきます。

ただ、会議の目的や決定の重みが曖昧なままだと、出てくる議事録もぼんやりします。

特に、会議の途中で話が横道にそれた場合、AIはその横道も丁寧にまとめてしまうことがあります。

読み物としては整っていても、実務では使いにくい。

そこで私は、文字起こしを使う場合でも、先に自分で「この会議で一番大事だったこと」を1行だけ書くようにしました。

たとえば、「今日はLP改善の方向性を決める会議だった」と書いておく。

そのうえで文字起こしやメモを渡すと、ChatGPTのまとめ方がかなり安定します。

AIに任せる前に、目的を1行で渡す。

地味ですが、ここが効きます。

## 議事録は、完成品より次の行動が大事

議事録を作る目的は、文章を残すことではありません。

次の行動を迷わないようにすることです。

だから、最終確認では次の3つだけ見ます。

決定事項は、読み手が同じ理解になりそうか。

宿題は、担当者と期限が分かるか。

確認事項は、曖昧なまま決定扱いになっていないか。

この3つが見えていれば、多少文章が不格好でも実務では十分です。

逆に、文章がきれいでも、この3つが曖昧なら手直しします。

ChatGPTは、ここでも使えます。

最後にこう聞くと、抜けを見つけやすくなります。

```
この議事録を読んだ人が、次に何をすればよいか迷いそうな箇所を指摘してください。
推測で直さず、確認すべき質問として挙げてください。
```

この「質問として挙げる」という指示が便利です。

AIに勝手に直させるのではなく、人間が確認すべき点を出してもらう。

これなら、議事録の正確性を保ちやすくなります。

## 明日から試すなら、この順番でいい

最初から完璧な運用を作る必要はありません。

まずは次の1回の会議だけで試せば十分です。

会議が終わった直後に、3分だけ時間を取る。

決定事項、未決事項、宿題、次回アクションを書く。

そのメモをChatGPTに渡して、社内共有用に整えてもらう。

最後に、担当者・期限・確認事項だけ人間が見る。

これだけです。

慣れてくると、議事録作成は「会議後に思い出す作業」ではなく、「会議直後に整える作業」に変わります。

この差は小さいようで、かなり大きいです。

後回しにすると記憶は薄れます。

でも、会議直後なら、重要だった空気感がまだ残っています。

そこを人間が3分で拾い、ChatGPTに整えてもらう。

それくらいの距離感が、今のところいちばん実務に合っていると感じています。

## 保存用チェックリスト

- 会議後すぐに3分だけメモ時間を取ったか
- 会議の目的を1行で書いたか
- 決定事項と未決事項を分けたか
- 宿題に担当者と期限を入れたか
- 不明点をAIに推測で埋めさせていないか
- 最後に「次に何をすればよいか」が分かる状態になっているか

議事録をAIに任せるコツは、全部を自動化しようとしないことです。

人間が意味を決める。

AIが形を整える。

この分担にすると、会議後の小さな負担はかなり減らせます。
