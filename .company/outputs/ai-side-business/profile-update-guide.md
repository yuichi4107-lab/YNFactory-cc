# プロフィール更新 指示書

作成日: 2026-04-05
目的: ココナラ・クラウドワークス・ランサーズの自己紹介にYN Toolsの実績を追加する

---

## 1. ココナラ

### アクセス手順
1. https://coconala.com にログイン
2. 右上のアイコン → 「プロフィール編集」をクリック
3. 「自己紹介」欄を見つける

### 貼り付けるテキスト

以下を「自己紹介」欄に貼り付けて保存してください：

---

プロフィールをご覧いただきありがとうございます。
AI業務自動化を専門とするエンジニアです。

「AIを使って業務を効率化したいけど、何から手をつけていいかわからない」
そんなお悩みを、技術と実務の両面からサポートいたします。

【個人開発の実績】
AI業務自動化プラットフォーム「YN Tools」を個人で設計・開発・運用しています。
https://tools.ynfactory.online

営業自動化、AIチャットボット、請求書生成、AI文書処理、翻訳、SEO分析、LP自動生成、AI画像生成など、29種類のAI業務ツールを搭載したWebサービスです。
バックエンド（FastAPI/Python）、認証（Google OAuth）、決済（Stripe連携）、VPSでのサーバー運用まで、すべて一人で構築しています。

単に「コードが書ける」だけでなく、企画からサービス設計、リリース、運用まで一貫して対応できることが強みです。

【提供しているサービス】
・AIチャットボット構築（LINE Bot、Webサイト埋め込み型）
・AI業務自動化ツールの開発（Python、GAS）
・AI導入コンサルティング（ChatGPT、Gemini、Claude等の活用提案）
・スクレイピング・データ収集の自動化
・Stripe決済連携の実装

【使用技術】
Python（FastAPI, Flask）/ Google Apps Script / ChatGPT API / Gemini API / Claude API / Stripe API / VPS構築・運用

ご要望をしっかりお聞きした上で、最適な方法をご提案いたします。
小さなご相談からでもお気軽にメッセージください。
丁寧かつ迅速な対応を心がけています。

---

### 保存後の確認
- プロフィールページを開いてYN ToolsのURLがリンクになっているか確認
- 文字化けがないか確認

## 2. クラウドワークス

3. 「自己PR」欄を見つける

技術構成: FastAPI (Python) / Google OAuth認証 / Stripe決済 / VPSホスティング
