「黒い画面」のイメージを、もう手放していい

〝キャリアコンサルタント兼AI活用アドバイザーの視点から。〟

第3巻からは、AIツールが日常になった時代のキャリア論として、より実践的にお届けします。

——「AI」と聞いて、何を思い浮かべるだろうか。

非エンジニアの方の多くが、まず連想するのは「黒い画面に、緑色の英数字がカタカタ流れていく映像」だろう。映画やドラマで見てきた、あの〝ハッカーの机〟のイメージだ。あるいは、難しいプログラミング言語、英語のエラーメッセージ、専門家しか理解できない呪文のような世界——。

「私には、無理」「文系だから」「機械が苦手だから」。第5章でミサキも、同じ言葉を最初に口にしていた。プログラミング、難しい設定、英語——3つの壁すべてが、この〝黒い画面〟のイメージから来ていた。

だが、現実のAIツールは、その姿をしていない。

Claude も ChatGPT も、開いてみると、そこにあるのは LINE のような白い対話画面だ。日本語で何か書いて、エンター。それだけで、相手から日本語で返事が返ってくる。プログラミングはどこにもない。コマンドラインも、黒い画面も、英語のエラーも、存在しない。
