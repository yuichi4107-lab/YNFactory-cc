## 工程3: 時系列整合性チェック（CSV生成直後に必須実行）

### 概要

過去の失敗（重複セリフ・時系列逆行）を自動検出するための専用チェック工程。
工程2（CSV生成）が完了した直後、工程4（画像生成）開始前に必ず実行する。

### チェック手順

**チェック1: 重複セリフ検出**

`コマ別テキストJSON` の全 `text` フィールドを抽出し、
完全一致または高類似度（Levenshtein距離 ≦ 5文字）のペアを列挙する。

```python
# 疑似コード
import csv, json, difflib

path = 'vol3/panels/comicle_output.csv'
with open(path) as f:
    rows = list(csv.reader(f))

all_texts = []
for row in rows[1:]:
    if row[3] == '[]' or not row[3].strip():
        continue
    try:
        items = json.loads(row[3])
        for item in items:
            all_texts.append({
                'page': row[0],
                'panel': item.get('panel_id'),
                'text': item.get('text', ''),
                'speaker': item.get('speaker')
            })
    except:
        pass

# 全ペアで一致率チェック
duplicates = []
for i in range(len(all_texts)):
    for j in range(i+1, len(all_texts)):
        ratio = difflib.SequenceMatcher(
            None, all_texts[i]['text'], all_texts[j]['text']
        ).ratio()
        if ratio >= 0.85 and all_texts[i]['page'] != all_texts[j]['page']:
            duplicates.append((all_texts[i], all_texts[j], ratio))

if duplicates:
    print('ERROR: 重複セリフ検出')
    for d in duplicates:
        print(f"  P{d[0]['page']} vs P{d[1]['page']}: {d[0]['text'][:50]} (類似度={d[2]:.2f})")
else:
    print('PASS: 重複セリフなし')
```

**チェック2: 時系列逆行検出**

各ページのナレーションテキストを順番に読み、
以下のキーワードパターンが後続ページで再登場していないかをチェックする。

| 禁止パターン | 理由 |
|---|---|
| 「Zoom面談の前日」「前日夜」「Zoom前夜」がT-2以降のページに登場 | 面談開始後に「前日」が再登場するのは時系列逆行 |
| 「明日.*Zoom」がT-2以降のページに登場 | 面談中に「明日面談がある」は矛盾 |
| 同一シーン名（例:「壁①」「壁②」「壁③」）が2回以上登場 | 同一場面の重複割り付け |

**チェック3: コラム配置確認**

- 第5章終了ページ（T-5）の直後2ページがコラム⑥であること
- コラム⑥のテキストが `コラム⑥_⑦_v2.md` の「【コラム⑥】」本文と一致すること（先頭50文字で一致確認）
- 第6章終了ページ（T-13）の直後2ページがコラム⑦であること
- コラム⑦のテキストが `コラム⑥_⑦_v2.md` の「【コラム⑦】」本文と一致すること

## 補足

### 品質ループ上限ルール
- 各工程ごとに executor → quality-checker のループは最大5回
- 5回で85点未満の場合はユーザーに相談する

### 画像生成モード
- デフォルトは `HANDOFF_MODE=inline`
- Codex handoff を使用する場合はユーザーが明示的に指示すること

### キャラクター参照画像の確認
- Step 3 は今回スキップ（既存流用）だが、工程開始前に `manuscript/characters/` に以下のPNGが存在することを確認する:
  - `ミサキ.png`
  - `タクヤ.png`
  - `ケンタ.png`
  - `ひなた_2歳期.png`
  - （上記が揃っていない場合のみ Step 3 を実行する）

### 目標ページ数
- 推定 90〜110 ページ（シナリオ文字数約 18,000 字ベース）
- 前付け3ページ + コラム4ページ + 後付け3ページ（著者紹介・CTA除く奥付等）= 固定10ページ
- 本編: 80〜100 ページ
