# ChatGPT GPTs 登録手順書

## はじめに
このドキュメントでは、ChatGPT GPTs の登録（作成）手順を説明します。
`delivery-gpts-summary.md` に記載されている設定情報を使って、1つずつGPTを作成していきます。

---

## 事前準備

1. OpenAI アカウントにログインする
2. [ChatGPT](https://chat.openai.com/) にアクセスする
3. ChatGPT Plus（有料プラン）が有効であることを確認する
   - GPTs作成機能はPlusプランでのみ利用可能です

---

## GPT の作成手順（1本あたり約3〜4分）

### Step 1: GPT作成画面を開く

1. ChatGPT の画面左側サイドバーにある **「GPTを探す」** をクリック
2. 右上の **「+ 作成」** ボタンをクリック
3. 上部のタブで **「構成」（Configure）** を選択

### Step 2: 基本情報を入力

1. **名前（Name）** 欄に、`delivery-gpts-summary.md` の「GPT名」をコピペ
   - 例: `社内メールアシスタント`

2. **説明（Description）** 欄に「説明文」をコピペ

### Step 3: インストラクションを設定

1. **「指示（Instructions）」** 欄に、`delivery-gpts-summary.md` の「インストラクション」部分をそのままコピペ
   - まとめファイルではコピペしやすいようにコードブロックの囲みを外してあります
   - そのまま貼り付けてください

### Step 4: 会話スターターを設定

1. **「会話のきっかけ（Conversation starters）」** 欄に、1つずつ入力
   - 入力欄が4つ表示されるので、各欄に1つずつコピペ
   - 例:
     - `社内向けの報告メールを作成したいです`
     - `上司への依頼メールを書きたいです`
     - `会議の案内メールを書きたいのですが`

### Step 5: 機能設定を確認

`delivery-gpts-summary.md` の「機能設定」に従って、トグルを ON/OFF する：

| 機能 | 設定場所 | 確認ポイント |
|------|---------|------------|
| **Web Browsing** | 「機能」セクション | ほとんどのGPTはOFF |
| **DALL·E** | 「機能」セクション | 全GPTでOFF |
| **Code Interpreter** | 「機能」セクション | Excel系（#33〜#37）とアンケート（#32）はON、他はOFF |

### Step 6: 保存・公開

1. 右上の **「保存」** ボタンをクリック
2. 公開範囲を選択：
   - **「自分だけ」（Only me）** — テスト用
   - **「リンクを知っている人」（Anyone with a link）** — 共有用
   - **「公開」（Public）** — 一般公開
   - クライアントの指示に従って設定してください
3. **「確認」** をクリック

### Step 7: 動作確認

1. 保存後、作成したGPTの画面で会話スターターをクリック
2. 正しく応答するか確認

### Step 8: チェックリストを更新

1. `delivery-gpts-summary.md` のチェックリスト表で、作成完了した行にチェックを入れる

## 効率的に進めるコツ

### 画面配置
- **左半分**: `delivery-gpts-summary.md` をブラウザまたはテキストエディタで開く
- **右半分**: ChatGPTのGPT作成画面を開く
- 順番にコピペしていくのが最も効率的

### 作業の順番
1. `delivery-gpts-summary.md` を上から順に（#01 → #50）進める
2. 1本完了するごとにチェックリストにチェック
3. 10本ごとに動作確認（スターターをクリックして応答を確認）

### 注意点
- インストラクションが長い場合、途中で途切れていないか確認してください
- 会話スターターは**4つの入力欄にそれぞれ1つずつ**入力してください
- 機能設定（特にCode Interpreter）を忘れずに確認してください
- GPT名が長すぎる場合は、短縮しても構いません

### Code Interpreter を ON にするGPT一覧
以下のGPTはCode Interpreterを必ずONにしてください：

| # | テーマ |
|---|--------|
| 32 | アンケート設計・集計分析 |
| 33 | Excel関数・マクロの作成支援 |
| 34 | データ集計・ピボット指示作成 |
| 35 | グラフ・チャート選定・作成指示 |
| 36 | CSV・データクレンジング指示 |
| 37 | Excel業務の自動化アドバイザー |

## 所要時間の目安

| 作業 | 1本あたり | 50本合計 |
|------|----------|---------|
| コピペ＋設定＋保存 | 約3〜4分 | 約2.5〜3.5時間 |
| 動作確認 | 約1分 | 約50分 |
| **合計** | **約4〜5分** | **約3〜4時間** |

休憩を挟みながら、半日〜1日あれば完了できます。

---

## トラブルシューティング

| 症状 | 対処法 |
|------|--------|
| インストラクションが保存されない | 文字数制限（約8,000文字）を確認。超える場合は要点を絞って短縮 |
| 会話スターターが4つ以上入力できない | ChatGPTの仕様で最大4つ。4つに収める |
| GPTが意図通りに動かない | インストラクションが途中で途切れていないか確認 |
| GPT作成メニューが見つからない | ChatGPT Plusプランが有効か確認 |
| 「保存」ボタンが押せない | 名前（Name）が未入力でないか確認 |
| Code Interpreterのトグルが見つからない | 「構成」タブの下部「機能」セクションまでスクロール |
