## どのプランを選ぶか — 選定フローチャート

```
AIについて何か相談したい
    │
    ├── まだ何もAIを使っていない。どこから始めるかわからない
    │       └──→  L1 ライト顧問（月4万円）
    │
    ├── ChatGPT等は使い始めた。もっと本格的に使いたい
    │       │
    │       ├── 月2回の壁打ち + 一緒にツールを作りたい
    │       │       └──→  L2 スタンダード顧問（月8万円）
    │       │
    │       └── 特定業務を集中的にAI化して成果物が欲しい
    │               └──→  L3 集中導入PJ（総額30万円・3ヶ月）
    │
    └── 迷っている → まず個別Zoom相談（無料）
```

## プラン別 こんな方に向いている

### L1 ライト顧問（月4万円）

**こんな方に:**
- AIを使い始めたいが、何から手をつければいいか迷っている
- まず相談できる専門家を月1回確保したい
- 大きな投資をする前に、少額で試したい

**向いていない方:**
- AIツールを既に複数使いこなしている
- 毎月10件以上の質問が予想される
- 社員への展開を急いでいる

---

### L2 スタンダード顧問（月8万円）

**こんな方に:**
- ChatGPT等を使い始めているが、もっと深く活用したい
- 月2回の壁打ちで継続的に伴走してほしい
- 簡単なツール・テンプレートを一緒に作りたい
- 社員向け研修資料等、カスタム資料が欲しい

**向いていない方:**
- まだAIをほとんど使ったことがない（L1からが安心）
- 特定業務を一気にAI化したい（L3が適切）

---

### L3 集中導入PJ（総額30万円・3ヶ月）

**こんな方に:**
- 「この業務をAI化したい」という明確な対象がある
- 業務分析から設計・導入まで一貫してサポートを受けたい
- 3ヶ月後に「使える成果物」が手元にある状態にしたい
- 補助金を活用してコストを抑えたい

**向いていない方:**
- まだ対象業務が決まっていない（L1/L2で整理してから）
- 3ヶ月の集中投資より月額継続を好む

## キャリアコンサルタント差別化（全プラン共通の強み）

**AI導入の最大の障壁は「人」の問題です。**

- 社員が「AIに仕事を奪われる」と感じ、使ってくれない
- ベテラン社員が抵抗感を示す
- 「ツールは動いているが誰も使っていない」

国家資格キャリアコンサルタントとして、採用・育成・評価の専門家でもある当アドバイザーは:

**「AI＝人を奪うものではなく、人を活かすもの」**として、経営者目線と社員目線の両方から助言できます。

これが一般的なIT/AIコンサルタントにはない、唯一無二の差別化です。
