## 申込フォーム設定（Peatix「アンケート」機能）

Peatixの「チケット購入時アンケート」機能で以下の質問を設定する。

| 質問 | 種別 | 必須 |
|---|---|---|
| 会社名 | テキスト（一行） | 必須 |
| 業種 | 選択肢（製造業 / 建設業 / 小売業 / 飲食業 / 物流業 / 医療福祉 / サービス業 / その他） | 必須 |
| 従業員数 | 選択肢（10〜30名 / 31〜50名 / 51〜100名 / 101名以上） | 必須 |
| 都道府県 | テキスト（一行） | 必須 |
| 事前に聞きたいこと・現在の課題 | テキスト（複数行） | 任意 |

> Peatixはデフォルトで氏名・メールアドレスを取得するため追加不要。

## 受付期間の目安

| タイミング | 内容 |
|---|---|
| 開催6週前〜 | イベントページ公開・DM/SNSで告知開始 |
| 開催3週前〜 | リマインド告知（SNS・DM再送） |
| 開催3日前 | 申込締切 |
| 開催前日 | Zoom URLを全申込者にメール送信 |
| 開催当日 | 開催1時間前にリマインドメール送信 |

## Peatixで申込データを取得する手順

1. Peatix管理画面 → 「参加者リスト」→ CSV書き出し
2. 項目: 氏名 / メール / 会社名 / 業種 / 従業員数 / 都道府県
3. 書き出したCSVをGoogleスプレッドシートにインポートして管理
4. ウェビナー後のフォローアップメールリストとして活用

## 運用Tips

- **無料イベントの場合**: Peatixの手数料は0円（有料イベントは参加費の5%）
- **Zoom URL共有**: Peatixの「開催情報」欄に直接Zoom URLを記載してもよいが、
  スパム防止のため「申込後にメールで送付」の方式を推奨
- **Peatix × Zoom連携**: Peatix Pro（有料）を使うとZoom連携が自動化できるが、
  初期は手動メール送信で十分（申込10件を超えたら検討）
