# AI活用ウェビナー アンケート構成案

ウェビナー終了後フォローアップメール（`post-webinar-followup.md`）に掲載するアンケートフォームの作成手順と設計内容。

---

## 1. Google Forms 作成手順

1. [Google Forms](https://forms.google.com) にアクセスし、Googleアカウントでログイン
2. 「新しいフォームを作成」（空白）をクリック
3. フォームタイトルに「AI活用ウェビナー アンケート」と入力
4. 説明欄に以下を入力:
   ```
   本日のウェビナーにご参加いただきありがとうございました。
   次回の内容をより良くするために、1〜2分でご回答いただけますと幸いです。
   ```
5. 下記「アンケート設計」に従って質問を追加
6. 右上の「送信」ボタン → リンクアイコンをクリックしてURLを発行（短縮URLにチェック推奨）
7. 発行したURLを `post-webinar-followup.md` の `{{survey_url}}` に反映

## 2. アンケート設計

### フォームタイトル
```
AI活用ウェビナー アンケート
```

### 説明文
```
本日のウェビナーにご参加いただきありがとうございました。
次回の内容をより良くするために、1〜2分でご回答いただけますと幸いです。
```

---

### Q1. 今日のウェビナー全体の満足度を教えてください

- 形式: **線形スケール（1〜5）**
- ラベル: 1 = まったく満足していない / 5 = とても満足した
- 必須: はい

---

### Q2. 特に参考になった内容を選んでください（複数選択可）

- 形式: **チェックボックス（複数選択）**
- 必須: いいえ
- 選択肢:
  - 求人票・採用文章の自動生成
  - 日報・議事録の自動化
  - 問い合わせ対応の自動化
  - マニュアル自動生成による新人育成効率化
  - データ分析・要約による経営判断の効率化
  - キャリアコンサルタント視点「AI＝人を活かす」という考え方
  - その他（自由記述欄を追加）

---

### Q3. 今後開催してほしいテーマや、聞いてみたいことがあれば教えてください

- 形式: **段落（自由記述）**
- 必須: いいえ
- プレースホルダー例: 「例: ChatGPTの使い方をもっと詳しく / 小売業でのAI活用事例など」

---

### Q4. 無料個別相談（Zoom・30分）にご興味はありますか？

- 形式: **ラジオボタン（単一選択）**
- 必須: はい
- 選択肢:
  - はい、ぜひ相談したい
  - 検討中（もう少し情報がほしい）
  - 今回は見送ります

> 「はい」を選択した方は、フォーム送信後に個別相談予約ページ（Calendly等）へ自動リダイレクトする設定を推奨。詳細は「CTA設計」セクション参照。

---

### Q5. 個別相談ご希望の方：お名前・会社名をお知らせください（任意）

- 形式: **短文回答**
- 必須: いいえ
- 表示条件: Q4 で「はい、ぜひ相談したい」を選択した場合のみ表示（セクション分割で対応）
- 入力例: 「山田 太郎 / 株式会社〇〇」

## 3. 設定オプション

### 回答受付期間
- Google Forms メニュー（歯車アイコン）→「プレゼンテーション」タブ
- 受付終了日は特に設定しなくてよい（随時受付）
- ただし、フォローアップメール送信後1週間を目安に集計を確認する

### メール通知設定
- Google Forms メニュー → 「回答」タブ → スプレッドシートアイコン → 「新しいスプレッドシートを作成」
- スプレッドシートの「ツール」→「通知ルール」→「回答があるたびにメールで通知」を設定
- 通知先: `info@ynfactory.online`

### スプレッドシート連携
- 「回答」タブ → スプレッドシートアイコンで自動的に回答データが記録される
- 列: タイムスタンプ、Q1満足度、Q2参考になった内容、Q3テーマ希望、Q4相談希望、Q5氏名・会社名

## 4. CTA設計（個別相談希望者へのリダイレクト）

フォームの「確認ページ」で個別相談希望者をCalendlyに誘導する。

### 設定手順
1. Google Forms メニュー（歯車アイコン）→「プレゼンテーション」タブ
2. 「回答後のリンク」または「確認メッセージ」欄に以下を入力:

```
ご回答ありがとうございます。
個別相談をご希望の方は、以下のURLから日程をご予約ください。
https://calendly.com/（オーナーのCalendlyURL）
```

> 注意: Google Forms のネイティブ機能では「Q4の回答に応じた条件付きリダイレクト」は設定不可。
> 全員に同じ確認メッセージが表示されるため、Q5（名前・会社名）で意思を補足する設計にしている。
> 条件付きリダイレクトが必要な場合は Typeform 等の有料ツールへの移行を検討する。

## 5. 回答データ活用案

### 次回ウェビナーテーマ選定
- Q3（テーマ希望）の自由記述を集計し、複数回答があったテーマを優先的に採用する
- スプレッドシートでキーワードを色分けしてパターンを把握する

### 継続的な改善PDCA
- Q1（満足度）の平均スコアを毎回記録し、前回比較で改善傾向を追う
- Q2（参考になった内容）の集計でコンテンツの「打率」を可視化する
- 目標: 満足度平均 4.2以上、個別相談希望率 20%以上

### 個別相談転換
- Q4「はい」の回答者には確認ページのCalendlyリンクと、フォローアップメール内の個別相談CTAの2段階でアクションを促す
- Q5で氏名・会社名を取得できた場合は、翌営業日以内に個別の御礼メールを送ることでさらに転換率を高める
