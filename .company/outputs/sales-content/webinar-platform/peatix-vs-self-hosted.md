# Peatix vs 自社ホスト 比較メモ

> ウェビナー集客基盤として「Peatix」と「自社ホスト（landing-page.html + Webhook）」のどちらを採用すべきかを比較し、推奨案を提示します。

---

## 比較表

| 観点 | Peatix | 自社ホスト（HTML LP + Webhook） |
|---|---|---|
| **コスト** | 無料イベントは0円。有料イベントは参加費の5%手数料 | 初期: ほぼ0円（VPSに同居）。メール送信にSendGrid無料枠(100通/日)使用 |
| **集客力（SEO・告知力）** | 強い。Peatix内検索・Google検索に自動でインデックス。「地域×ビジネス勉強会」での発見が期待できる | ゼロ（URL拡散のみ）。SEO効果はドメイン育成が必要で即効性なし |
| **カスタマイズ性** | 限定的。テンプレート内での編集のみ。ブランドカラーや独自レイアウトは不可 | 完全自由。landing-page.html をそのまま使用可。デザイン統一・CTAの最適化が自在 |
| **申込データ取得のしやすさ** | 簡単。管理画面からCSV書き出し一発。氏名・メール・アンケート回答が揃う | 設計次第。Webhook → Google Sheets / DB に自動格納すれば同等のデータが取れる |
| **当日の運営しやすさ** | 高い。参加者へのメール一括送信機能あり。キャンセル管理・入金管理（有料時）も一元化 | 手動操作が増える。Zoom URL送付・リマインダーは自分でスケジュール送信を組む必要あり |
| **自動メール** | 基本的な申込確認メールは自動。リマインダーは「メール配信」から手動スケジュール設定が必要 | Webhook + Gmail API / SendGrid で完全自動化可能。テンプレートの自由度も高い |
| **Zoom連携** | 手動URL共有（無料プラン）。Peatix Pro（有料）なら自動連携 | Zoom API を使えば自動連携可能（工程7以降で実装可能） |
| **ブランド統一感** | Peatix のロゴ・UIが前面に出る。オーナーブランドは弱まる | 完全自社ブランド。landing-page.html のネイビー×オレンジ配色が貫かれる |
| **初期設定の速さ** | 最速15分で公開可能。アカウント登録 → イベント作成 → 公開だけ | LP作成済み。Webhookエンドポイントの実装に1〜2時間かかる |
| **スパムフィルタリスク** | 低い。Peatix のドメインからメールが送られるため届きやすい | 中。info@ynfactory.online のSPF/DKIM設定が適切なら問題なし |
| **参加者の安心感** | 高い。Peatixというプラットフォームの信頼性がある | やや低い（初期）。実績が積まれてきたら問題なくなる |

## 詳細比較

### コスト

**Peatix（無料イベント）**
- 参加費0円のイベントなら完全無料
- 有料イベント（例: 5,000円/人 × 30名 = 150,000円）の場合は5%（7,500円）の手数料

**自社ホスト**
- landing-page.html は作成済みのため追加コストなし
- Webhook受付: VPSの既存サーバーに同居（追加コスト0円）
- メール送信: SendGrid 無料枠（100通/日）または Gmail API（100通/日）で十分
- 月次コスト: 約0円（既存VPS代に含まれる）

**判定: コストはほぼ互角。どちらも無料で始められる。**

---

### 集客力（SEO・告知力）

**Peatix の強み**
- Peatix 自体がSEO評価を受けているため、「地方中小企業 AI セミナー」などのキーワードで検索に引っかかる可能性がある
- Peatixのトップページ「おすすめイベント」に表示されることがある
- 「Peatix 経由で参加した」という口コミが広まりやすい

**自社ホストの弱み**
- ドメイン（ynfactory.online）の検索評価がゼロスタートに近い
- SNS・DM・口コミ以外での集客チャネルがない
- SEO成果が出るまでに3〜6ヶ月かかる

**判定: 集客力はPeatixが圧勝。初期フェーズでは重要な優位点。**

---

### カスタマイズ性

**Peatix の限界**
- イベント本文はテキストのみ（一部HTML不可）
- 申込フォームのカスタムはアンケート機能のみ
- ブランドカラーやオリジナルデザインは表現できない

**自社ホストの強み**
- landing-page.html でネイビー×オレンジの完全統一デザイン
- フォーム項目を自由に追加・変更可能
- A/Bテスト（ヒーローコピーのバリエーション検証）が可能

**判定: カスタマイズ性は自社ホストが優位。ただしMVP段階では不要。**

---

### 当日の運営しやすさ

**Peatix**
- 参加者リスト一覧をリアルタイムで確認できる
- メール一括送信が簡単（リマインダーもスケジュール設定可能）
- キャンセル管理が自動化されている

**自社ホスト**
- 参加者データはGoogle SheetsやDBで管理
- Zoom URL送付・リマインダーは手動スケジュール送信が必要（工程7で自動化可能）

**判定: 初期の運営しやすさはPeatixに軍配。**

---

## 推奨案

### MVPフェーズ（今すぐ）: Peatix を採用する

**理由:**
1. Peatixは今日中に無料で公開でき、DM・SNS告知とセットで即集客できる
2. Peatix内の検索・おすすめからオーガニック流入が期待できる（自社ホストにはない強み）
3. 申込フォーム・確認メール・参加者管理が最初から揃っており、運営コストが低い
4. 参加者にとっての信頼性（「Peatixのイベント」という安心感）
5. 最初の10〜30名集客に最適。コンセプト検証フェーズでは機能的に十分

**実施手順（Peatixで即スタート）:**
1. `signup-form.md` の設定例を使ってPeatixでイベントを作成（所要15〜30分）
2. DM送付先に `{{webinar_url}}` としてPeatixのURLを挿入
3. SNS・HP・メール署名にPeatixのURLを掲載
4. 自動メール（前日リマインダー・1時間前リマインダー）を Peatix の「メール配信」機能でスケジュール設定

---

### 安定フェーズ（月3回以上・参加者累計100名超）: 自社ホストに移行する

**移行を検討するタイミング:**
- 月2〜3回の開催が定常化した
- Peatixのブランド感がオーナーブランドと乖離してきたと感じる
- A/Bテストや細かいCTA最適化をしたい
- メール自動化を完全にコントロールしたい

**移行時の準備:**
- landing-page.html を VPS に配置（工程7以降で実施）
- Webhook エンドポイント実装（申込データの自動受取）
- Gmail API / SendGrid での自動メール送信パイプライン構築
- Peatixから自社ホストへの切替を既存参加者にアナウンス

---

## まとめ

| フェーズ | 採用 | 理由 |
|---|---|---|
| **今すぐ（MVPフェーズ）** | **Peatix** | 即日公開・Peatix内集客・管理コスト最小 |
| **安定化後（3〜6ヶ月後）** | **自社ホスト移行** | ブランド統一・自動化・A/Bテスト・CTA最適化 |

> **結論: まずはPeatixで動かして「需要の検証」を行い、手応えが得られたら自社ホストへ移行する。この順序が最もリスクが低くスピードが速い。**
