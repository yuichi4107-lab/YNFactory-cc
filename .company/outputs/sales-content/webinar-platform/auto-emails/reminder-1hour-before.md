# 開催1時間前リマインダーメール

## 差し込み変数一覧

| 変数 | 内容 |
|---|---|
| `{{name}}` | 申込者の氏名 |
| `{{company_name}}` | 会社名 |
| `{{webinar_date}}` | ウェビナー開催日時（例: 2026年6月17日（水）19:00〜20:30） |
| `{{zoom_url}}` | ZoomミーティングURL |
| `{{handout_url}}` | 持ち帰り資料ダウンロードURL（当日後に送付） |
| `{{consult_booking_url}}` | 無料個別相談予約URL |

---

## 件名

```
【本日18:00開始・1時間前】Zoom URLはこちらです
```

> 件名の「18:00」は開始1時間前の時刻に合わせて変更する。
> （19:00開催なら「18:00」、14:00開催なら「13:00」）

## 送信タイミング

- **開催1時間前に送信**（例: 19:00開催なら18:00送信）
- Peatix の「参加者へのメール配信」→「スケジュール送信」で設定
- 送信者名: `中田 Yuichi（YN Factory）`
- 送信元アドレス: `info@ynfactory.online`

## 運用メモ

- このメールは短く、Zoom URL が素早く見つかることを最優先とする
- 開催直前なのでリンクは Zoom URL だけでよい（他の情報は不要）
- Peatix からの一括送信の場合: 参加者全員に送信。キャンセル者には自動的に送らない設定にする
- 件名に「1時間前」「Zoom URL」を含めることで開封率が上がる
