# 1時間前リマインダーメール（reminder-1h）

> **送信タイミング**: 予約の1時間前に自動送信
> **目的**: 直前の確認。Zoom URLを再提示してスムーズな入室を促す。シンプルに短く。

---

## 件名

```
【1時間後】個別相談 開始のお知らせ
```

---

## 本文

```
{{invitee_full_name}} 様

本日の個別相談まであと1時間です。
お会いできることを楽しみにしています。

──────────────────────────────
Zoom 参加リンク: {{zoom_join_url}}
──────────────────────────────

開始時間の 5 分前からお待ちしています。

それでは、本日もよろしくお願いいたします。

YN Factory 代表
国家資格キャリアコンサルタント
info@ynfactory.online
```

---

## Calendly への設定手順

1. Event Type 編集 → 「**Notifications and Cancellation policy**」タブ
2. 「**Reminders**」セクション → 「**+ Add a reminder**」をクリック
3. 「**Email**」を選択
4. タイミング: **1 hour before**
5. 件名・本文を上記の内容に設定

> **注**: リマインダーは1件目（24時間前）と2件目（1時間前）を合わせて設定する。
> Calendly の有料プランでは複数のリマインダーを設定できる。
> 無料プランでは1件のみの場合は「24時間前」を優先して設定する。
