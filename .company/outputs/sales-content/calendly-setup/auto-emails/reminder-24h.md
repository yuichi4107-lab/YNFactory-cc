# 24時間前リマインダーメール（reminder-24h）

> **送信タイミング**: 予約の24時間前に自動送信
> **目的**: 当日の無断キャンセルを減らす + 予約者に事前準備を促す

---

## 件名

```
【明日開催】個別相談リマインダー — {{event_date_time}} のご確認
```

---

## Calendly への設定手順

1. Event Type 編集 → 「**Notifications and Cancellation policy**」タブ
2. 「**Reminders**」セクション → 「**+ Add a reminder**」をクリック
3. 「**Email**」を選択
4. タイミング: **24 hours before**
5. 件名・本文を上記の内容に設定

---

## 差し込み変数一覧

| 変数 | 意味 |
|------|------|
| `{{invitee_full_name}}` | 予約者の氏名 |
| `{{event_date_time}}` | 予約日時（例: 2026年5月10日 14:00 JST） |
| `{{event_date}}` | 予約日（例: 2026年5月10日） |
| `{{zoom_join_url}}` | Zoom 参加 URL |
| `{{cancel_url}}` | キャンセルリンク |
