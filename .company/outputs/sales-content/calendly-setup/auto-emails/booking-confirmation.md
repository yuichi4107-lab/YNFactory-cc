# 予約確認メール（booking-confirmation）

> **送信タイミング**: 予約完了直後に自動送信
> **差し込み変数**: Calendly が自動挿入する変数を使用（`{{invitee_full_name}}` 等）
> **送信元**: Calendly 経由（メール設定で info@ynfactory.online を表示名に設定）

---

## 件名

```
【YN Factory】30分個別相談 ご予約ありがとうございます（{{event_date_time}}）
```

> **Calendly の変数**:
> - `{{event_date_time}}` → 予約日時（例: 2026年5月10日（日）14:00〜14:30 JST）
> - Calendly の設定画面で該当の変数名を確認して使用すること

---

## Calendly への設定手順

1. Event Type 編集 → 「**Notifications and Cancellation policy**」タブ
2. 「**Confirmation**」セクションの「**Invitee**」の編集ボタンをクリック
3. 「**Custom message**」を ON にする
4. 上記の件名・本文をコピーして貼り付ける

> **注意**: Calendly の無料プランでは本文のカスタマイズが制限される場合がある。
> カスタマイズできない場合は、Calendly 標準のメールに加えて、
> Zapier/Make などで Gmail から追加メールを自動送信する方法を検討する。
> 詳しくは `integration-with-other-tools.md` を参照。

## 差し込み変数一覧

| 変数 | 意味 | Calendly での変数名 |
|------|------|---------------------|
| `{{invitee_full_name}}` | 予約者の氏名 | `{{invitee.full_name}}` |
| `{{event_date_time}}` | 予約日時 | `{{event.start_time}}` |
| `{{zoom_join_url}}` | Zoom 参加 URL | Zoom 連携で自動挿入 |
| `{{cancel_url}}` | キャンセルリンク | Calendly 自動生成 |
| `{{company_name}}` | 会社名（Q1の回答） | カスタム質問の回答として取得 |
