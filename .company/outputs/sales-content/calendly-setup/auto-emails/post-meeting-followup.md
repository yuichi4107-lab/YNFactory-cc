# 商談後フォローアップメール（post-meeting-followup）

> **送信タイミング**: 30分 Zoom 商談終了後、**30分以内にオーナーが手動で送信**
> （Calendly 自動送信ではなく、Gmail で送る）
>
> **3パターンの使い分け**:
> - **Pattern A（即決）**: 商談中に「契約したい」「進めたい」という意思表示があった場合
> - **Pattern B（検討）**: 「一度社内で相談する」「少し時間をください」という場合
> - **Pattern C（見送り）**: 「今回は見送る」「タイミングが合わない」という場合
>
> 差し込み変数: `{{customer_name}}` `{{plan_recommendation}}` `{{plan_price}}` は送信前に書き換えること。

---

## Pattern B — 検討パターン（1週間後フォローアップ）

> **キャリコン差別化ポイント**: 検討期間中も「人を活かす AI 活用」の視点で寄り添う姿勢を示す。
> L1/L2/L3 比較資料を添付し、社内での比較検討をしやすくする。

### 件名

```
【YN Factory】本日のご相談 まとめ資料 + フォローアップのご案内
```

### 本文

```
{{customer_name}} 様

本日はお時間をいただき、誠にありがとうございました。

ご検討いただけるとのこと、ありがとうございます。
社内でのご相談・検討に役立てていただけるよう、
本日の内容をまとめた資料をお送りします。

──────────────────────────────
■ 本日の対話のポイント（オーナーがまとめ）
──────────────────────────────

・ご状況: {{summary_situation}}
  （例: 製造ラインの記録作業が属人化しており、退職リスクが高い状態）

・特にご関心が高かった点: {{key_interest}}
  （例: 採用コスト削減 / 補助金の活用 / 社員のAIスキルアップ）

・ご提案プラン: {{plan_recommendation}}（{{plan_price}}/月）

──────────────────────────────
■ 添付・参考資料
──────────────────────────────

1. プラン比較表（L1/L2/L3）
   → 3プランの違い・費用・サービス内容をA4 1枚にまとめました

2. AI活用事例集（地方中小企業向け）
   → 同規模の企業が実際にどう AI を活用しているかの事例をご紹介

3. 補助金活用概要パンフレット
   → IT導入補助金・小規模事業者持続化補助金の概要
     ※補助金の採択は外部機関の審査のため保証はできませんが、
       活用できる可能性がある場合にご紹介しています

4. AI活用プロンプト集（今すぐ使えるもの）
   → 社内で今日から試せるプロンプトをまとめました。無料でお使いください

──────────────────────────────
■ キャリアコンサルタントからの一言
──────────────────────────────

https://calendly.com/yn-factory/30min-consult
```

## 差し込み変数一覧

| 変数 | 意味 | 使用パターン |
|------|------|------------|
| `{{customer_name}}` | 顧客の会社名または氏名（例: 山田社長 / 株式会社〇〇 山田様） | A / B / C |
| `{{plan_recommendation}}` | 推奨プラン名（例: L2 スタンダード顧問） | A / B |
| `{{plan_price}}` | プランの月額（例: 月額 8万円） | A / B |
| `{{summary_situation}}` | 今日のヒアリングで把握した現状の要約（1〜2行） | B |
| `{{key_interest}}` | 最も関心が高かった課題・テーマ（1〜2点） | B |
