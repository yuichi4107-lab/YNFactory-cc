# Zoom 自動URL生成連携手順

> **目的**: Calendly と Zoom Pro を連携させ、予約ごとに Zoom URL を自動生成する。
> **前提**: Zoom Pro アカウント（$14.99/月）が契約済みであること。
> **所要時間**: 約10分

---

## 連携のメリット

| メリット | 説明 |
|---------|------|
| URL 自動生成 | 予約ごとに固有の Zoom URL が自動生成される（毎回同じ URL を使い回さない） |
| 確認メール自動挿入 | 予約確認メール・リマインダーに Zoom URL が自動的に含まれる |
| パスコード自動付与 | セキュリティのためパスコードを自動設定できる |
| Google Calendar 連携 | Google Calendar の予定にも Zoom URL が自動追加される |

---

## Step 1: Calendly と Zoom を連携する

### 操作手順

1. Calendly にログイン → 右上アバター → 「**Integrations & apps**」
2. 「**Video conferencing**」セクションを探す
3. 「**Zoom**」を見つけて「**Connect**」をクリック
4. Zoom のログイン画面が開く → **YN Factory の Zoom Pro アカウント**でログイン
5. Calendly からのアクセス許可画面 → 「**Allow**」をクリック
6. 「Connected」と表示されれば連携完了

---

## Step 2: Event Type に Zoom を設定する

Event Type（個別相談 30分）ごとに Zoom 連携を有効にする。

### 操作手順

1. Event Type の編集画面を開く
2. 「**Location**」（場所）の設定欄を探す
3. 「**Zoom**」を選択する
4. 「Zoom meeting links are automatically generated for each event」と表示されれば設定完了

> **注意**: 「Location」に固定の Zoom URL を貼り付ける方法もあるが、
> それだと全員同じ URL になりセキュリティリスクがある。
> **自動生成（Zoom 連携）の方法を強く推奨する。**

---

## Step 3: パスコードの設定（推奨）

Zoom の管理画面で自動生成 URL にパスコードを設定する。

### Zoom 管理画面での操作

1. `https://zoom.us/profile/setting` にアクセス
2. 「**セキュリティ**」タブを開く
3. 「**ミーティングパスコード**」の設定を確認:
   - 「スケジュールされたミーティングにはパスコードが必要です」→ ON
   - 「参加 URL にパスコードを埋め込む」→ ON
     （リンクをクリックするだけでパスコード入力が不要になる）

---

## Step 4: 自動録画の設定（推奨）

商談の振り返り・品質向上のために自動録画を設定する。

### Zoom 管理画面での操作

1. `https://zoom.us/profile/setting` にアクセス
2. 「**記録**」タブを開く
3. 「**クラウドへの自動記録**」を ON にする
4. 「ホストが参加したとき」を選択
5. 「Save」をクリック

> **録画の活用**:
> - 商談後のフォローアップメール作成時に振り返りとして活用
> - トーク改善のセルフレビュー用途
> - 商談相手には「録画を行っています。ご了承ください」と冒頭で伝えること

> **クラウド保存の容量**:
> Zoom Pro の無料クラウドストレージは 1GB（旧プラン）または無制限（新プラン）。
> 商談が月10件を超えるようなら、不要な録画を定期的に削除するか
> ローカルダウンロード後に削除する運用にする。

---

## Step 5: テスト予約で確認する

1. Calendly の予約ページから自分でテスト予約を行う（別メールアドレスで）
2. 受信した確認メールに Zoom URL が含まれているか確認
3. Zoom URL をクリックして入室できるか確認
4. パスコードなしでスムーズに入室できるか確認

---

## トラブルシューティング

| 症状 | 原因 | 対処 |
|------|------|------|
| Zoom と連携できない | Zoom アカウントの権限不足 | Zoom の管理者アカウントで接続を試みる |
| 確認メールに Zoom URL が含まれない | Event Type の Location が未設定 | Step 2 を再確認して「Zoom」を選択 |
| Zoom URL が開けない | パスコードの設定ミス | Zoom 管理画面のセキュリティ設定を確認 |
| 自動録画が開始されない | 録画設定が未完了 | Step 4 の手順を再確認 |

---

## 手動 URL 運用（Zoom 連携が使えない場合の代替）

Zoom 連携が設定できない場合や、Calendly 無料プランで制限がある場合の代替手順:

1. Zoom でミーティングを**スケジュール**して固定 URL を発行する
2. Calendly の Event Type の Location に「**Custom Location**」で Zoom URL を貼り付ける
3. 予約確認メールに手動でその URL を記載する

> **デメリット**: 全員が同じ URL を使うため、部外者が入室するリスクがある。
> パスコードを設定して URL + パスコードを確認メールに記載すること。
> 早期に Zoom 自動連携に移行することを推奨する。
