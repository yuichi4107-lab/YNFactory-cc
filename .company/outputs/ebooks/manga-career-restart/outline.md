## ■ 第一幕：崩壊（日常の喪失）

### 第1話「陽性反応と、描いていた未来」（9P + コラム1P / 27コマ）
**テーマ**: 妊娠の喜び、そして忍び寄る現実

- 事務職として真面目に働くミサキの日常。子供が欲しいと思っていた
- 検査薬の陽性反応 → 無条件の喜び！涙が出る
- 夫に報告「できたよ…！」「本当に！？」→ 抱き合う。幸せの絶頂
- 上司に報告「おめでとう。産休の手続きしようか」→ 表面上は円満
- 同僚の微妙な反応「また産休か…」（聞こえるか聞こえないか）
- 幸せなはずなのに、日が経つにつれ現実が見えてくる
- 夜中、スマホで「産休 復帰 不安」と検索するミサキ
- 「戻れるよね…？」— 喜びの裏に、少しずつ不安の影

**コラム①**:「出産とキャリアの分岐点」
- 日本の女性の約5割が第一子出産を機に離職するデータ
- 「マミートラック」の現実
- 制度はあっても"使える空気"があるかは別問題

**読者の感情**: 共感 → 「この不安、わかる」

### 第2話「保育園落ちた」（9P + コラム1P / 27コマ）
**テーマ**: 制度の壁にぶつかる

- 産休・育休を経て、復帰準備を始めるミサキ
- 保育園の申請書類の山。必死に書く
- 結果：不承諾通知。「落ちた…」
- 会社に相談「在宅勤務はできませんか？」→「うちにはそういう制度がないんだよね」
- 育休延長を申請するも、上司の態度が微妙に変わる
- 「仕事も育児も中途半端…」
- 夫は協力的だが帰りが遅い。実家は遠方。ワンオペの現実
- 追い詰められていくミサキ

**コラム②**:「保育園問題と"自己責任"の構造」
- 待機児童問題の現状
- 「女性活躍推進」と言いながら保育インフラが追いついていない矛盾
- 会社に育児支援を押し付ける政策の限界

**読者の感情**: 怒り・共感 → 「これ、社会の問題じゃん」

- 結局、退職を決断するミサキ

- 最終出社日。デスクを片付けながら涙をこらえる
- 同僚「また戻っておいでよ」（社交辞令だとわかっている）
- 会社を出る。振り返る。もう自分の居場所はない
- 家に帰る。子供の泣き声。「ただいま…」
- 名刺がなくなった自分。肩書きがない自分
- 「私、何者なんだろう」

**コラム③**:「キャリア・アイデンティティの喪失」
- 退職＝キャリアの終わりと感じてしまう心理
- 「会社員」以外の自分を想像できない日本社会の問題
- 本当は「会社員」は働き方の一つに過ぎない

**読者の感情**: 胸が苦しい → 「この先どうなるの」

## ■ 第二幕：暗闘（もがく日々）

**テーマ**: 育児と経済不安の二重苦

- 退職後の日常：授乳→おむつ→寝かしつけ→また授乳のループ
- 共働き前提だった家計。通帳を見て青ざめる
- 夫が帰宅「大丈夫？」「うん…大丈夫」（大丈夫じゃない）
- 夜中の授乳。暗い部屋。スマホだけが光る

- 「在宅 仕事 子育て」で検索 → 内職、データ入力…時給の低さに絶望
- 「事務しかやったことない私に、何ができるの…」
- 子供の寝顔を見ながら涙

**コラム④**:「"何もできない"は本当か？」
- 事務職スキルの棚卸し（実は汎用性が高い）
- 「自分には何もない」と感じる心理のメカニズム
- 可能性を狭めているのは自分自身かもしれない

**読者の感情**: 辛さのピーク → でもコラムで少し救われる

### 第7話「毎日投稿という戦い」（9P + コラム1P / 27コマ）
**テーマ**: 地道な努力 — 華やかさの裏側

- Instagram開始。毎日AIと一緒に投稿を作る
- 最初は反応ゼロ。「誰にも届いてない…」
- 曖昧な指示でAIに作らせる → 微妙な投稿 → 「なんか違う…」
- タクヤ「AIが悪いんじゃなく指示が曖昧なんです。具体的に伝えれば具体的に返ってくる」
- 言語化を意識し始める → 投稿の質が変わる
- でも子供の体調不良で3日間投稿できない → フォロワー減
- 「やっぱり育児しながらは無理なのかな…」
- タクヤ「完璧じゃなくていい。止まっても、また始めればいい」
- 再開。少しずつ、でも確実に積み上げる

**コラム⑦**:「"続ける"というキャリア戦略」
- 育児中のキャリア構築は"完璧"を目指すと折れる
- 「細く長く」が最強の戦略
- 中断しても再開できる仕組みの重要性

**読者の感情**: リアリティ → 「きれいごとじゃない、だからこそ信頼できる」

- 金額は小さい。でも手が震える
- 「これ…私が稼いだお金…？」

- 自分で考えて、自分で作って、自分で稼いだ

- 通帳を見る。前とは違う気持ちで

- 収入を得る方法は就職だけではない
- 副業・フリーランス・コンテンツビジネスの現実
- 会社に頼る/国に頼るのではなく、自分で選択肢を作る時代

**読者の感情**: 感動 → 目頭が熱くなる

### 第10話「私のキャリアは、私が決める」（9P + コラム1P / 27コマ）
**テーマ**: 着地 — 核心メッセージの体現

- 初収益から数ヶ月。収入は少しずつ安定してきている
- ふと、退職届を出した日を思い出す
- あの日「何者でもなくなった」と思った
- 今は違う。肩書きがなくても、自分で立っている
- ママ友に聞かれる「今何やってるの？」→ 「…自分でちょっとね」（まだうまく説明できない）
- でもそれでいい。誰かに説明できる肩書きなんていらない
- タクヤ「ミサキさん、最初に言ったこと覚えてますか？"事務しかできない"って」
- ミサキ「…言いましたね（笑）」
- タクヤ「今のミサキさんは、自分の可能性を自分で証明しました」
- 夜、子供を寝かしつけた後、PCを開く
- 画面にはClaudeと次の企画のやりとり
- **最後のモノローグ**:
  「会社が私の席を用意してくれなかったのは、不幸なことだと思っていた」
  「でも今は思う。あの日退職届を出したから、私は"自分の席"を見つけられた」
  「大事なのは、誰かに用意してもらうことじゃない」
  「自分の可能性を、自分で決めつけないこと」

**コラム⑩**:「おわりに — キャリアコンサルタントとして伝えたいこと」
- ミサキは特別な人ではない。特別なスキルも学歴もなかった
- 変わったのは「自分にはできない」という思い込みを手放したこと
- 国の制度が変わるのを待たなくていい。会社が変わるのを待たなくていい
- あなたのキャリアは、あなたが決めていい
- 最初の一歩は、思っているより小さくていい

**読者の感情**: 感動 → 「私もやってみよう」
