# 目次・各話構成（最終版）

> 全10話 / 100ページ / 約300コマ
> 登場人物: ミサキ（主人公・32歳・元事務職ママ）、タクヤ（メンター・40代・元営業・AIコンサル）

---

## ■ 起：現状と出会い

### 第1話「退職、そして何もない日々」（10P / 30コマ）
**テーマ**: ミサキの現状と焦り
**成長段階**: 第0段階（ChatGPTに質問するだけ）

- 保育園の不承諾通知を見て呆然とするミサキ
- 会社に在宅勤務を相談するが「制度がない」と断られる
- 退職届を出す（回想）
- 日常：授乳→おむつ→寝かしつけ→また授乳のループ
- 夫が遅く帰宅「お疲れ」「うん…」のすれ違い
- 通帳を見て「このままだとまずい…」
- 夜中の授乳、暗い部屋でスマホを見るミサキ（孤独感）
- ChatGPTに「離乳食 レシピ」と聞いている描写（AIは"質問するもの"という認識）

**読者の感情**: 共感・同情 → 「この先どうなるんだろう」

---

### 第2話「画面の向こうの先輩」（10P / 30コマ）
**テーマ**: タクヤとの出会い（ウェビナー）
**成長段階**: 第0段階 → 第1段階への橋渡し

- 夜中の授乳中、SNSで「非エンジニアでもAIで月10万稼いだ方法」というウェビナー広告を発見
- 「怪しい…でも気になる」半信半疑でポチる
- 無料ウェビナー当日：子供を寝かしつけてからPC前に座るミサキ
- タクヤ登場「僕も元々は普通の営業マンでした。WordとExcelしか使えなかった」
- 「ChatGPTに質問するだけで終わってませんか？」→ ミサキ「ドキッ」
- タクヤ「AIは質問に答えてくれるだけじゃない。"作業をしてくれる"んです」
- 「大事なのはプログラミングスキルじゃない。"何をやりたいか"です」
- ウェビナー終了後、有料プログラムの案内を見て悩むミサキ
- 通帳を見る → 夫の寝顔を見る → 「やってみよう」（決意）

**読者の感情**: ワクワク → 「この人について行ったらどうなるんだろう」

## ■ 承：最初の一歩と成長

### 第3話「はじめてのClaude Code」（10P / 30コマ）
**テーマ**: 3大壁の解消 + 言語化の重要性 + Claude Codeの形態説明
**成長段階**: 第1段階の入口（AIに作業をさせる）

- 有料プログラム初日：オンラインでタクヤと1対1
- タクヤ「まず Claude Code っていうツールを使ってみましょう」
- **壁①** ミサキ「プログラミングできないと使えないんじゃ…」
  - タクヤ「僕も営業出身。日本語で話しかけるだけでいいんです」
- **壁②** Claude Code CLI画面を見て「え、この黒い画面…無理…」
  - タクヤ「デスクトップアプリもWeb版もあります」（Claude Codeの形態を説明）
  - デスクトップアプリに切り替え → 「あ、普通のアプリみたい」
- **壁③** ミサキ「英語じゃないと動かないんですか？」
  - タクヤ「日本語で全部できますよ。やってみて」→ 日本語で返ってきて驚く
- **タクヤの失敗談**：「僕も最初はターミナルからCLIで使ってて、自分で作業する部分が多かった。でもIDE拡張機能を使うようになったら、そこもAIがやってくれるようになった」
- **言語化の教え**：タクヤ「まず何をしたいか、言葉にしてみてください」
  - 「"いい感じにして"じゃダメ。"誰に向けて、何を、どんなトーンで"まで伝えないと」
- ミサキ「育児のことなら…Instagramで発信とか？」
- AIにアカウントのコンセプトを考えてもらう → 「え、これ私が考えたみたい！」
- 子供が泣いて中断 → タクヤ「大丈夫、自分のペースでやりましょう」

**読者の感情**: 「自分にもできそう」→ 3つの壁が解消される安心感

---

### 第4話「フォロワー100人の壁」（10P / 30コマ）
**テーマ**: 試行錯誤と言語化の実践
**成長段階**: 第1段階（AIに作業をさせる）

- 毎日の投稿をAIと一緒に作るルーティンができる
- **言語化の失敗**: 曖昧な指示で投稿文を作らせる → 「こんなの頼んでない…」
  - タクヤ「AIが悪いんじゃなくて、指示が曖昧だったんです。具体的に伝えれば具体的に返ってくる」
- 指示の出し方を改善 → 成果物の質が上がる → 「言葉にするって大事なんだ」
- タクヤにチャットで相談「いいねが全然つかないんですけど…」
- タクヤ「Claude Codeにエンゲージメント分析させてみて」
- AIが改善提案 → 育児ネタで共感を集める投稿がバズる（小バズ）
- フォロワー100人突破！「やった！！」タクヤに報告
- タクヤ「おめでとう！最初の100人が一番大変なんですよ」
- フォロワーからDM「参考になります！」→ 承認欲求が満たされる
- 「もっとやりたい」という気持ちが芽生える

**読者の感情**: 「おお、成果出てきた」→ 言語化の重要性が実感できる

### 第5話「やりたいことが止まらない」（10P / 30コマ）
**テーマ**: 欲張りすぎて破綻 → 第2段階への伏線
**成長段階**: 第1段階の限界

- Instagram運用が軌道に乗り、アフィリエイト収入が少し入る
- 「ブログもやりたい」「ハンドメイド販売も」「電子書籍も」
- Claude Codeに次々相談 → AIは全部「できますよ」と答える
- 複数プロジェクトを同時進行し始める
- スプレッドシートで管理しようとするが追いつかない
- 投稿の予定を忘れる、ブログの更新が止まる
- 子供の体調不良で1週間すべてストップ
- 「やっぱり私には無理なのかな…」と落ち込むミサキ
- タクヤに泣きながら相談「全部中途半端で…」
- タクヤ「大丈夫。AIは作業はしてくれる。でも今のミサキさんに足りないのは、"どう回すか"のビジョンです」（次回への引き）

**読者の感情**: 「あー、広げすぎた…」→ どう乗り越えるのか気になる

## ■ 転：ブレイクスルー

### 第6話「AIに会社をつくらせてみた」（12P / 36コマ）
**テーマ**: 仮想会社という発想の転換 + 3つの鉄則
**成長段階**: 第2段階への突入（自分のビジョンをAIで実現する）

- タクヤ「ミサキさん、会社って社長が全部やると思いますか？」
- ミサキ「え？…違いますよね、部下がいて…」
- タクヤ「そう。じゃあClaude Codeを部下にして、会社を作ったらどうですか？」
- タクヤが自分の仮想会社の画面を見せる → ミサキ目を丸くする
- タクヤ「東大生を想像してください。ものすごく優秀でしょ？でも、子供が東大生に指示を出しても大した結果は出ない。大人が的確に指示を出すから、東大生の能力が活きるんです」
- ミサキ「つまり…AIの使い方じゃなくて、使う私が成長しないといけない…？」
- タクヤ「そう。でも今のミサキさんはもう"作業をさせる"はできてる。次は"ビジョンを実現する"番です」

**仮想会社の3つの鉄則（タクヤが教える）:**
- 鉄則①「各エージェントの役割を明確にする。秘書、マーケ、制作…誰が何をやるか決める」
- 鉄則②「作業が終わったら必ず"どこまでやったか"を記録させる。AIは記憶を持たないから、引き継ぎノートが必要」
- 鉄則③「自分で作業しない。AIが自分で判断して進められるようにルールを決める。社長が作業を始めたら、それは社長じゃなくて作業員です」

- Claude Codeに「仮想の会社を作りたい」と相談
- 司令塔（CEO）の下に秘書・マーケ・制作…役割を決めていく
- 「秘書に毎朝TODOをまとめてもらう」→ 実際に動く！
- 「マーケ部にInstagramの投稿計画を作らせる」→ できた！
- 「私、社長になった…？」（目がキラキラ）
- 夫が帰宅「何やってるの？」「…会社つくった」「は？」

**読者の感情**: 「これはすごい！」→ 最大のワクワクポイント + 東大生の例えで本質を理解

---

### 第7話「ひとり社長の仮想オフィス」（10P / 30コマ）
**テーマ**: 仮想会社の日常 + 「判断する」ことの本質
**成長段階**: 第2段階の実践

- 朝、子供にミルクをあげながらスマホで「秘書」からの朝ブリーフィングを確認
- 今日のタスク一覧が整理されている
- Instagram投稿 → 「マーケ部」が原稿を用意済み
- ブログ記事 → 「制作部」が下書き済み
- 自分は最終チェックと「承認」だけ
- タクヤとの定期ミーティング「順調そうですね」「はい！」
- タクヤ「社長の仕事は"判断すること"です。作業は全部AIに任せていい」
- 「社長の仕事って、判断することなんだ」という気づき
- 子供と公園に行く余裕ができる
- 公園のベンチでスマホチェック → 問題なし
- 「育児しながら会社回ってる…」（静かな感動）

**読者の感情**: 「こんな働き方あるのか」→ 具体的なイメージが湧く

## ■ 結：成果と着地

### 第8話「収入の柱が増えていく」（10P / 30コマ）
**テーマ**: 成果が数字に表れる
**成長段階**: 第2段階の成果

- Instagram: フォロワー5,000人、月のアフィリエイト収入○万円
- ブログ: PV数が伸び始め、広告収入が入る
- 電子書籍: 育児ノウハウ本を出版、じわじわ売れる
- すべてAIが下準備 → 自分は方向性の判断と最終確認
- 通帳を見て「あれ、パート代くらいになってる…」
- タクヤ「ここからが本番ですよ。仕組みができたら、あとはスケールするだけ」
- さらにクラウドソーシングでライティング案件を受注
- 「事務しかできないと思ってたのに」
- 夫「最近なんか楽しそうだね」「うん、ちょっとね」
- 月の収入グラフが右肩上がりになる演出

**読者の感情**: 「結果出てる！」→ 説得力・再現性を感じる

### 第9話「壁と、乗り越え方」（8P / 24コマ）
**テーマ**: AIだけでは解決できないこと → 核心メッセージの体現
**成長段階**: 第2段階の深化（人間の判断の質が問われる）

- AIが生成した文章がそのまま使えないケース
- 「AIに任せすぎて自分の言葉がない」と気づく
- フォロワーから「最近の投稿、なんか機械的…」というコメント
- 落ち込むミサキ → タクヤに相談
- タクヤ「AIは道具です。ミサキさんの経験や想いは、ミサキさんにしか書けない」
- タクヤ「AIは東大生より優秀です。でも"何を伝えたいか"を決めるのは人間の仕事です」
- 自分の育児体験を自分の言葉で書く → AIにはそれをベースに展開してもらう → 反響が大きい
- 「AIに頼るところと、自分でやるところの線引き」という気づき
- 技術的な壁：Claude Codeがエラーを出す → タクヤ「完璧じゃなくていい。動けばいい」

**読者の感情**: リアリティ・信頼感 → 「きれいごとだけじゃない」

### 第10話「もう、戻らなくていい」（10P / 30コマ）
**テーマ**: 新しい人生の形 → 核心メッセージの着地
**成長段階**: 第2段階の完成

- ある日の朝、仮想会社の「秘書」から月次レポートが届く
- 収入が安定し、会社員時代の手取りに近づいている
- 子供が「ママ」と初めて呼ぶシーン（成長の象徴）
- タクヤとのミーティング「ミサキさん、もう立派な経営者ですよ」
- ミサキ「タクヤさんのおかげです」タクヤ「いえ、行動したのはミサキさんです」
- タクヤ「AIは最初から優秀だった。変わったのはミサキさんの方です」
- 夫と夕食中「あのさ、もう会社に戻らなくていいかも」
- 夫「…え？」→ 収入の話をする → 「すごいな」
- 「私、事務しかできないと思ってた。でも大事なのはスキルじゃなかった」
- 子供を抱きながらPCを開くミサキの後ろ姿
- **最後のモノローグ**:
  - 「AIは何でもできる。でも"何をするか"を決められるのは、人間だけだ」
  - 「特別なスキルはいらない。必要なのは、"自分は何がしたいか"を持つことと、最初の一歩を踏み出す勇気だけ」
- エピローグ：SNSで「非エンジニアのためのAI活用講座」を始めるミサキ

**読者の感情**: 感動・「自分もやろう」→ 行動喚起
