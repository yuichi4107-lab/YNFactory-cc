# 第3話「はじめてのClaude Code」

---

## 初回セッション

有料プログラムに申し込んで3日後。

ユウくんを昼寝させたタイミングで、ミサキはPCの前に座った。

Zoomが繋がる。タクヤの柔らかい笑顔が画面に映った。

「ミサキさん、はじめまして。タクヤです。今日からよろしくお願いします」

「よ、よろしくお願いします…」

緊張で声が上ずる。

「まず聞いてもいいですか？ ミサキさんは、何をやりたいんですか？」

「え…えっと…副業で稼ぎたい、です」

「もう少し具体的に言えますか？ 何を使って、誰に向けて、どうやって？」

「……わかりません」

「大丈夫です。それを一緒に見つけていきましょう。今日はまず、一つのツールに触ってもらいます」

---

## 壁①：プログラミングできないと無理？

「今日使うのは、Claude Code というツールです」

「クロード…コード？」

ミサキの顔が曇った。

「あの…"コード"って、プログラミングのことですよね？ 私、プログラミングなんて一行も…」

タクヤは笑った。

「ミサキさん、僕もプログラミングできませんよ。10年営業やってただけです。Claude Code は"コード"って名前がついてますけど、実際にやることは日本語で話しかけるだけです」

「日本語で…？」

「はい。やってみればわかります。まず、インストールしてみましょう」

---

## 壁②：黒い画面が怖い

タクヤの指示に従って、ミサキはClaude Codeをインストールした。

ターミナルが開く。黒い背景に白い文字。カーソルが点滅している。

「……無理です」

ミサキは素直に言った。

「この画面、プログラマーの人が使うやつですよね。私には絶対無理です」

タクヤは予想していたように頷いた。

「そう思いますよね。僕も最初はそうでした。でも安心してください。Claude Code は色んな使い方ができるんです」

タクヤが画面共有を切り替えた。

「まず、今見てもらった黒い画面。これはCLIっていう、ターミナルから直接使う方法です。これが一番元祖の使い方」

「次に——」タクヤがアプリを切り替える。「これがデスクトップアプリ。WindowsでもMacでも使えます。普通のアプリと同じ見た目でしょ？」

画面には、チャットアプリのようなきれいなインターフェースが映っていた。

「あ…これなら普通のアプリみたいですね」

「そうなんです。他にもブラウザから使えるWeb版もあります。スマホからでもアクセスできる」

タクヤがまとめを見せた。

「CLI、デスクトップアプリ、Web版、あとIDEの拡張機能。全部同じClaude Codeです。自分が使いやすいものを選べばいい」

「じゃあ、私はデスクトップアプリでいいですか？」

「もちろん。それで始めましょう」

---

## 壁③：英語じゃないと動かない？

デスクトップアプリを起動した。きれいなチャット画面が表示される。入力欄にカーソルが点滅している。

「あの…これ、英語で入力しないとダメですか？ AIって英語の方が精度がいいって聞いたことがあって…」

「日本語で全然大丈夫です。やってみましょう。何でもいいので、日本語で話しかけてみてください」

ミサキはおそるおそるキーボードを打った。

「こんにちは」

Enterキーを押す。

数秒後、画面にAIの返答が表示された。

「こんにちは！何かお手伝いできることはありますか？」

「あ…日本語だ。ちゃんと日本語で返ってきた…！」

タクヤは笑った。

「ね？ プログラミングもいらない、黒い画面も使わなくていい、英語もいらない。日本語で話しかけるだけです」

---

## タクヤの失敗談

「ちなみに、僕自身の失敗談を一つ話していいですか？」

「はい」

「僕がClaude Codeを使い始めた頃、IDEっていうコードを書くためのアプリのターミナルから、CLIで動かしてたんです」

「さっきの黒い画面ですか？」

「そうです。それで、AIにファイルを作ってもらったり、コードを書いてもらったりしてたんですけど…結局、出来上がったものを自分でコピーして、自分でファイルに貼り付けて、自分で保存して、っていう作業を自分でやってたんですよ」

「え、それってAIに作業させてるのに、結局自分で作業してるってことですか？」

「まさにそれです」タクヤは苦笑いした。「で、ある時気づいたんです。IDEの拡張機能にClaude Codeがあるって」

「拡張機能？」

「アプリの中にClaude Codeを組み込めるんです。そうすると、AIがファイルを直接編集してくれる。保存もしてくれる。差分も見せてくれる。僕がやってた"自分で作業する"部分を、全部AIがやってくれるようになったんです」

「へぇ…！使い方一つでそんなに変わるんですね」

「そうなんです。だから最初から完璧な使い方をする必要はない。使いながら少しずつ良くなっていけばいいんです」

---

## 言語化の第一歩

「さて、ミサキさん。ここからが本番です」

「はい」

「さっき"副業で稼ぎたい"って言ってましたよね。もう少し具体的に考えてみましょう。何か得意なこと、好きなこと、詳しいことはありますか？」

「得意なこと…。事務作業くらいしか…。あ、でも今は育児のことならたくさん調べてます。離乳食とか、寝かしつけとか」

「いいですね。じゃあ育児の経験を活かして、何かやりたいことはありますか？」

「うーん…Instagramで育児の情報を発信してる人、結構いるんです。私も見てて。ああいうの、やってみたいなって思ったことはあります」

「いいじゃないですか。じゃあ、それをClaude Codeに伝えてみましょう」

「え、何て言えばいいんですか？」

タクヤは真剣な顔になった。

「ここが一番大事なポイントです。Claude Codeに限らず、AIを使う上で最も重要なのは、"自分がやりたいことを言語化すること"です」

「言語化…」

「"いい感じにして"じゃダメなんです。"誰に向けて、何を、どんなトーンで"——そこまで伝えて初めて、AIは具体的に動いてくれる」

「でも、私、まだ何がやりたいかはっきりしてなくて…」

「大丈夫。最初は曖昧でいいんです。AIと会話しながら具体的にしていけばいい。じゃあ、まずはこう聞いてみてください」

タクヤがチャットに打つ文章を教えてくれた。

---

## はじめての「作業」

ミサキがClaude Codeに入力する。

「育児中のママ向けに、Instagramで情報発信をしたいです。アカウントのコンセプトを一緒に考えてもらえますか？ ターゲットは0〜1歳の子供を持つ新米ママで、離乳食や寝かしつけの実体験をベースにした、親しみやすいトーンにしたいです」

Enterキーを押す。

数秒後、AIが動き始めた。アカウント名の候補、プロフィール文の案、投稿のテーマ案、ハッシュタグ戦略…

次々と具体的な提案が画面に表示されていく。

「え…」

ミサキは画面に釘付けになった。

「これ…私が考えたみたいなのが出てきてる…」

タクヤは穏やかに言った。

「質問に答えてもらうのと、作業をしてもらうの、全然違うでしょ？」

「全然違います…！ ChatGPTに"Instagramのやり方教えて"って聞いた時は、一般的な説明が返ってきただけだったのに…」

「そう。"やり方を教えて"は質問。"一緒に考えてほしい"は作業の依頼。同じAIでも、使い方で結果が全く違うんです」

ミサキの目が輝いていた。

---

## 中断、でも大丈夫

その時、隣の部屋からユウくんの泣き声が聞こえた。

「あ、すみません、子供が起きちゃって…」

「全然大丈夫ですよ。ミサキさん、育児しながらやるんですから、自分のペースでやりましょう。Claude Codeは逃げません」

ミサキは少し笑った。

「今日わかったことは3つです」とタクヤが言った。

「1つ目、プログラミングはいらない。2つ目、日本語でできる。3つ目、"やりたいこと"を言葉にすることが一番大事。この3つだけ覚えておいてください」

「はい…！ あの、タクヤさん」

「はい？」

「私、やってみたいです。Instagramの育児アカウント」

タクヤは嬉しそうに笑った。

「いいですね。次回から、本格的に始めていきましょう」

ミサキはPCを閉じて、泣いているユウくんを抱き上げた。

「ユウくん、ママね、ちょっとだけ変わるかもしれないよ」

ユウくんは、ミサキの顔を見て泣き止んだ。
