# 漫画企画書：AIで会社をつくった主婦の話（仮題）

## コンセプト
非エンジニアの元事務職ママが、メンターとの出会いをきっかけにClaude Codeで
Instagram運用 → 副業拡大 → AI仮想会社経営へと成長していくストーリー漫画。

## ターゲット読者
- **メイン**: 30〜40代 男性ビジネスパーソン
- **サブ**: AIに興味はあるが踏み出せていない非エンジニア全般
- **読後感**: 「非エンジニアの自分にもできるかも」という行動喚起

## 核心メッセージ
> AIは東大生より優秀な道具。でも「子供が東大生を使う」のと「大人が東大生を使う」のでは結果が全く違う。
> AIを使ったからといって何でもできるわけではない。最終的に意思決定をするのは人間。
> 大事なのはAIスキルではなく、**「何がしたいか」「発想」「アイデア」「意思決定」**である。

  - 共働き前提の家計だったため経済的な不安あり
  - 「事務しかやったことない自分に何ができるのか」という焦り

- ウェビナー後、有料プログラムに申し込み、タクヤの個別指導でClaude Codeを知る

## 作中で伝える重要概念

### 非エンジニアの3大壁（→ 全部解消できる）
1. **エンジニアじゃないと無理という先入観** → 日本語で話しかけるだけ
2. **CLIの画面が怖い** → デスクトップアプリ、Web版、IDE拡張がある
3. **英語が必要** → 日本語で全部できる

### Claude Codeの形態
| 形態 | 特徴 |
|------|------|
| CLI（ターミナル版） | コマンドラインで操作。元祖 |
| デスクトップアプリ | Mac/Windows対応。GUIで使いやすい |
| Web版（claude.ai/code） | ブラウザから使える |
| IDE拡張機能 | VS Code等の中で使える。ファイル操作も自動化 |

### タクヤの失敗談（IDE活用）
- 最初：IDEのターミナルからCLIで使っていた → 自分で作業する部分が多かった
- 気づき：IDE拡張機能でClaude Codeを使うと、ファイル編集やdiff確認もIDE内で完結
- 結果：作業もAIがやってくれるようになり、一段と効率化

### 言語化の重要性
- やりたいことを言語化することが第一
- 曖昧な指示 → 期待と違う成果物が出てくる
- 具体的に伝えれば具体的に返ってくる
- プログラミングスキルは不要だが「言葉にする力」は必要

### 仮想会社の3つの鉄則
1. **役割の明確化**: 各エージェントに明確な役割を定義する
2. **進捗の記録と引き継ぎ**: 作業終了時に「どこまでやったか・次に何をするか」を記録する
3. **自律実行**: AIが自分で判断して作業を進められるようにルールを定めて、自分は作業しない

### 仮想会社の概念図
```
社長（人間 = ミサキ）
  └── 司令塔エージェント（CEO）
        ├── 秘書エージェント（窓口・TODO管理）
        ├── マーケエージェント（SNS運用）
        ├── 制作エージェント（コンテンツ作成）
        ├── リサーチエージェント（調査）
        └── ...必要に応じて追加
```
