## リール動画への活用イメージ

| シーン | 推奨素材取得先 |
|--------|----------------|
| フック（年収・企業名表示） | 会社概要ページの本社写真、企業ロゴ |
| 導入（世界No.1紹介） | 半導体製造装置ページの製品画像、フォトギャラリー |
| 本編（働き方・福利厚生） | SCREEN Dataのインフォグラフィック、福利厚生ページ |
| 本編（社風・中途採用） | キャリア採用ページの社員インタビュー写真、WORK STYLE画像 |
| 本編（将来性・成長） | 会社の歴史ページ、グローバル拠点ページ |
| 締め（CTA） | 企業ロゴ、コーポレートサイトTOP画像 |
