# テーマ14：報告書作成アシスタント

## このツールでできること

日報・週報・月報を、やったことを伝えるだけで上司に伝わる形にまとめます。「何を書けばいいか分からない」「毎回同じ形式で書くのが面倒」を解決します。

## こんなときに使ってください

- 毎日の日報を書くのが面倒
- 週報で何を書いたらいいか分からない
- 月報のフォーマットを整えたい
- 数字や成果をうまくまとめられない

## 使い方

「今日やったこと」をざっくり伝えるだけ。整った報告書にしてくれます。

### 入力例（日報）
```
今日やったこと：A社への提案資料作成（8割完成）、B社とオンライン打ち合わせ、新人研修の資料レビュー。
困っていること：A社の提案で使うデータが経理からまだ届いていない。
明日の予定：A社提案資料の仕上げ、C社へのフォローアップメール。
```

### 出力例
```
【日報】2026/03/12（山田太郎）

▼ 今日やったこと
| 内容 | 時間 | 進み具合 |
|------|------|---------|
| A社提案資料作成 | 3h | 80% |
| B社オンライン打ち合わせ | 1h | 完了 |
| 新人研修資料レビュー | 1h | 完了 |

▼ 成果
- B社打ち合わせで次回提案の方向性が合意
- 新人研修資料のフィードバック完了

▼ 課題
- A社提案に必要なデータが経理から未着（3/10依頼済み）
  → 明日午前にリマインド予定

▼ 明日の予定
- A社提案資料の仕上げ・最終チェック
- C社フォローアップメール送信
```

## 上司に伝わる報告書のコツ

| ポイント | NG例 | OK例 |
|---------|------|------|
| 数字で書く | 「たくさん連絡した」 | 「15件の顧客に連絡した」 |
| 進捗を％で | 「だいたい終わった」 | 「80%完了」 |
| 課題に対策を添える | 「データが届かない」 | 「データ未着 → 明日リマインド予定」 |
| 成果を具体的に | 「打ち合わせした」 | 「次回提案の方向性が合意された」 |

# テーマ15：報告書リライトアシスタント

## このツールでできること

書いた報告書の下書きを「読みやすく・伝わりやすく」リライトします。文章をスッキリさせたい、もっと説得力を出したい、というときに使えます。

## こんなときに使ってください

- 報告書を書いたけど、何か読みにくい
- 上司に「もっと簡潔に」と言われた
- 提案書の説得力を上げたい
- 誤字脱字や表現のチェックもしてほしい

## 使い方

1. 書いた下書きを貼り付ける
2. 「誰が読むか」「どう直したいか」を伝える
3. リライト版 + 何を変えたかの説明が返ってくる

## 何を直してくれるか

| 修正の種類 | Before | After |
|-----------|--------|-------|
| 結論ファースト | 「先日○○があり、その結果…（長い前置き）」 | 「結論：○○です。背景は以下の通りです。」 |
| 数値化 | 「多くの顧客に好評でした」 | 「アンケートで85%の顧客が満足と回答」 |
| 構造化 | ダラダラした文章 | 見出し + 箇条書き + 表 |
| 短文化 | 80文字の長い1文 | 40文字以下の短い文に分割 |
| 受動態→能動態 | 「検討が行われた」 | 「チームで検討した」 |

# テーマ16：引き継ぎ資料アシスタント

## このツールでできること

異動や退職のとき、後任者に渡す引き継ぎ資料を作成します。「何を引き継げばいいか」の洗い出しから、「読めば一人でできる」レベルの資料にまとめるまでサポートします。

## こんなときに使ってください

- 異動が決まって引き継ぎ資料を作らないといけない
- 退職前に業務を整理したい
- 休暇中の代理対応のために手順をまとめたい
- 属人化している業務を文書化したい

## 出力に含まれるもの

| セクション | 内容 |
|-----------|------|
| 業務の概要 | 何のために、どのくらいの頻度でやる仕事か |
| やり方（手順） | ステップバイステップの手順 |
| 使うツール | URL、ログイン情報、アクセス方法 |
| 関係する人 | 名前、役割、連絡先 |
| よくあるトラブル | 起きがちな問題と対処法 |
| 進行中の案件 | 今動いている仕事の状況 |
| コツ・注意点 | マニュアルには書けないノウハウ |

## 引き継ぎのコツ

- **「自分がいなくても回る」がゴール** → 口頭補足が必要な資料はNG
- **まず業務の一覧を作る** → そこから1つずつ深掘りする
- **判断基準も書く** → 「AのときはX、BのときはY」が一番大事

# テーマ17：マニュアル作成アシスタント

## このツールでできること

業務の手順を、初めての人でも見ながらできるマニュアル（手順書）にまとめます。「1ステップ＝1つの動作」のルールで、迷わないマニュアルを作ります。

## こんなときに使ってください

- 新人に教える業務のマニュアルを作りたい
- 「前任者の頭の中にしかない」業務を文書化したい
- 既存のマニュアルが分かりにくいので改善したい
- システム操作の手順書を作りたい

## 使い方

業務の手順を「ざっくり」伝えるだけ。ツールが深掘り質問で細部を聞き出し、丁寧な手順書にまとめます。

## 良いマニュアルと悪いマニュアルの違い

| 良いマニュアル | 悪いマニュアル |
|-------------|-------------|
| 1ステップ＝1動作 | 1ステップに5個の動作が詰まっている |
| 画面のどこをクリックするか書いてある | 「設定を変更する」だけ |
| 判断ポイントが明確 | 「適宜判断してください」 |
| よくある質問がある | 困ったら誰かに聞いて |
| 初めての人がテストして検証済み | 書いた人しか分からない |

# テーマ18：稟議書アシスタント

## このツールでできること

上司や経営層にお金や新施策のOKをもらうための「稟議書」を作成します。何を買いたいのか・なぜ必要か・いくらかかるか・効果は何かを、判断しやすい形にまとめます。

## こんなときに使ってください

- 新しいツールやサービスを契約したい
- 外注・業務委託の予算を申請したい
- 研修やセミナーへの参加費を申請したい
- 設備投資の承認を得たい

## 通る稟議書のポイント

| ポイント | 説明 |
|---------|------|
| 結論と金額を最初に | 「何をいくらで」が一目で分かること |
| 効果を数字で示す | 「業務が楽になる」→「月20時間の工数削減」 |
| 代替案を1つ以上 | 「他の選択肢も検討した上でこれを推奨」 |
| 3分で判断できる量 | A4で1〜2枚。長すぎると読まれない |

## 入力例
```
月額5,000円のプロジェクト管理ツールを契約したい。
理由：今Excelで管理しているが、タスクの抜け漏れが月2〜3件起きている。
ツールを入れれば抜け漏れがゼロになり、管理の時間も月5時間減る見込み。
```

# テーマ19：企画書アシスタント

## このツールでできること

企画書や提案書の「骨組み（アウトライン）」を作ります。中身を書く前に全体の構成を決めることで、論理的で説得力のある企画書になります。

## こんなときに使ってください

- 新しい企画の提案書を作りたい
- 企画書を書き始めたいけど構成が決まらない
- クライアントへの提案書の骨組みがほしい
- ストーリーの流れを相談したい

## 企画書の基本構成

```
① 表紙（タイトル・日付・名前）
② まとめ（1ページで要点をギュッと）
③ 背景・課題（なぜこの企画が必要か）
④ 提案の中身（何をするか）
⑤ 期待効果（やるとどうなるか）
⑥ スケジュール（いつ何をするか）
⑦ 予算（いくらかかるか）
⑧ リスクと対策（心配ごとと備え）
⑨ まとめ・お願い（OKしてほしいこと）
```

## コツ

- **「まとめ」を先に作る** → 1ページで企画の全体像が伝わるように
- **ストーリーの流れ** は「問題がある → こう解決する → するとこうなる → だからやりましょう」

# テーマ20：プレゼン構成アシスタント

## このツールでできること

プレゼン資料のスライド構成を作ります。「何枚のスライドで、どんな順番で、何を話すか」を設計するので、あとはスライドを作るだけの状態になります。

## こんなときに使ってください

- プレゼンのスライド構成を考えたい
- 持ち時間に合ったスライド枚数がわからない
- 話す内容の順番に自信がない
- 「何を強調すべきか」を相談したい

## 使い方

テーマ・聴衆・持ち時間・キーメッセージを伝えると、スライドの並びと各スライドで話すことが返ってきます。

## スライド枚数の目安

| 持ち時間 | スライド枚数 | 1枚あたり |
|---------|------------|----------|
| 5分 | 3〜5枚 | 1〜1.5分 |
| 15分 | 8〜12枚 | 1〜2分 |
| 30分 | 15〜20枚 | 1.5〜2分 |
| 60分 | 25〜35枚 | 1.5〜2.5分 |

## プレゼンの鉄則

- **1スライド＝1メッセージ** → 欲張って詰め込まない
- **最初の3枚で心を掴む** → ここで「聞きたい」と思わせる
- **文字は少なく、ビジュアルで伝える** → スライドは「読むもの」ではなく「見るもの」
- **最後に「次にどうしてほしいか」を明確に** → アクションを促す
