# テーマ33：Excel関数アシスタント

## このツールでできること

「Excelでこういうことしたいんだけど、どの関数を使えばいいの？」を解決します。やりたいことを日本語で伝えるだけで、最適な関数やマクロを教えてくれます。

## こんなときに使ってください

- 「VLOOKUP? IF? どの関数を使えば…」と悩んだとき
- 関数を組んだけどエラーが出る
- もっと効率的な数式があるか知りたい
- マクロ（VBA）で自動化したい

## 使い方

「こういうことがしたい」を伝えるだけ。数式とその意味を教えてくれます。

### 入力例
```
A列に社員名、B列に部署名、C列に売上が入っています。
部署ごとの売上合計を出したい。
```

### 出力例
```
▼ 使う関数：SUMIFS
▼ 数式：=SUMIFS(C:C, B:B, "営業部")
▼ 意味：B列が「営業部」の行のC列の合計を計算します

▼ 全部署をまとめて出すなら
E列に部署名を入れて、F1に以下を入力：
=SUMIFS(C:C, B:B, E1)
→ 下にコピーすれば全部署分が出ます
```

## よく使う関数 早見表

| やりたいこと | 関数 |
|------------|------|
| 条件に合うデータを探す | VLOOKUP / XLOOKUP |
| 条件で処理を変える | IF / IFS |
| 条件付きで合計 | SUMIFS |
| 条件付きで件数 | COUNTIFS |
| 条件付きで平均 | AVERAGEIFS |
| 文字をくっつける | CONCAT / & |
| 日付を計算 | DATEDIF / EDATE |
| 重複を除く | UNIQUE |

# テーマ34：データ集計アシスタント

## このツールでできること

Excelでのデータ集計方法を、ピボットテーブルの操作手順や関数の使い方と一緒に教えてくれます。「このデータから何を読み取れるか」も分析します。

## こんなときに使ってください

- 大量のデータを集計したい
- ピボットテーブルの使い方が分からない
- 「月別」「担当者別」などの切り口で集計したい
- 集計結果をグラフにしたい

## ピボットテーブルって何？

大量のデータを「ドラッグ&ドロップだけ」でいろいろな切り口から集計できる、Excelの超便利機能です。

### ピボットテーブルの作り方（3ステップ）

1. **データ範囲を選択** → メニュー「挿入」→「ピボットテーブル」
2. **フィールドを配置**
   - 「行」に → 集計の軸にしたいもの（例：部署名、月）
   - 「値」に → 計算したいもの（例：売上）
3. **集計方法を選ぶ** → 合計 / 個数 / 平均 など

### 例：月別の売上集計
- 行：月
- 値：売上金額（合計）
- → 月ごとの売上合計が一発で出る！

# テーマ35：グラフ選びアシスタント

## このツールでできること

「このデータ、どのグラフにしたらいいの？」を解決します。データの性質と伝えたいメッセージに合わせて、最適なグラフを提案し、作り方も教えます。

## こんなときに使ってください

- レポートにグラフを入れたいけど種類が多すぎて迷う
- 上司に「分かりにくい」と言われたグラフを直したい
- プレゼンで映えるグラフを作りたい

## グラフの選び方早見表

| 伝えたいこと | おすすめグラフ | 使用例 |
|------------|-------------|--------|
| 大きさを比べたい | 棒グラフ | 部署別売上、月別件数 |
| 時間の変化を見せたい | 折れ線グラフ | 月次推移、成長率 |
| 割合を見せたい | 円グラフ | 市場シェア、構成比 |
| 順位を見せたい | 横棒グラフ | ランキング、評価結果 |
| 2つの関係を見せたい | 散布図 | 広告費と売上の関係 |
| 比較+推移 | 複合グラフ | 売上（棒）と利益率（折れ線） |

## やりがちなNG

| NG | なぜ悪いか | こうする |
|----|----------|---------|
| 項目が多すぎる円グラフ | 細かすぎて読めない | 5個以内にまとめる。6個目以降は「その他」 |
| 3Dグラフ | 数字が歪んで見える | 2Dのシンプルなグラフにする |
| Y軸が0から始まらない棒グラフ | 差が大きく見えて誤解を招く | 0からスタートする |

# テーマ36：データお掃除アシスタント

## このツールでできること

ぐちゃぐちゃなデータ（重複・空白・書式バラバラ）をきれいに整えるお手伝いをします。データクレンジング（お掃除）の手順を、Excelの操作方法と一緒に教えます。

## こんなときに使ってください

- CSVをExcelで開いたらデータがぐちゃぐちゃ
- 同じ人のデータが2行ある（重複）
- 全角と半角が混ざっている
- 日付の書き方がバラバラ
- 集計する前にデータを整えたい

## よくある「データの汚れ」と直し方

| 汚れ | 直し方（Excel） |
|------|----------------|
| 同じデータが2つある | 「データ」→「重複の削除」 |
| 空白セルがある | Ctrl+Hで一括置換、またはISBLANKで探す |
| 前後にスペースがある | =TRIM(A1) で除去 |
| 全角と半角が混ざっている | =ASC(A1) で半角に統一 |
| 日付がバラバラ | =DATEVALUE(A1) で統一 |
| 数字なのに文字扱い | =VALUE(A1) で数値に変換 |
| 「(株)」と「株式会社」が混在 | =SUBSTITUTE(A1,"(株)","株式会社") |

## データクレンジングの順番

1. **バックアップを取る** ← 最重要！元データは残す
2. **重複を削除する**
3. **空白を処理する**
4. **書式を統一する**（全角半角、日付、表記揺れ）
5. **確認する** → 件数は合っているか？おかしなデータはないか？

# テーマ37：Excel自動化アドバイザー

## このツールでできること

「毎月同じExcel作業していてめんどくさい…」を解決します。繰り返しの作業を分析して、関数・マクロ・Power Queryなどで自動化する方法を提案します。

## こんなときに使ってください

- 毎月同じ集計作業を手作業でやっている
- データのコピー&ペーストを繰り返している
- 「この作業、自動化できないかな？」と思ったとき
- マクロに興味はあるけど何から始めたらいいか分からない

## 自動化の3つのレベル

| レベル | 方法 | 難しさ | こんな人向け |
|--------|------|--------|------------|
| 初級 | 関数を工夫する | ★☆☆ | 関数がなんとなく使える人 |
| 中級 | マクロ（VBA）を使う | ★★☆ | 「マクロの記録」を使ったことがある人 |
| 上級 | Power Query / Power Automate | ★★★ | 複数ファイルを自動処理したい人 |

## 入力例
```
毎月、CSVで届く売上データ（500行くらい）を開いて、
部署別・月別に集計して、グラフ付きの報告書シートにまとめる作業。
今は手作業で毎月2時間かかっている。
```

## 自動化の効果を計算するイメージ

```
▼ 今の状況
- 1回の作業時間：2時間
- 頻度：月1回
- 年間の作業時間：24時間

▼ 自動化した場合
- 自動化を作る時間：4時間（初回のみ）
- 自動化後の作業時間：15分/回
- 年間の節約時間：21時間
- 元が取れるまで：約2回（2ヶ月目から得）
```
