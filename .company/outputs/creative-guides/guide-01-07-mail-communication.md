# テーマ1：社内メールアシスタント

## このツールでできること

「こういうメールを書きたいんだけど、うまく書けない…」を解決します。

伝えたい内容をざっくり入力するだけで、社内向けの丁寧なビジネスメールを自動で作成。件名と本文をセットで出力するので、そのままコピペして送れます。

## こんなときに使ってください

- 上司への報告メールを書くとき
- 他部署への依頼メールを書くとき
- 同僚へのお礼メールを書くとき
- 会議の日程変更を連絡するとき
- 「この書き方で失礼じゃないかな？」と不安なとき

## 使い方（3ステップ）

### ステップ1：ツールを開く
Gemini Gems または ChatGPT GPTs から「社内メールアシスタント」を選んで開きます。

### ステップ2：4つの質問に答える
ツールが以下の4つを聞いてきます。ざっくり答えるだけでOKです。

| 質問 | 答え方の例 |
|------|-----------|
| 誰に送る？ | 「田中部長」「開発チームの鈴木さん」 |
| 何を伝えたい？ | 「来週のミーティングを金曜に変更したい」 |
| メールの種類は？ | 「お願い」「報告」「確認」「お礼」「共有」から選ぶ |
| 急ぎ？ | 「急ぎ」か「ふつう」 |

### ステップ3：メールを受け取る
件名と本文がセットで出てきます。必要に応じて自分の言葉に微調整して、そのまま送信できます。

## 入力例と出力例

### あなたの入力
```
田中部長に、来週水曜の定例ミーティングを金曜15時に変更してほしいとお願いしたい。理由は客先訪問が入ったため。
```

### AIの出力
```
件名：【ご相談】来週の定例ミーティング日程変更のお願い

田中部長

お疲れ様です。山田です。

来週水曜（3/19）の定例ミーティングについて、
日程変更のご相談をさせてください。

水曜に客先訪問が入ったため、以下の日程への変更を
お願いできますでしょうか。

・変更後：3月21日（金）15:00〜
・場所：会議室B（変更なし）

ご都合が悪い場合は別日程を調整いたしますので、
お気軽にお知らせください。

よろしくお願いいたします。
```

## もっと便利に使うコツ

- **「もう少しカジュアルに」** と追加で伝えると、同僚向けのフランクな文体に調整してくれます
- **「箇条書きを増やして」** と伝えると、より読みやすい形に直してくれます
- **複数パターンほしいとき** は「2パターン作って」と伝えると比較できます

# テーマ2：取引先メールアシスタント

## このツールでできること

取引先やお客様に送る「失礼のない丁寧なメール」を自動で作成します。

社外メールは敬語の使い方や形式が重要ですが、このツールが正しいビジネスメールの形式に整えてくれるので安心です。

## こんなときに使ってください

- 取引先に見積もりやお提案を送るとき
- 初めての会社にアポイントメールを送るとき
- 納品完了の連絡をするとき
- 打ち合わせのお礼メールを書くとき
- 英語圏以外の海外取引先へ（日本語メールの場合）

## 使い方（3ステップ）

### ステップ1：ツールを開く
「取引先メールアシスタント」を選んで開きます。

### ステップ2：3つの質問に答える

| 質問 | 答え方の例 |
|------|-----------|
| どこの誰に送る？ | 「ABC株式会社 営業部の佐藤様」 |
| 何の用件？ | 「見積書を送りたい」「アポイントを取りたい」 |
| あなたの会社名と名前 | 「XYZ株式会社の山田です」 |

### ステップ3：メールを受け取る
件名・本文・署名ブロックがセットで出てきます。

## 入力例と出力例

### あなたの入力
```
ABC株式会社の佐藤様に、先日の打ち合わせのお礼と、見積書を添付で送りたい。私はXYZ株式会社 営業部の山田です。
```

### AIの出力
```
件名：先日のお打ち合わせの御礼と見積書のご送付

株式会社ABC
営業部 佐藤様

いつもお世話になっております。
XYZ株式会社 営業部の山田です。

先日はお忙しい中、お打ち合わせのお時間をいただき
誠にありがとうございました。

ご依頼いただいておりました見積書を作成いたしましたので、
添付にてお送りいたします。

・添付ファイル：御見積書_XYZ_20260312.pdf

ご不明な点やご質問がございましたら、
お気軽にお申し付けください。

何卒よろしくお願い申し上げます。

━━━━━━━━━━━━
XYZ株式会社 営業部
山田 太郎
TEL：03-XXXX-XXXX
Email：yamada@xyz.co.jp
━━━━━━━━━━━━
```

## 社内メールとの違い

| 項目 | 社内メール | 取引先メール |
|------|----------|------------|
| 書き出し | お疲れ様です | いつもお世話になっております |
| 宛名 | ○○さん、○○部長 | 株式会社○○ ○○部 ○○様 |
| 敬語 | 丁寧語中心 | 尊敬語・謙譲語をしっかり |
| 締め | よろしくお願いいたします | 何卒よろしくお願い申し上げます |
| 署名 | なくてもOK | 必ず付ける |

# テーマ3：謝罪メールアシスタント

## このツールでできること

ミスやトラブルが起きたとき、「誠意が伝わる謝罪メール」を作成します。

謝罪メールは書き方を間違えると火に油を注ぐことも。このツールが「お詫び → 事実 → 原因 → 対応 → 再発防止」の正しい順番で組み立てます。

## こんなときに使ってください

- 納期に遅れてしまったとき
- 間違ったファイルや情報を送ってしまったとき
- ミーティングに遅刻・欠席してしまったとき
- お客様への対応で不手際があったとき
- 社内でミスをして迷惑をかけたとき

## 使い方（3ステップ）

### ステップ1：ツールを開く
「謝罪メールアシスタント」を選んで開きます。

### ステップ2：4つの質問に答える

| 質問 | 答え方の例 |
|------|-----------|
| 何が起きた？ | 「納品が2日遅れた」「間違ったファイルを送った」 |
| 誰に送る？ | 「取引先の佐藤様」「上司の田中部長」 |
| 原因は分かってる？ | 「確認不足でバージョン違いを送った」 |
| もう対応した？ | 「正しいファイルを再送済み」「まだ対応中」 |

### ステップ3：謝罪メールを受け取る

## 謝罪メールの正しい構成

このツールは以下の順番でメールを組み立てます。

```
① まずお詫び         ← 冒頭ではっきり謝る
② 何が起きたか       ← 事実を簡潔に
③ 原因              ← 分かっている範囲で
④ 対応したこと       ← すでにやったこと
⑤ これからの対応     ← これからやること
⑥ 再発防止策        ← 同じことを繰り返さないために
⑦ もう一度お詫び     ← 最後に改めて
```

## やりがちなNG例

| NG | 理由 | OKな書き方 |
|----|------|-----------|
| 「忙しくてミスしてしまい…」 | 言い訳に聞こえる | 「確認が不十分でした」 |
| 「たぶん○○が原因です」 | あいまい | 「○○が原因であることを確認しました」 |
| 「今後気をつけます」 | 具体性がない | 「ダブルチェック体制を導入します」 |

# テーマ4：リマインドメールアシスタント

## このツールでできること

「返事がこない」「期限を過ぎている」…でも催促って気まずい。

このツールは、相手を不快にさせずにやんわり催促するメールを作成します。トーンを3段階（やわらかめ/ふつう/少し強め）から選べます。

## こんなときに使ってください

- メールを送ったのに返信がない
- 提出物の期限が過ぎている
- 支払いの確認がまだ
- 確認依頼に反応がない
- 2回目、3回目の催促をしたい

## 3段階のトーン

| レベル | こんな感じ | 使う場面 |
|--------|----------|---------|
| やわらかめ | 「念のためのご確認なのですが…」 | 期限前、親しい相手 |
| ふつう | 「ご確認いただけましたでしょうか」 | 期限直後、一般的な関係 |
| 少し強め | 「業務に影響が出ております」 | 期限を大幅に過ぎた、2回目以降 |

## 入力例と出力例

### あなたの入力
```
先週お願いした企画書のレビュー、まだ返事がもらえてない。相手は同じチームの鈴木さん。やわらかめで。
```

### AIの出力
```
件名：企画書レビューの件（ご確認のお願い）

鈴木さん

お疲れ様です。山田です。

先週お送りした企画書のレビューの件、
その後ご確認いただけましたでしょうか？

お忙しいところ恐れ入りますが、
今週金曜のミーティングまでにフィードバックを
いただけると助かります。

もし内容にご不明な点があれば、
口頭でのご説明も可能ですのでお気軽にどうぞ。

よろしくお願いいたします。
```

# テーマ5：英語メールアシスタント

## このツールでできること

日本語で伝えたいことを入力するだけで、ネイティブが読んでも自然な英語ビジネスメールに変換します。

英語メールの返信作成や、届いた英語メールの翻訳もできます。日本語訳も一緒に出力するので、内容の確認も安心です。

## こんなときに使ってください

- 海外の取引先にメールを送りたい
- 英語のメールが届いたけど意味が分からない
- 英語メールの返信を書きたい
- 「お世話になっております」を英語でどう言えばいいか分からない

## 使い方

3つのモードがあります。

### モード1：メール作成
**入力：** 日本語で伝えたいこと
**出力：** 英語メール + 日本語訳

### モード2：翻訳
**入力：** 英語のメール本文
**出力：** 日本語訳

### モード3：返信作成
**入力：** 届いた英語メール + 返事の内容（日本語でOK）
**出力：** 英語の返信メール + 日本語訳

## 日本語と英語の違い（知っておくと便利）

| 日本語の表現 | 英語ではこう書く |
|------------|----------------|
| いつもお世話になっております | （英語にはこの概念がないので省略、または "Thank you for your continued support" と状況に応じて） |
| ご検討のほどよろしくお願いいたします | We would appreciate your consideration. |
| お忙しいところ恐れ入りますが | I understand you are busy, but... |
| 何卒よろしくお願い申し上げます | Thank you in advance. / Best regards, |

## フォーマリティ（丁寧さ）の選び方

| レベル | 英語の書き方 | 使う場面 |
|--------|------------|---------|
| フォーマル | Dear Mr./Ms. ○○ | 初対面、重要な取引先、公式文書 |
| ふつう | Dear [名前], | 何度かやり取りのある相手 |
| カジュアル | Hi [名前], | 親しい同僚、日常的なやり取り |

# テーマ6：チャット要点まとめアシスタント

## このツールでできること

SlackやTeamsの長いやり取りを、パッと見て分かる形にまとめます。

「あのチャットで何が決まったんだっけ？」「誰が何をやるんだっけ？」を解決します。

## こんなときに使ってください

- Slackのスレッドが長くなって要点が分からない
- チャットで決まったことを関係者に共有したい
- 会議中のチャットから決定事項を抽出したい
- TODOが埋もれているチャットを整理したい

## 使い方

1. SlackやTeamsのやり取りをコピー
2. このツールに貼り付け
3. 以下の形式でまとめが返ってくる

```
【要点まとめ】
- ポイントを箇条書きで

【決まったこと】
- 確定した内容

【やること（TODO）】
- [ ] 誰が / 何を / いつまでに

【まだ決まっていないこと】
- 結論が出ていないこと
```

## 使い方のコツ

- **チャット全文をコピペ** してください。部分的に貼ると文脈を見落とす可能性があります
- **発言者の名前がある方がいい** です。TODOの担当者を特定できます
- 「TODOだけ抽出して」「決定事項だけまとめて」など、欲しい部分だけ指定してもOK

# テーマ7：社内お知らせアシスタント

## このツールでできること

社内向けのお知らせ・通知文を、分かりやすく整った形で作成します。

「全員に伝わる」「必要なアクションが一目で分かる」お知らせ文を作りましょう。

## こんなときに使ってください

- システムメンテナンスの案内を出すとき
- 社内制度やルールが変わるとき
- イベントや研修の案内をするとき
- 人事異動のお知らせを書くとき
- オフィスの注意事項を周知するとき

## 使い方（3ステップ）

### ステップ1：ツールを開く
「社内お知らせアシスタント」を選んで開きます。

### ステップ2：5つの質問に答える

| 質問 | 答え方の例 |
|------|-----------|
| どんなお知らせ？ | 「来週のシステムメンテナンス」 |
| 誰に向けて？ | 「全社員」「営業部のみ」 |
| 伝えたい内容は？ | 「3/20の22時〜翌6時まで社内システムが停止」 |
| やってほしいことは？ | 「20日の18時までに作業を保存してください」 |
| 日時や期限は？ | 「3月20日 22:00〜3月21日 6:00」 |

### ステップ3：お知らせ文を受け取る

## 入力例と出力例

### あなたの入力
```
来週金曜の夜にシステムメンテナンスがある。社内システムが止まるので全社員に通知したい。
日時は3月20日22時〜21日朝6時。それまでに作業を保存して、ログアウトしておいてほしい。
```

### AIの出力
```
【重要】社内システムメンテナンスのお知らせ

各位

下記の通りシステムメンテナンスを実施いたします。
メンテナンス中はシステムが停止しますので、ご確認ください。

■ 日時
2026年3月20日（金）22:00 〜 3月21日（土）6:00

■ 影響範囲
社内システム全般（メール・ファイルサーバー含む）

■ お願いしたいこと
・3月20日 18:00 までに作業内容を保存してください
・20日 21:30 までにシステムからログアウトしてください

■ 問い合わせ先
情報システム部 内線：1234
Email：it-support@example.co.jp

情報システム部
2026年3月12日
```

## 件名の【タグ】の使い分け

| タグ | 使う場面 |
|------|---------|
| 【重要】 | 全員に関わる、必ず読んでほしいとき |
| 【ご案内】 | イベント・研修など任意参加のとき |
| 【変更】 | 制度やルールが変わるとき |
| 【お願い】 | 何かアクションをしてほしいとき |
| 【お知らせ】 | 情報共有のみで、アクション不要のとき |
