# テーマ8：アジェンダ作成アシスタント

## このツールでできること

会議のアジェンダ（進行表）を自動で作ります。「何を・どの順番で・何分ずつ話すか」が一目で分かるので、会議がダラダラしなくなります。

## こんなときに使ってください

- 定例ミーティングのアジェンダを毎週作っている
- 急な会議で進行表を作る時間がない
- 会議がいつも時間オーバーする
- ブレストや意思決定会議の設計をしたい

## 使い方

目的・参加者・時間・話したいことを伝えるだけでOK。

### 入力例
```
来週の営業チーム定例。参加者5名。1時間。
話したいこと：先週の数字の振り返り、新規キャンペーンの進捗、来月の目標設定。
```

### 出力例
```
【会議アジェンダ】営業チーム定例
日時：2026/3/19 10:00-11:00
参加者：5名

| 順番 | 話すこと | 時間 | やること |
|------|---------|------|---------|
| 1 | 開始・前回の振り返り | 5分 | 確認 |
| 2 | 先週の数字レビュー | 15分 | 報告・議論 |
| 3 | 新規キャンペーン進捗 | 15分 | 報告 |
| 4 | 来月の目標設定 | 20分 | 議論・決定 |
| 5 | まとめ・ネクストアクション | 5分 | 確認 |
```

## コツ

- **大事な話題は前半に** → 後半は集中力が落ちるため
- **「決める」会議と「共有する」会議は分ける** → 目的が混ざると時間が足りなくなる
- **必ず最後に「次にやること確認」を入れる** → 会議の意味がなくならないように

# テーマ9：議事録まとめアシスタント

## このツールでできること

会議のメモやテキストを貼り付けるだけで、きちんとした議事録に整形します。決定事項とTODOが自動で抽出されるので、「あれ、何が決まったんだっけ？」がなくなります。

## こんなときに使ってください

- 走り書きのメモを議事録にしたい
- 録音の文字起こしテキストを整理したい
- 議事録を書くのが苦手
- とにかく早く議事録を仕上げたい

## 使い方

会議のメモを貼り付けるだけ。以下の形にまとめてくれます。

```
【ひとことまとめ】（3行以内で全体像）
【話し合った内容】（話題ごとに整理）
【決まったこと】（箇条書き）
【やること】（誰が・何を・いつまでに、の表）
```

## 入力のコツ

- **メモは完璧でなくてOK** → 走り書きでも文脈を読み取って整理してくれます
- **発言者名があるとベター** → TODOの担当者を特定できます
- **「議題ごとにまとめて」と追加指示** すると、より構造化されます

# テーマ10：タスク抽出アシスタント

## このツールでできること

議事録や会議メモから「誰が・何を・いつまでにやるか」を漏れなく拾い出します。

会議で「○○しましょう」と言ったのに、誰もやっていなかった…を防ぎます。

## こんなときに使ってください

- 会議後にTODOを整理したい
- 議事録からアクションアイテムを抽出したい
- 「○○さん確認お願いします」が埋もれている
- タスクの抜け漏れがないかチェックしたい

## 使い方

議事録を貼り付けるだけ。こんな表が出てきます。

```
| # | やること | 担当者 | 期限 | 優先度 |
|---|---------|--------|------|--------|
| 1 | 見積書を再送する | 田中 | 3/15 | 高 |
| 2 | デザイン案をレビューする | 鈴木 | 3/18 | 中 |
| 3 | クライアントに日程確認 | 要確認 | 3/14 | 高 |
```

## このツールが拾うもの

- 「○○する」「○○を確認する」「○○を検討する」→ すべてタスク化
- 「○○さんが」「○○部で」→ 担当者として抽出
- 「来週までに」「金曜まで」→ 期限として抽出
- 「資料を共有します」のような暗黙のタスクも拾う
- 担当者が不明なものは「要確認」と表示

# テーマ11：会議進行準備アシスタント

## このツールでできること

会議の進行役（ファシリテーター）に必要な「準備シート」を作ります。意見が割れそうなポイントの対策や、使えるフレーズ集も含まれるので、初めてのファシリテーターでも安心です。

## こんなときに使ってください

- 初めて会議の司会をすることになった
- 難しいテーマの会議で意見がぶつかりそう
- 会議がいつも脱線してまとまらない
- 進行の段取りを事前に準備しておきたい

## 出力に含まれるもの

| セクション | 中身 |
|-----------|------|
| 今日のゴール | 会議で達成すべきことを明確に |
| タイムライン | 何を何分で進めるかの計画 |
| もめそうなポイント | 賛成意見・反対意見・落とし所の案 |
| 使えるフレーズ集 | 場面別にすぐ言えるセリフ |
| 困ったときの対処法 | まとまらない・時間切れ・沈黙のとき |

## すぐ使えるフレーズ例

| 場面 | フレーズ |
|------|---------|
| 話を深めたい | 「具体的にはどういうことですか？」 |
| 合意を取りたい | 「この方向で進めてよろしいですか？」 |
| 脱線を戻したい | 「面白い話題ですが、本題に戻りますね」 |
| 発言を促したい | 「○○さんはいかがですか？」 |
| 時間を管理 | 「残り5分ですので、まとめに入りましょう」 |

# テーマ12：会議の事前まとめアシスタント

## このツールでできること

会議の前に参加者へ配る「事前ブリーフ」を作成します。これがあると、参加者が予備知識を持った状態で会議に来られるので、議論の質が上がり、時間も短縮できます。

## こんなときに使ってください

- 複雑なテーマの会議で事前に情報を共有したい
- 参加者に前もって考えてきてほしいことがある
- 会議の冒頭で説明する時間を減らしたい
- 会議の論点を事前に整理しておきたい

## 使い方

テーマ・背景・論点を伝えると、5分で読める事前資料にまとめてくれます。

### 出力に含まれるもの
- この会議の背景（なぜやるのか、2〜3行）
- 論点（3つ以内に絞る）
- 事前に確認・考えてきてほしいこと
- 参考情報
- 会議で決めたいこと

## コツ

- **論点は3つまでに絞る** → 多すぎると読まれない
- **A4で1〜2枚が理想** → 読むのに5分以内
- **会議の前日までに送る** → 当日送っても読む時間がない

# テーマ13：1on1準備アシスタント

## このツールでできること

上司と部下の1on1ミーティング（1対1の面談）の準備シートを作ります。「上司として何を聞くべきか」「部下として何を話すべきか」の両方に対応。

## こんなときに使ってください

- 定期的な1on1の準備に毎回悩む
- 部下に何を聞いたらいいか分からない
- 上司との面談で話すことが思いつかない
- フィードバックの伝え方を事前に整理したい

## 上司として使う場合

以下のような準備シートが出力されます。

```
▼ 確認したいこと
- 仕事の進み具合、困っていることはないか
- やる気・体調は大丈夫か
- キャリアの方向性

▼ 聞いてみる質問
- 「最近うまくいっていることは？」
- 「困っていること、手伝えることはある？」
- 「チームの雰囲気はどう感じてる？」
```

## 部下として使う場合

```
▼ 報告・共有したいこと
1.（自分の成果や進捗）

▼ 相談したいこと
1.（悩みや判断に迷っていること）

▼ 手伝ってほしいこと
1.（上司のサポートが必要なこと）
```

## 1on1を有意義にするコツ

- **事前に準備シートを埋めておく** → 何も考えずに臨むと雑談で終わる
- **相手の話を7割聞く** → 特に上司は「聞く」意識を
- **前回のアクションを最初に確認する** → 継続性が大事
