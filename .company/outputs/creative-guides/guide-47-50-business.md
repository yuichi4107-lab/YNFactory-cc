# テーマ47：契約チェックアシスタント

## このツールでできること

契約書や利用規約の「ここを確認すべき」ポイントを整理します。見落としがちな条項をチェックリスト形式で確認できます。

⚠️ **注意：このツールは法律のアドバイスではありません。最終的な判断は必ず法務部門や弁護士にご確認ください。**

## こんなときに使ってください

- 業務委託契約書を確認したい
- NDA（秘密保持契約）のチェックポイントが知りたい
- サービスの利用規約で気をつけるべき点は？
- フリーランスで契約する前に確認すべきことは？

## チェックすべき9つのポイント

| # | チェック項目 | なぜ大事か |
|---|------------|-----------|
| 1 | 契約期間と更新条件 | 自動更新で解約できなくなるケースがある |
| 2 | 解約の条件・費用 | いつ・どうやって解約できるか |
| 3 | 支払い条件 | 金額・支払い時期・方法 |
| 4 | 責任の範囲 | どこまで責任を負うのか |
| 5 | 知的財産権の帰属 | 作ったものの権利は誰のものか |
| 6 | 秘密保持の範囲 | 何を秘密にする必要があるか |
| 7 | 損害賠償の上限 | 最悪の場合いくら払う可能性があるか |
| 8 | 競業禁止条項 | 同業他社で働けなくなる条件があるか |
| 9 | 紛争解決方法 | トラブルになったときどうするか |

## 使い方

契約書のテキストを貼り付けるか、契約の種類と自分の立場を伝えると、チェックポイントを整理してくれます。

## 特にフリーランスが注意すべき点

| 注意点 | よくある罠 |
|--------|-----------|
| 著作権の譲渡 | 「制作物の権利は全て発注者に帰属」→ ポートフォリオに使えなくなる |
| 無制限の修正 | 「修正回数に制限なし」→ 際限なく修正を求められる |
| 支払いサイト | 「納品後60日以内」→ 2ヶ月も入金がない |
| 競業禁止 | 「1年間は同業の仕事を受けてはならない」→ 仕事がなくなる |

# テーマ48：クレーム対応アシスタント

## このツールでできること

お客様や取引先からのクレームに対する対応文（メール・書面・電話の台本）を作成します。誠意が伝わり、事態を収める文章を一緒に考えます。

## こんなときに使ってください

- クレームのメールが来て、どう返信すればいいか分からない
- 電話でクレーム対応するための台本がほしい
- 書面でのお詫び文を作りたい
- 相手を怒らせない伝え方を考えたい

## クレーム対応の7ステップ

```
① まずお詫び          ← 相手の気持ちに寄り添う
② 内容の復唱          ← 「ちゃんと理解しています」と示す
③ 事実確認の結果       ← 何が起きたかを客観的に
④ 原因の説明          ← なぜ起きたか
⑤ 具体的な対応策       ← 何をするか（いつまでに）
⑥ 再発防止策          ← 同じことを起こさないために
⑦ もう一度お詫び       ← 今後もよろしくお願いします
```

## 入力例
```
お客様から「注文した商品と違うものが届いた」とクレームメールが来た。
調べたところ、倉庫での出荷ミスが原因。正しい商品をすぐ発送する予定。
```

## クレーム対応の鉄則

| 鉄則 | 理由 |
|------|------|
| まず相手の気持ちに寄り添う | 「お詫び」が先。事実確認は後 |
| 言い訳をしない | 「忙しくて…」は火に油 |
| 具体的な対応と期限を示す | 「善処します」はNG。「明日中に発送します」 |
| 過剰な補償を安易に約束しない | 上と相談してから回答する |
| 記録に残す | メールなど文字で残す。言った言わないを防ぐ |

# テーマ49：プレスリリースアシスタント

## このツールでできること

新商品やサービス、提携、実績などのニュースを、メディアや世の中に発表するための公式文書（プレスリリース）を作成します。

## こんなときに使ってください

- 新しいサービスをリリースするとき
- 事業提携を発表するとき
- 実績や受賞を発表するとき
- イベントの告知をしたいとき

## プレスリリースの基本構成

```
① タイトル（一目で内容が分かる見出し）
② サブタイトル（補足説明）
③ リード文（冒頭2〜3文で全体像を要約）
④ 本文
   - 背景・課題
   - 内容・特徴
   - 今後の展望
⑤ 概要（名称・日時・価格・URLの表）
⑥ 会社概要
⑦ お問い合わせ先
```

## 良いプレスリリースのポイント

| ポイント | 説明 |
|---------|------|
| タイトルで内容が分かる | 読まれるかどうかはタイトルで決まる |
| リード文だけで全体像が分かる | 記者は最初の数行しか読まないことも |
| 事実ベースで書く | 「すごい！」「画期的！」は避ける。数字で語る |
| A4で2枚以内 | 短く、簡潔に |

## 入力例
```
来月から新しいオンライン研修サービスを始める。
名前は「SkillUp Online」。月額980円で、ビジネススキルの動画50本が見放題。
ターゲットは中小企業の新入社員教育。
```

# テーマ50：ビジネスマナー先生

## このツールでできること

仕事で遭遇するマナーや常識について、「なぜそうするのか」の理由付きで、親しみやすく教えてくれます。新入社員はもちろん、「今さら聞けない…」というベテランにも使えます。

## こんなときに使ってください

- 「了解しました」と「承知しました」、どっちが正しい？
- 名刺交換の正しいやり方が不安
- メールのCC/BCCの使い分けが分からない
- 上座・下座が分からない
- 接待のマナーを確認したい

## よくある質問トップ10

| # | 質問 | ざっくり回答 |
|---|------|------------|
| 1 | 「了解しました」は失礼？ | 目上の人には「承知しました」「かしこまりました」が安全 |
| 2 | メールのCCとBCCの違いは？ | CC＝全員にアドレスが見える。BCC＝他の人にアドレスが見えない |
| 3 | 名刺はどう渡す？ | 目下から先に、両手で、相手に読める向きで |
| 4 | 上座・下座の見分け方は？ | 入口から一番遠い席が上座 |
| 5 | 電話の取り次ぎ方は？ | 「○○でございますね。少々お待ちください」 |
| 6 | 「お疲れ様」と「ご苦労様」の違い？ | 「ご苦労様」は目上→目下。目上には「お疲れ様です」 |
| 7 | メールの返信はいつまで？ | 24時間以内が目安。すぐに回答できなくても「受領しました」を先に |
| 8 | 会議に遅刻しそうなときは？ | 遅れると分かった時点ですぐ連絡。到着予定時刻を伝える |
| 9 | エレベーターのマナーは？ | 操作盤の前に立つのが後輩の役割。降りるときはお客様・上司が先 |
| 10 | 「させていただく」の使いすぎ？ | 相手の許可が必要な場面だけ使う。自分の意志でやることには不要 |

## 使い方

マナーについて何でも質問してください。「こういう場面で、どうすればいい？」と場面を伝えると、具体的なセリフ例付きで回答します。

| 言う | おっしゃる | 申す・申し上げる |
