# 電話応答シナリオ（整体院向け AI電話受付）

作成日: 2026-07-05
対象業種: 整体院・骨盤矯正サロン（架空店舗「からだ回復整体院サンプル」）
関連: `ヒアリング項目.md`「FAQ・禁止回答リスト.md`

本シナリオは4パターン（通常問い合わせ／予約ヒアリング／クレーム／緊急時の有人転送）を網羅する。
すべて**架空店舗を前提としたサンプル会話**であり、実際の音声収録・電話ボット実装は本工程のスコープ外（後続フェーズで対応）。

---

## 0. 共通オープニング（全通話共通）

```
AI: お電話ありがとうございます。からだ回復整体院サンプルでございます。
    ただいまの時間、施術者が施術中のためAIスタッフがご用件をお伺いしております。
    サービス向上のため、通話内容を録音・記録させていただいております。
    ご了承いただける場合はそのままお話しください。
    もしご了承いただけない場合はその旨をお伝えください。折り返しのお電話に切り替えます。
```

- 架電者が録音に同意しない意思を示した場合 → 「かしこまりました。折り返しのご希望時間帯だけお伺いし、担当より折り返しご連絡いたします」に分岐し、詳細ヒアリングは行わず**お名前・電話番号・折り返し希望時間帯のみ**を聴取して終話する。
- 同意（無言で用件を話し始めた場合を含む）が得られたら、以下の用件判定に進む。

```
AI: 本日はどのようなご用件でしょうか。
    「ご予約」「ご予約の変更・キャンセル」「お問い合わせ」から
    お選びいただくか、そのままご用件をお話しください。
```

架電者の発話内容から、以下4パターンのいずれかへ分岐する。

---

## パターン1: 通常問い合わせ（FAQ範囲の質問）

**分岐条件**: 料金・営業時間・アクセス・メニュー内容など、FAQ・禁止回答リストで回答可能と判定される質問。

```
架電者: 料金と施術時間を教えてください。

AI: ご案内いたします。
    初回体験コースは60分で5,000円、カウンセリングを含みます。
    通常コースは45分で6,500円、60分で8,500円です。
    （FAQリストの範囲内で回答）

架電者: 分かりました。予約は今すぐしなくても大丈夫ですか。

AI: はい、もちろんです。ご検討のうえ、またお気軽にお電話またはLINEにてご連絡ください。
    念のため、お名前とご連絡先を伺ってもよろしいでしょうか。
    折り返しのご案内などに使わせていただきます。

架電者: （名前・電話番号を伝える／伝えないを選択できる）

AI: ありがとうございます。本日はお問い合わせとして担当へ共有いたします。
    お電話ありがとうございました。
```

**分岐: FAQ範囲外の質問だった場合**
```
AI: 申し訳ございません、その点につきましては担当者から直接ご案内させていただきたく、
    お名前とご連絡先、ご質問の内容を伺ってもよろしいでしょうか。
    後ほど担当より折り返しご連絡いたします。
```
→ ヒアリング項目（共通項目）を聴取し、店舗オーナーへ通知して終話。

---

## パターン2: 予約ヒアリング

**分岐条件**: 「予約」「予約の変更」「キャンセル」の意思が確認された場合。

```
架電者: 予約を取りたいです。

AI: ありがとうございます。いくつかお伺いしてもよろしいでしょうか。
    まず、当店のご利用は初めてでいらっしゃいますか。

架電者: 初めてです。

AI: ありがとうございます。初めての方は60分のカウンセリング付き体験コースがおすすめです。
    お名前を教えていただけますか。

架電者: （名前を伝える）

AI: （名前）様、ありがとうございます。
    折り返し用のお電話番号は、今おかけいただいている番号でよろしいですか。

架電者: はい、大丈夫です。

AI: 気になっている部位や、施術を受けたい理由があれば教えてください。
    ※こちらは施術者への申し送りのために伺うもので、AIから施術内容やおすすめの判断はいたしません。

架電者: 腰が張っていて、デスクワークが多いので気になっています。

AI: 承知いたしました。そのまま担当施術者へお伝えいたします。
    ご希望の日時を、第1希望から第3希望まで教えていただけますか。
    ※この時点では仮のご希望として承り、確定は改めて担当よりご連絡いたします。

架電者: （日時候補を伝える）

AI: ありがとうございます。頂いた内容を担当へ共有し、
    本日中に折り返しご連絡してご予約を確定いたします。
    お電話ありがとうございました。
```

**分岐: 予約変更・キャンセルの場合**
```
架電者: 予約を変更したいです。

AI: かしこまりました。お名前と、変更前のご予約日時を教えていただけますか。

架電者: （回答）

AI: ありがとうございます。変更のご希望日時も教えてください。

架電者: （回答）

AI: 承知いたしました。担当へ共有し、変更が可能か確認のうえ、折り返しご連絡いたします。
    ※この時点では変更確定ではなく、仮受付である旨をご了承ください。
```

**分岐: キャンセルの場合**
```
架電者: 予約をキャンセルしたいです。

AI: かしこまりました。お名前と、キャンセルされたいご予約の日時を教えていただけますか。

架電者: （回答）

AI: ありがとうございます。〇月〇日〇時のご予約のキャンセルとして承りました。
    担当へ共有のうえ、キャンセル完了のご連絡を差し上げます。
    ※キャンセル理由の確認は行わず、お話しいただいた内容のみをそのまま担当へ共有いたします。
    またのご利用をお待ちしております。
```

## パターン3: クレーム

**分岐条件**: 施術内容・接客・料金・体調不良の訴えなど、不満・苦情のトーンが検知された場合。

```
架電者: 前回の施術を受けてから腰の調子が悪くなった気がします。

AI: ご心配とご不便をおかけし、申し訳ございません。
    体調に関わる大切なご連絡ですので、私からその場でお答えするのではなく、
    担当施術者または責任者に直接確認のうえ、折り返しご連絡させていただきたく存じます。
    ※AIからは施術内容の評価や体調に関する判断は行いません。

AI: お名前と、施術を受けられたおおよその日時を教えていただけますか。

架電者: （回答）

AI: ありがとうございます。今の症状について、
    差し支えなければ詳しく教えていただけますか。
    そのまま担当へ申し送りいたします。

架電者: （回答）

AI: 承知いたしました。この内容は重要案件として即時、責任者へ共有いたします。
    本日中に折り返しお電話いたします。
    もし強い痛みや体調の急変がある場合は、すぐに医療機関へのご相談をお願いいたします。
```

- クレーム内容は**その場での謝罪・返金判断・施術評価をAIが行わない**。必ず有人（オーナーまたは責任者）へ即時エスカレーションする（緊急度「高」として扱う。詳細は下記「緊急時・クレーム時の有人転送ルール」参照）。
- 体調急変を疑わせる発言（強い痛み・しびれ・意識障害等）があった場合は、パターン4（緊急転送）の対応に切り替える。

---

## パターン4: 緊急時の有人転送

**分岐条件**: 以下のいずれかに該当する場合、即座に有人転送フローへ移行する。
- 強い痛み・しびれ・意識障害・呼吸困難など、健康・安全に関わる緊急性が疑われる発言
- 施術中の事故・急な体調変化の訴え
- 架電者が明確に「今すぐ人と話したい」「緊急です」と伝えた場合
- 未成年者・保護者からの緊急連絡

```
架電者: さっき施術を受けた後から急に息苦しくて、めまいもします。

AI: お伝えいただきありがとうございます。緊急性が高い内容と判断し、
    すぐに担当スタッフにおつなぎ、または至急折り返しのお電話をいたします。
    今、電話をお切りにならずにこのままお待ちいただけますか。

（内部処理）
AI: ただいま担当へ緊急連絡を行っております。少々お待ちください。

【有人へ即時通知】※AIは以降の医療的判断・アドバイスを一切行わない
```

**緊急時・クレーム時の有人転送ルール（共通）**

| 項目 | ルール |
|---|---|
| 転送トリガー | 体調急変・事故・強いクレーム・「緊急です」等の明示発言・未成年/保護者からの緊急連絡 |
| 一次対応 | AIは症状や状況を判断せず、「担当へ即時共有する」旨のみ伝え、架電者を待たせる、または折り返し時間を明確に伝える |
| 通知方法 | 「緊急」フラグ付きでLINE・SMS・電話コール等、店舗が指定した最優先チャネルで即時通知（営業時間外含む） |
| 通知内容 | 架電者名・連絡先・症状/クレーム内容の要約（AIの解釈を加えず原発言に近い形で記録）・受信時刻 |
| 応答目標時間 | 緊急案件は原則15分以内に有人から折り返す運用を店舗と合意する（本工程では運用ルール案として提示、実運用体制は導入時に店舗と個別合意） |
| 医療的助言の禁止 | AIは「様子を見てください」等の医療的アドバイスを行わない。健康・安全に関わる緊急性が疑われる場合は「必要に応じて医療機関へのご相談をお願いします」という定型案内のみ行う |
| 記録保持 | 緊急対応・クレーム内容は店舗の同意した保管期間・アクセス権限のルールに従い記録する（ヒアリング項目.md「録音・個人情報方針」参照） |

## シナリオ運用上の注意（法規制・リスク配慮）

- 本シナリオは架空店舗を前提としたサンプルであり、実在の店舗・事業者を示すものではない。
- AIは診断・治療方針・返金可否・法的判断を一切行わない（詳細は「FAQ・禁止回答リスト.md」参照）。
- 実際の音声合成・電話ボットへの実装、通話録音システムとの連携は本工程のスコープ外であり、後続フェーズ（実導入フェーズ）で行う。
