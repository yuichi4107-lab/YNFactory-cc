# 営業用デモ台本（AI電話受付・予約導入代行）

作成日: 2026-07-05
対象業種: 整体院・骨盤矯正サロン（架空店舗「からだ回復整体院サンプル」）
用途: 商談時に営業担当が読み上げ／再生して見せるデモ台本

> **注記**: 本台本は商談で人が読み上げる、またはスライド・PDFで会話例として見せるためのものである。
> **実際の音声合成・電話ボットによる自動音声デモ、録音デモの制作は本工程のスコープ外であり、後続フェーズ（実導入・音声収録フェーズ）で対応する。**

---

## 1. 商談オープニング（営業担当が話すトーク）

```
本日は「電話の取り逃し」についてお話しさせてください。

施術中や接客中に電話が鳴っても、手が離せずに出られないことはありませんか。
営業時間外にかかってきた新規のお問い合わせは、そのまま他の店舗に流れてしまっているかもしれません。

私たちがご提案するのは、電話を完全に自動化することではありません。
まずは「AIが一次受付をして、要件を聞き取り、内容をLINEやメールで即座に店舗様へお伝えする」ところから始めます。

実際にどんな受け答えになるか、サンプルの会話でご覧いただきます。
```

## 2. デモ会話例1: 営業時間外の新規問い合わせ（読み上げ用）

商談の場で、営業担当が「AI役」と「お客様役」の両方を読み分けて実演する、またはスライドで音声吹き出し風に見せる。

```
【お客様役】もしもし、そちらは今日まだ営業していますか。

【AI役】お電話ありがとうございます。からだ回復整体院サンプルでございます。
      ただいまの時間、施術者が施術中のためAIスタッフがご用件をお伺いしております。
      サービス向上のため、通話内容を録音・記録させていただいております。

【お客様役】あ、そうなんですね。腰が痛くて、初めてなんですけど予約したいです。

【AI役】ありがとうございます。初めての方は60分のカウンセリング付き体験コースがおすすめです。
      お名前を教えていただけますか。

【お客様役】山田です。

【AI役】山田様、ありがとうございます。ご希望の日時を第1希望から第3希望まで教えていただけますか。

【お客様役】明日の午後か、明後日の午前中がいいです。

【AI役】承知いたしました。頂いた内容を担当へ共有し、本日中に折り返しご連絡してご予約を確定いたします。
      お電話ありがとうございました。
```

**商談での見せ方のポイント**:
- 「この会話が終わった直後、店舗オーナーのLINEにはこう届きます」と、通知イメージ（下記3）を続けて見せる。
- 「AIは症状の診断や施術方針の判断をしていない」点を必ず口頭で補足する（差別化ポイント）。

## 3. デモ通知イメージ（LINE/メール通知サンプル）

```
【AI電話受付 通知】2026-07-05 21:14
お客様: 山田様（電話番号: 090-XXXX-XXXX）
区分: 新規予約ヒアリング（初回）
内容: 腰の痛みで来店希望。60分体験コース案内済み。
希望日時: 第1希望 明日午後／第2希望 明後日午前
録音: あり（同意取得済み）
対応: 本日中に折り返し確定連絡をお願いします。
```

## 4. デモ会話例2: クレーム発生時（判断をしない設計を見せる）

```
【お客様役】前回施術を受けてから腰の調子が悪くなった気がするんですけど。

【AI役】ご心配とご不便をおかけし、申し訳ございません。
      体調に関わる大切なご連絡ですので、私からその場でお答えするのではなく、
      担当施術者または責任者に直接確認のうえ、折り返しご連絡させていただきたく存じます。

【お客様役】早く連絡ください。

【AI役】承知いたしました。この内容は重要案件として即時、責任者へ共有いたします。
      本日中に折り返しお電話いたします。
      もし強い痛みや体調の急変がある場合は、すぐに医療機関へのご相談をお願いいたします。
```

**商談での訴求ポイント**:
```
ご覧の通り、AIはクレームに対してその場で謝罪や返金判断、症状の評価を一切行いません。
「担当者へ即時共有し、責任者が判断する」という設計にしているため、
医療や法律に関わるリスクをAIが負わない仕組みになっています。
```

## 5. クロージングトーク

```
今日お見せしたのは会話のサンプルです。
実際の音声での自動応答システムの構築は、貴店の情報（メニュー、料金、資格情報、
転送先の連絡方法など）を伺ったうえで、次のステップとして進めます。

まずは「電話の取り逃しがどれくらい発生しているか」を簡単に診断させていただく
無料の電話取り逃し診断からご案内できます。
```

（診断オファーの詳細は「電話取り逃し診断_営業文面.md」参照）

## 6. 台本運用メモ

- 本台本はすべて架空店舗を前提としたサンプルであり、実在の店舗を示すものではない。
- 商談相手の業種が美容室・修理業等の場合は、`ヒアリング項目.md`・`電話応答シナリオ.md`の構造を保ったまま、業種固有のキーワード（症状→故障内容、施術メニュー→サービスメニュー等）を差し替えて使用する。
- 音声ファイルでのデモ（実際の合成音声・録音）は、本工程では制作しない。次フェーズで音声合成ツールまたは電話ボットサービスと連携して制作する。
