# AI生成有無管理表テンプレート

作成日: 2026-07-05
目的: 納品する商品画像について「実写／AI生成／AI加工（実写+AI編集）」の区分を記録し、優良誤認表示・ステルスマーケティング規制（ステマ規制）への配慮を徹底するための管理表。
実データ入力用: `AI生成有無管理表テンプレ.csv`（同フォルダ）

## 使い方

1. 商品ごと・画像ごとに1行を追加する。
2. 「区分」は必ず以下のいずれかを選ぶ（曖昧な場合は「AI加工」を選ぶ）。
   - **実写**: 撮影のみ、AI加工なし
   - **AI生成**: 実写素材を使わず画像生成AIのみで作成
   - **AI加工**: 実写素材を背景変更・切り抜き・スタイル変換等でAI加工したもの
3. 「表示上の明記」欄は、その画像を掲載するページ・投稿でAI利用を表示するかどうかを記録する。
   - 商品ページのメイン画像等、実物と誤認されやすい箇所は明記を推奨する。
   - 明記文言の例: 「画像はイメージです（AI生成）」「本画像は生成AIで加工しています」
4. 納品前に必ず1名以上のダブルチェックを行い、「確認者」欄に記名する。

## 列の定義

| 列名 | 内容 |
|---|---|
| 商品ID | 社内管理用の商品番号 |
| 商品名 | 商品名（架空商品の場合はブランド名も記載） |
| 画像ファイル名 | 納品ファイル名 |
| 区分 | 実写／AI生成／AI加工 |
| 使用ツール | 例: ChatGPT Images 2.0 (gpt-image-2)、実機カメラ 等 |
| 生成・加工日 | YYYY-MM-DD |
| 作業担当者 | 作成した担当者名 |
| 確認者 | ダブルチェックを行った担当者名 |
| 掲載先 | EC商品ページ／SNS／広告／その他 |
| 表示上のAI利用明記 | 有／無（有の場合は文言も記載） |
| 誤認リスク配慮メモ | 効能・サイズ感・素材感等、実物との差異が生じうる点への配慮内容 |

## 法規制上の配慮事項（必読）

- **景品表示法（優良誤認表示）**: 実物より著しく優れているかのように見せる画像は使用しない。色・サイズ・質感は実物準拠を必須とする。
- **ステルスマーケティング規制（景表法上の指定告示、2023年10月施行）**: 広告であることを隠して表示しない。AI生成・加工である旨は、誤認のおそれがある場合は明記する。
- **食品・コスメ等の効能表示**: 本テンプレートは雑貨カテゴリを想定しているが、他カテゴリに展開する場合は、効能・健康効果を暗示する表現がないか追加でチェックする。
- 管理表は納品物の一部として保管し、クライアントからの問い合わせ（「これはAI生成ですか」等）に即答できるようにする。
