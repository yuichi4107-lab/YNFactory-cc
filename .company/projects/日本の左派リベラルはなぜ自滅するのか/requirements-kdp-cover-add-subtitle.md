# KDP表紙 サブタイトル追加要件定義書

- 確定日: 2026-08-02
- 対象書籍: 『日本の左派・リベラルは、なぜ自滅するのか』
- 編集対象: `KDP出版用/cover.png`
- 編集方式: built-in `image_gen` による既存画像編集

## ゴール

現行表紙のポップなデザインと既存情報を維持したまま、正式サブタイトル「最大の敵は保守ではない。自分たち自身である。」を読みやすく追加する。主タイトルを最優先とする情報階層を崩さず、KDPサムネイルでも新しいサブタイトルを識別できる表紙にする。

## スコープ

### 実施すること

1. 現行 `cover.png` を編集対象画像として使用する。
2. 以下のサブタイトルを一字一句正確に追加する。
   - 最大の敵は保守ではない。自分たち自身である。
3. サブタイトルを、主タイトル直下、または主タイトルと吹き出しの間に置く。
4. 濃紫または濃紺の細い帯へ白文字で配置し、1〜2行に収める。
5. 必要最小限の余白調整だけを行い、主タイトルを最大の文字階層として維持する。
6. 2:3縦長、1024×1536 PNGの仕様を維持する。

### 必ず維持するもの

- 既存書名「日本の左派・リベラルは、なぜ自滅するのか」
- 既存フック「その正義、なぜ届かない？」
- 既存補助文「排除ではなく、再生のための自己点検」
- 既存著者名「左派リベラル再点検室」
- 若い日本人編集者／有権者の人物、表情、ポーズ、画風
- 黄色、シアン、コーラル、紫の高彩度配色
- 主タイトルの大きさと最優先の文字階層
- 吹き出し、斜め帯、著者欄、背景図形、全体の雑誌広告レイアウト

### 実施しないこと

- 人物・背景・配色・画風・既存文言の描き直しや置換。
- 主タイトルの縮小、フック・補助文・著者名の削除。
- 指定された5文言以外の文字、英語、数字、記号的コピーの追加。
- 実在人物、政党ロゴ、国旗・党旗、選挙ポスター、バーコード、ISBN、透かしの追加。
- 背表紙・裏表紙・3D書影・端末モックアップの作成。

## 完了条件

- [ ] サブタイトルが一字一句正しく追加されている。
- [ ] サブタイトルが濃紫／濃紺の細帯に白文字、1〜2行で表示されている。
- [ ] サブタイトルの位置が主タイトル直下、または主タイトルと吹き出しの間である。
- [ ] 既存4文言が一字一句変わらず残っている。
- [ ] 人物、配色、主タイトルの大きさ、吹き出し、斜め帯、著者欄が保持されている。
- [ ] 主タイトルが最大の文字階層のままである。
- [ ] 指定外の文字、文字化け、重複文字、透かしがない。
- [ ] PNG、1024×1536、2:3縦長を維持している。
- [ ] 幅100px相当でも主タイトル、フック、サブタイトルの役割を識別できる。

## 品質基準（100点）

| 項目 | 配点 |
|---|---:|
| 追加サブタイトルの正確性 | 25 |
| 既存4文言の完全保持 | 20 |
| 人物・配色・画風・既存レイアウト要素の保持 | 20 |
| 細帯、白文字、1〜2行、主タイトルを妨げない配置 | 15 |
| 主タイトル最優先とサムネイル視認性 | 10 |
| 1024×1536・2:3・PNGの技術仕様 | 5 |
| 指定外文字・禁止要素・透かしがない | 5 |

合格基準: 85点以上。サブタイトルの誤字・欠落、既存4文言の改変、主タイトルの優先順位低下、寸法不一致は配点にかかわらず不合格とする。
