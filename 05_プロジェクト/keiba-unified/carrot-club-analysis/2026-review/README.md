# キャロットクラブ出資検討 (2026年度募集)

過去3年(2020〜2022年募集)の全276頭のデビュー後成績を netkeiba から照会し、
出資検討基準を導出して2026年度募集馬94頭を採点したプロジェクト。

## 成果物

- **キャロット2026検討.xlsx** — メインの検討資料
  - `募集馬一覧`: 確定94頭(2026/8/1確定・8/18測尺反映)。価格・測尺・予定厩舎・母年齢・産駒数・基準スコア(6点満点)・スコア内訳
  - `検討基準`: 過去276頭の分析から導出したスコア基準と厩舎相性
  - `過去募集馬成績`: 2020-22年募集276頭の成績・回収率・スコア(答え合わせ用)

- **キャロット2026_統合検討.xlsx** — 本ディレクトリの分析と、親ディレクトリの
  母馬優先枠の推計を1冊にまとめたもの。「走るか」と「当たるか」を横に並べて見る
  - `統合判断表`: 94頭を1行1頭で。スコア(6点満点)と母馬優先枠が埋まる確率を並べ、
    掛け合わせた判断区分を付けた表。見出しの色が列の出自を表す
    (紺=成績分析／緑=母馬優先枠の推計／茶=統合して足した列)
  - `読み方`: 判断区分の定義・確率の意味・注意点
  - `検討基準`: スコアの定義と過去実績(`キャロット2026検討.xlsx` から)
  - `母馬優先枠の予測`: 母馬優先対象57頭を確率順(親の `data/forecast_2026.csv` から)
  - `過去募集馬成績`: 276頭(`キャロット2026検討.xlsx` から)

### 判断区分

スコア別の勝ち上がり実績(走るか)と、母馬優先枠が埋まる確率(当たるか)の掛け合わせ。
確率50%以上を「人気(competitive)」と見なす。母馬優先対象外の37頭は枠の食い合いが
ないので「取りやすい」側に置いている。

| 区分 | 条件 | 頭数 |
|---|---|---|
| S 最有力 | スコア5以上 × 枠が埋まりにくい | 9頭 |
| A 有力 | スコア4 × 枠が埋まりにくい | 28頭 |
| A 有力(人気) | スコア5以上 × 枠が埋まる見込み | 7頭 |
| B 検討 | スコア4 × 枠が埋まる見込み | 7頭 |
| C 見送り寄り | スコア3以下 | 43頭 |

回避条件(メス430kg未満・勝ち上がり42%)に該当する17頭は、区分とは独立に別列で印を付けている。

### 統合して見えたこと

スコア6は3頭だが、母馬優先枠が埋まる確率は大きく違う。

| 馬名 | 父 | 総額 | 予定厩舎 | 枠が埋まる確率 | 区分 |
|---|---|---|---|---|---|
| アンフィトリテの25 | モーリス | 5,000万 | 林徹 | 80% | A 有力(人気) |
| メサルティムの25 | アドマイヤマーズ | 4,000万 | 杉山佳明 | 61% | A 有力(人気) |
| **ヴィルデローゼの25** | ニューイヤーズデイ | 4,000万 | 松永幹夫(相性◎) | **9%** | **S 最有力** |

ヴィルデローゼの25だけが「走る見込みが高いのに競争が緩い」位置にいる。
どちらか片方の分析だけでは出てこない結論。

## スコア基準 (各1点・6点満点)

| 条件 | 根拠(過去276頭) |
|---|---|
| 牡馬 | 勝ち上がり74% vs メス56% |
| 3〜4月生まれ | 3月74% vs 2月55% |
| ノーザンF生産 | 重賞勝ち16頭すべてノーザンF系 |
| 母年齢8〜11歳 | 勝ち上がり67%・回収≥1が30%でピーク |
| 募集総額2500〜5999万円 | 2500-3999万帯が回収最良。8000万+は回収率最低 |
| 募集時馬体重430kg以上 | 430未満のメスは勝ち上がり42% |

過去実績: スコア6=勝ち上がり100%(12頭) / スコア5=82% / スコア4=67% / 3以下=55%

## ディレクトリ

- `scripts/` — netkeiba照会・Excel生成スクリプト(レート制限3秒・HTMLキャッシュ付き)
  - `build_unified.py`: 統合Excelの生成。スクリプト自身の位置を基準にパスを解決するので
    実行時のカレントディレクトリは問わない(要 openpyxl)

    ```bash
    python3 scripts/build_unified.py
    ```

    入力は親ディレクトリの `data/forecast_2026.csv`・`data/bosyu_2026.csv` と、
    本ディレクトリの `キャロット2026検討.xlsx` の3点。94頭・母馬優先57頭で
    揃わなければ assert で止まる
- `datasets/` — 照会結果データ
  - `roster.csv`: 過去3年の募集馬276頭(検討Excelから抽出)
  - `final_results.json`: 276頭のnetkeiba成績(父名照合で全頭検証済み)
  - `dams2026_v3.json`: 2026年募集馬の母情報(母馬ID基準で産駒数を確定)
  - `kakutei.json`: 2026年確定94頭(確定PDF由来)

## 注意

- 回収率 = 賞金(中央+地方) / 募集総額。進上金・維持費・メスの繁殖価値は未考慮
- 2022年募集世代は現役馬が多く数値は今後変動する
- netkeibaのHTMLキャッシュ(`nk_cache/`)はコミット対象外
- 統合Excelは2つの分析の結合であって、新しい推計をしているわけではない。
  94頭・母馬優先57頭が両分析で一致すること、スコア・厩舎相性・枠が埋まる確率が
  元データと一致することを確認済み
