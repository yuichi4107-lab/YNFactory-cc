# STEP13 2026年度募集（2025年産）の母馬優先枠 申込口数の予測

## 13-1. 何を出したか

**2026年度募集の母馬優先対象馬 57頭それぞれについて、
母馬優先枠への申込口数 D と「枠が埋まって母馬優先者どうしの抽選になる確率」を予測した。**

その母馬の**過去の産駒の申込実績**に、**母馬の馬齢**と**退会による減衰**を効かせて外挿する。

- 一覧：`data/forecast_2026.csv`（57頭）
- 再現：`python3 model/forecast2026.py`
- 出力：`data/forecast2026_output.txt`

## 13-2. モデル

```
log D(母馬, 年) = m(母馬) − λ·(年 − 2026) + ε      ε ~ N(0, σ_f)

  m(母馬) … その母馬の水準（有資格者数 E と母系の格。2026年基準）
  λ       … 1年あたりの減衰（退会 ＋ 産次が進むことによる権利行使率の低下）
  σ_f     … その年の産駒しだいのブレ（父・性別・馬体・価格・厩舎）

母馬優先枠が埋まる ⇔ D ≧ 200口（地方入厩予定馬は総口数100口なので 50口）
```

m(母馬) を過去の観測から推定して2026年に外挿する。観測は2種類。

| 観測 | 内容 | 情報量 | 該当頭数 |
|---|---|---|---|
| **中間発表の申込口数**（2024・2025年度） | D の直接観測（→ `docs/08`） | 強い | 29頭 |
| **抽選ランク**（2021〜2025年度） | D ≧ 200 か否かの打ち切り観測 | 弱い | 18頭 |
| なし（初仔など） | 母馬の馬齢だけから事前分布 | — | 10頭 |

同じ年に両方ある場合は、**その年の潜在量 L を積分して1回の尤度にまとめている**。
別々の観測として掛けると産駒のブレ σ_f を二重に数えて過信になるため。

### パラメータの出どころ

| 記号 | 値 | 根拠 |
|---|---|---|
| σ_tot | 1.0 | 母馬をまたいだ log D のばらつき（`members.py` と共通） |
| ρ | 0.73 | 同一母馬の連年相関（`docs/07` のテトラコリック相関） |
| σ_dam | 0.854 | = σ_tot·√ρ |
| σ_f | 0.520 | = σ_tot·√(1−ρ)。中間発表の連年ペア9頭から出る 0.38 とも整合 |
| **λ** | **0.085** | 連年ペア103組の遷移表。前年に埋まった30.1% → 翌年27.2% のシフト |
| g | 3.2 | 中間発表（締切24時間前）から最終値への伸び（`docs/08` の較正値） |
| σ_m | 0.35 | その伸びのばらつき（1.5〜3.8倍に開く） |

> **λ が横断的な勾配（0.237）よりずっと小さいことが重要。**
> 母馬の馬齢を横断的に見たときの勾配には**世代効果**（昔の募集は1口が安く、
> 1人あたり口数が多かったので有資格者数 S がそもそも少ない）が乗っている。
> 1年先の予測に使うべきは、同じ母馬を追いかけた within の 0.085。
> **年8%程度の減衰**で、うち退会が4.5%、残りが産次による行使率の低下。

事前分布は `dam_age.py` のプロビット `P(埋まる) = Φ(1.909 − 0.2372·t)` を
log D の水準に読み替えたもの（ばらつき σ_dam）。

## 13-3. バックテスト — 同じ手順で過去を当てにいく

その年より**前**の観測だけを使って予測し、実際の結果と突き合わせた。

| 対象年 | 頭数 | 予測の平均 | 実際 | AUC | ブライアスコア |
|---|---|---|---|---|---|
| 2023年度 | 49頭 | 34% | **24%** | 0.76 | 0.173 |
| 2024年度 | 59頭 | 34% | 34% | 0.79 | 0.174 |
| 2025年度 | 53頭 | 35% | 34% | 0.78 | 0.179 |

- **AUC 0.76〜0.79** … 埋まる馬と余る馬の並べ替えはかなり効いている（0.5がでたらめ）
- **ブライアスコア 0.17〜0.18** … 全頭に一律34%と答えるだけのモデル（0.224）より2割良い
- 較正は2024・2025年度でほぼ完璧。**2023年度だけ10ポイント外している**

2023年度の外し方が重要で、これは**年ごとの共通ショック**（その年の募集全体の需給）
であってモデルでは読めない。予測の幅にはこれを織り込む必要がある。

## 13-4. 予測結果

### 全体

```
枠が埋まる（母馬優先者どうしの抽選になる）と見込まれる頭数
  = 21.9頭 / 57頭 = 38%
  8割の幅で 16〜28頭（28%〜49%）
```

内訳の不確実性：

| 要因 | 幅 |
|---|---|
| 個々の母馬のばらつき | ±3.1頭 |
| 年ごとの共通ショック（実測24〜40%の幅から） | ±3.4頭 |

実測の推移は 2021年度40% → 2022年度39% → 2023年度24% → 2024年度34% → 2025年度34%。
**2026年度は例年よりやや高めの38%**という予測になる。

理由は母馬の顔ぶれで、**57頭中47頭（82%）が過去5年にも産駒を出している常連**、
うち33頭は2年以上の実績がある。過去に枠を埋めた実績のある母馬が多い。

| 13歳以上 | 21頭 | 75口 | 4.0頭 = 19% |

（アンフィトリテ・フィニフティ・コンダクトレス・クルークハイト・リカビトス）が
たまたま集まっているため。馬齢だけの傾向とは別に、個々の実績が効いている。

## 13-5. 感度：減衰 λ の置き方

| λ | 意味 | 埋まる期待頭数 | 割合 |
|---|---|---|---|
| 0.000 | 減衰なし（退会も行使率低下も無し） | 23.8頭 | 42% |
| 0.046 | 退会4.5%だけ | 22.8頭 | 40% |
| **0.085** | **連年ペアの遷移から（既定）** | **21.9頭** | **38%** |
| 0.150 | 中間 | 20.3頭 | 36% |
| 0.237 | 馬齢の横断的勾配をそのまま使う | 18.6頭 | 33% |

**減衰の置き方で期待頭数は数頭しか動かない。**
個々の母馬の過去の観測のほうがはるかに効いている。
つまり「退会率をいくつに置くか」は、この予測の主要な不確実性ではない。

## 13-6. この予測の弱点

1. **募集馬リストは POG の募集予定馬リスト（2026年8月時点）。**
   クラブ公式の募集馬一覧はまだ2025年度募集を表示しており、
   2026年度のカタログ電子版は8月22日公開予定。**頭数・価格・厩舎は変わりうる**
   （実際すでに「募集予定から消えた馬」が6頭いる）
2. **母馬優先対象の判定に2頭の食い違いがある。**
   POG が「母親優先」と記した マラコスタムブラダ と エレガントマナー は、
   クラブ自身の過去の分類（2024年度・2021年度）では**非対象**だった。
   本予測からは外している。57頭か59頭かはカタログで確認が必要
3. **年ごとの共通ショックは読めない。** 2023年度が24%まで落ちた理由が
   分かっていないので、同じことが起きれば全体が下振れする
4. **「馬齢のみ」の10頭は母馬の馬齢しか情報がない。**
   予測Dの幅が 91〜1,167口 と極端に広く、実質「その年齢の平均」を言っているだけ
5. **産駒側の情報（父・馬体・価格）をモデルに入れていない。**
   `docs/07` の 11-9b では、馬体重の増減や性別の転換が実際に効いていた。
   カタログ公開後に測尺が出れば、そこを織り込んで精度を上げられる
6. **σ_tot = 1.0 は `members.py` からの仮定値。** 予測Dの絶対値はこれに依存する
   （確率のほうは相対的なので影響は小さい）
