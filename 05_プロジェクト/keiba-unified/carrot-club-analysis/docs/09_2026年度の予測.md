# STEP13 2026年度募集（2025年産）の母馬優先枠 申込口数の予測

## 13-1. 何を出したか

**2026年度募集の母馬優先対象馬 57頭それぞれについて、
母馬優先枠への申込口数 D と「枠が埋まって母馬優先者どうしの抽選になる確率」を予測した。**

その母馬の**過去の産駒の申込実績**に、**母馬の馬齢**と**退会による減衰**、
さらに**その年の産駒の馬体重**を効かせて外挿する。

- 募集馬リスト：`data/bosyu_2026.csv`（94頭。クラブ確定一覧 2026/8/1 版）
- 一覧：`data/forecast_2026.csv`（母馬優先対象57頭）
- 再現：`python3 model/forecast2026.py`
- 出力：`data/forecast2026_output.txt`

## 13-2. モデル

```
log D(母馬, 年) = m(母馬) − λ·(年 − 2026) + ε      ε ~ N(0, σ_f)

  m(母馬) … その母馬の水準（有資格者数 E と母系の格。2026年基準）
  λ       … 1年あたりの減衰（退会 ＋ 産次が進むことによる権利行使率の低下）
  σ_f     … その年の産駒しだいのブレ（父・性別・馬体・価格・厩舎）

母馬優先枠が埋まる ⇔ D ≧ 200口（地方入厩予定馬は総口数100口なので 50口）
```

m(母馬) を過去の観測から推定して2026年に外挿する。観測は2種類。

| 観測 | 内容 | 情報量 | 該当頭数 |
|---|---|---|---|
| **中間発表の申込口数**（2024・2025年度） | D の直接観測（→ `docs/08`） | 強い | 29頭 |
| **抽選ランク**（2021〜2025年度） | D ≧ 200 か否かの打ち切り観測 | 弱い | 18頭 |
| なし（初仔など） | 母馬の馬齢だけから事前分布 | — | 10頭 |

これに加えて、**その年の産駒の馬体重**を補正項として乗せる（13-2b）。

同じ年に両方ある場合は、**その年の潜在量 L を積分して1回の尤度にまとめている**。
別々の観測として掛けると産駒のブレ σ_f を二重に数えて過信になるため。

### パラメータの出どころ

| 記号 | 値 | 根拠 |
|---|---|---|
| σ_tot | 1.0 | 母馬をまたいだ log D のばらつき（`members.py` と共通） |
| ρ | 0.73 | 同一母馬の連年相関（`docs/07` のテトラコリック相関） |
| σ_dam | 0.854 | = σ_tot·√ρ |
| σ_f | 0.520 | = σ_tot·√(1−ρ)。中間発表の連年ペア9頭から出る 0.38 とも整合 |
| **λ** | **0.085** | 連年ペア103組の遷移表。前年に埋まった30.1% → 翌年27.2% のシフト |
| g | 3.2 | 中間発表（締切24時間前）から最終値への伸び（`docs/08` の較正値） |
| σ_m | 0.35 | その伸びのばらつき（1.5〜3.8倍に開く） |

> **λ が横断的な勾配（0.237）よりずっと小さいことが重要。**
> 母馬の馬齢を横断的に見たときの勾配には**世代効果**（昔の募集は1口が安く、
> 1人あたり口数が多かったので有資格者数 S がそもそも少ない）が乗っている。
> 1年先の予測に使うべきは、同じ母馬を追いかけた within の 0.085。
> **年8%程度の減衰**で、うち退会が4.5%、残りが産次による行使率の低下。

事前分布は `dam_age.py` のプロビット `P(埋まる) = Φ(1.909 − 0.2372·t)` を
log D の水準に読み替えたもの（ばらつき σ_dam）。

## 13-2b. 産駒側の変数を入れる — 馬体重だけが効いた

母馬側の要因が73%、産駒側が27%（`docs/07`）。この27%を予測に使えないか、
募集馬カタログの数値で試した。

2021・2022年度の母馬優先対象**92頭**について、抽選ランクと
カタログ掲載の馬体重・性別・募集価格・産駒数（何番仔）を突き合わせた。

### 産駒数（何番仔）は母馬の馬齢と分離できない

`docs/06` で「産次が進むほど権利行使率が下がる」交絡を挙げていたが、実データでは

```
corr(経過年数 t, 産駒数) = +0.97
```

**ほぼ完全に同じ変数**だった。クラブの繁殖牝馬は引退後ほぼ毎年産駒を出すので当然ではある。
つまり「馬齢の効果」と「産次の効果」は、**この観測からは原理的に分離できない**。
`docs/06` の λ/σ に両方が混ざっているという指摘は正しいが、
**分解する方法はこのデータには無い**、というのが結論。

| 産駒数 | 枠内抽選 | 割合 |
|---|---|---|
| 1番仔 | 10/16 | 62% |
| 2番仔 | 11/18 | 61% |
| 3番仔 | 6/10 | 60% |
| 4番仔 | 5/13 | 38% |
| 5番仔 | 1/9 | 11% |
| 6番仔以降 | 3/26 | 12% |

### 馬体重は母馬の馬齢と独立に効く

一方、馬体重は t との相関が **+0.29** しかなく、独立な情報を持っている。
価格（相関 −0.00）と性別も試したが、こちらは有意でなかった。

| プロビット（n=92） | 係数 | z |
|---|---|---|
| t（経過年数） | −0.279 | −4.02 |
| **馬体重（年内平均から10kgごと）** | **+0.123** | **+2.32** |
| log 募集価格 | +0.374 | +0.66（有意でない） |
| 牡馬ダミー | −0.449 | −0.87（有意でない） |

ただし**生の分布を見ると線形ではない**。

| 年内平均からの馬体重差 | 枠内抽選 | 割合 |
|---|---|---|
| −30kg以下 | 4/15 | **27%** |
| −30〜−10kg | 9/19 | 47% |
| −10〜+10kg | 9/24 | 38% |
| +10〜+30kg | 9/22 | 41% |
| +30kg以上 | 5/12 | 42% |

**落ちるのは軽い側だけで、重い側に上乗せは無い。**
仕様を比べると AIC は 線形 104.88 ／ 下方向だけ線形 105.05 ／ 軽い馬ダミー 106.32 で
線形が僅差の最良だが、**差0.2は誤差の範囲**。
重い側へ外挿すると最大2.2倍まで効いてしまい根拠に乏しいので、
**「年内平均より軽い側にだけ減点する」仕様を採用した**（β = +0.195 / 10kg、z = +2.27）。

さらに片側だけの減点は全体を下へずらしてバックテスト済みの較正を壊すので、
**対象57頭の中で平均ゼロになるよう中心化**している。
結果として補正は年内の相対的な並べ替えにしか効かず、期待頭数は 21.9頭 → 22.5頭 とほぼ動かない。

補正の幅は **×0.45〜×1.18**。いちばん下げたのはシーリア（402kg・×0.54・確率 −33ポイント）、
レシステンシア（393kg・×0.45）、リカビトス（410kg・×0.63）。

> **この馬体重の項だけはバックテストできていない。**
> カタログの馬体重が手元にあるのは2020〜2022年度と2026年度で、
> バックテストの対象年（2023〜2025年度）には無い。
> `data/forecast_2026.csv` に**馬体重を使わない確率**も併記してあるので、
> 信用しない場合はそちらを見てほしい。

## 13-3. バックテスト — 同じ手順で過去を当てにいく

その年より**前**の観測だけを使って予測し、実際の結果と突き合わせた。

| 対象年 | 頭数 | 予測の平均 | 実際 | AUC | ブライアスコア |
|---|---|---|---|---|---|
| 2023年度 | 49頭 | 34% | **24%** | 0.76 | 0.173 |
| 2024年度 | 59頭 | 34% | 34% | 0.79 | 0.174 |
| 2025年度 | 53頭 | 35% | 34% | 0.78 | 0.179 |

- **AUC 0.76〜0.79** … 埋まる馬と余る馬の並べ替えはかなり効いている（0.5がでたらめ）
- **ブライアスコア 0.17〜0.18** … 全頭に一律34%と答えるだけのモデル（0.224）より2割良い
- 較正は2024・2025年度でほぼ完璧。**2023年度だけ10ポイント外している**

2023年度の外し方が重要で、これは**年ごとの共通ショック**（その年の募集全体の需給）
であってモデルでは読めない。予測の幅にはこれを織り込む必要がある。

## 13-4. 予測結果

### 全体

```
枠が埋まる（母馬優先者どうしの抽選になる）と見込まれる頭数
  = 22.5頭 / 57頭 = 40%
  8割の幅で 17〜28頭（29%〜50%）
```

内訳の不確実性：

| 要因 | 幅 |
|---|---|
| 個々の母馬のばらつき | ±3.1頭 |
| 年ごとの共通ショック（実測24〜40%の幅から） | ±3.4頭 |

実測の推移は 2021年度40% → 2022年度39% → 2023年度24% → 2024年度34% → 2025年度34%。
**2026年度は例年よりやや高めの40%**という予測になる。

理由は母馬の顔ぶれで、**57頭中47頭（82%）が過去5年にも産駒を出している常連**、
うち33頭は2年以上の実績がある。過去に枠を埋めた実績のある母馬が多い。

### 母馬の馬齢帯ごと

| 母馬の馬齢 | 頭数 | 予測Dの中央値 | 埋まる期待頭数 |

| 5〜8歳 | 7頭 | 303口 | 4.5頭 = 64% |
| 9〜10歳 | 16頭 | 176口 | 7.7頭 = 48% |
| 11〜12歳 | 13頭 | 158口 | 5.9頭 = 45% |
| 13歳以上 | 21頭 | 74口 | 4.5頭 = 21% |

9〜10歳と11〜12歳がほぼ並ぶのは、11〜12歳に**過去に枠を埋めた実績のある母馬**
（アンフィトリテ・フィニフティ・コンダクトレス・クルークハイト）が集まっている一方、
9〜10歳には実績のない初仔・2番仔が混じっているため。
**馬齢だけの傾向より、個々の母馬の実績のほうが強く効いている。**

## 13-5. 感度：減衰 λ の置き方

| λ | 意味 | 埋まる期待頭数 | 割合 |
|---|---|---|---|
| 0.000 | 減衰なし（退会も行使率低下も無し） | 25.9頭 | 45% |
| 0.046 | 退会4.5%だけ | 24.6頭 | 43% |
| **0.085** | **連年ペアの遷移から（既定）** | **23.5頭** | **41%** |
| 0.150 | 中間 | 21.7頭 | 38% |
| 0.237 | 馬齢の横断的勾配をそのまま使う | 19.7頭 | 35% |

（この感度表は馬体重補正を入れない素の値。補正を入れた既定値は 22.5頭）

**減衰の置き方で期待頭数は数頭しか動かない。**
個々の母馬の過去の観測のほうがはるかに効いている。
つまり「退会率をいくつに置くか」は、この予測の主要な不確実性ではない。

## 13-6. この予測の弱点

1. **馬体重の項だけバックテストできていない。**
   カタログの馬体重が手元にあるのは2020〜2022年度と2026年度で、
   バックテストの対象年（2023〜2025年度）には無い。
   n=92 の推定（z=+2.27）で、係数の標準誤差は予測幅に足し込んであるが、
   検証は次年度以降になる。`data/forecast_2026.csv` の
   **「馬体重を使わない確率」**列を見れば補正前の値が分かる
2. **年ごとの共通ショックは読めない。** 2023年度が24%まで落ちた理由が
   分かっていないので、同じことが起きれば全体が下振れする
3. **「馬齢のみ」の10頭は母馬の馬齢しか情報がない。**
   予測Dの幅が 85〜1,082口 と極端に広く、実質「その年齢の平均」を言っているだけ
4. **産駒数（何番仔）は使えなかった。** 母馬の馬齢との相関が +0.97 で、
   `docs/06` で挙げた「産次による行使率低下」の交絡は
   **このデータからは原理的に分離できない**（13-2b）
5. **父・厩舎・生産牧場はモデルに入れていない。**
   価格と性別は有意でなかったが、父の格（初年度産駒かどうか等）は
   `docs/07` の個別事例では効いていた。カテゴリ数が多く n=92 では推定できない
6. **σ_tot = 1.0 は `members.py` からの仮定値。** 予測Dの絶対値はこれに依存する
   （確率のほうは相対的なので影響は小さい）
