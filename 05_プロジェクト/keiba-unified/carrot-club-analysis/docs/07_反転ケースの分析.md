# STEP11 母馬単位で「途中から抽選対象になる」ケースの分析

## 11-1. 問いの立て方

母馬優先枠（200口）が埋まる条件は

```
D = E × u × m ≧ 200
  E … 母馬優先の有資格者数（母馬に出資していて今も会員の人）
  u … 権利行使率（有資格者のうち実際にその産駒に申し込む割合）
  m … 母馬優先で申し込む人の1人あたり口数
```

E は退会で毎年 4.5% ずつ減る**一方通行**なので、普通は年を追うごとに埋まりにくくなる。
にもかかわらず「前年は枠が余ったのに今年は抽選になった」＝**反転**が起きるということは、
u × m が E の減少を上回って上昇したということ。

- どれくらいの頻度で起きるのか
- どれくらい u×m が跳ねる必要があるのか
- 母馬側の事情と産駒側の事情の、どちらがどれだけ効いているのか

を5年分（2021〜2025年度、母馬優先対象 253頭・実母馬116頭・連年ペア103組）で調べた。

再現：`python3 model/reversal.py`（出力は `data/reversal_output.txt`）

## 11-2. 反転はどのくらい起きるか

|  | 翌年：埋まる | 翌年：余る |
|---|---|---|
| **当年：埋まる** | 19 | 12 |
| **当年：余る** | **9** | 63 |

```
継続率 P(埋 | 前年 埋) = 19/31 = 61%
反転率 P(埋 | 前年 余) =  9/72 = 12%
オッズ比 = 11.1
```

**前年に枠が余った馬が翌年に抽選になる確率は12%。** 8頭に1頭弱。
逆に前年に埋まった馬は61%で翌年も埋まる。粘着性はかなり強い。

## 11-3. 反転の中身を分ける — 「産駒が人気になった」のか「優先権者だけが動いた」のか

抽選ランクは2軸（枠内＝母馬優先枠／枠外＝優先権を持たない層）でできている。
**枠外ランクが動いていなければ、その産駒の一般人気は前年と変わっていない。**
それでも枠内の結果が変わったなら、動いたのは母馬優先権者だけということになる。

| 型 | 反転 | 悪化 |
|---|---|---|
| 連動型（枠外が2段階以上動いた＝産駒の人気そのものが変わった） | 4件 | 5件 |
| やや連動（1段階） | 1件 | 5件 |
| **母馬側だけが動いた（枠外は不変）** | **4件** | 2件 |

**反転9件のうち4件は枠外がD→Dで動いていない**
（セレナズヴォイス・ブルーメンクローネ・エスティタート・ビットレート）。
産駒全体の人気は据え置きなのに母馬優先枠だけが埋まった。
つまり**反転の半分近くは「産駒が人気化したから」ではなく「優先権を持つ層だけが動いたから」**。

逆側では、リカビトス（枠外C→C）とエスティタート（D→D）が
枠外不変のまま枠内だけ余った。**有資格者が実際に減ったと読める、退会のもっとも素直な現れ方。**

シンハライトは枠外A→Bで依然として全体最上位人気なのに枠内は余った。
母馬12歳で優先権を持つ層が薄くなり、人気は一般層が支えている構図。

## 11-4. しきい値のすぐ近くで往復している母馬

同じ母馬が期間中に反転も悪化も両方経験していれば、その母馬の申込口数は
200口のすぐ近くにあって、産駒側の小さなブレで行ったり来たりしている。

```
エスティタート  （2013年産） 2021:埋 → 2022:余 → 2023:埋 → 2025:余
プルメリアスター （2012年産） 2021:埋 → 2022:埋 → 2023:余 → 2024:埋 → 2025:埋
```

反転9件のうち2件、悪化12件のうち2件がこの2頭から出ている。
**「一度余ったら終わり」ではなく、境界付近の母馬は毎年コインを投げている。**

3年以上続けて産駒が募集された母馬40頭のうち、途中で反転したのは6頭。
残りは一貫して埋まり続ける（パドゥヴァルス・クルークハイト）か、
一貫して余り続ける（ローズノーブル・グリューヴァインなど）か、
一度落ちてそのまま（ピースエンブレム・ココファンタジアなど）だった。

## 11-5. 母馬要因と産駒要因の分解（テトラコリック相関）

「枠が埋まるか」の背後に連続量 log D があり

```
log D =（母馬固有の水準）＋（その年の産駒固有のブレ）
```

と分解できると考えると、同一母馬の連年2値の**テトラコリック相関 ρ が母馬要因の分散比**になる。
103組の遷移表から推定すると

```
ρ = 0.73
  母馬要因（有資格者数・母系の格）              … 73%
  産駒要因（父・馬体・価格・性別・上の仔の成績） … 27%
```

**73%は母馬側で決まるが、残る27%はその年の仔次第。**
この産駒側のブレが、退会による右肩下がりを押し戻して反転を起こしている。

## 11-6. 反転に必要な「行使率 × 口数」の倍率

D ~ 対数正規（σ=1.0）で P(D≧200口)=34% に合わせると中央値は132口。
E は退会で年4.5%減るので、その分も取り返す必要がある。

| 前年の位置（枠が余った馬の中で） | 前年の D | 反転に必要な u×m の倍率 |
|---|---|---|
| 上位10%（あと一歩） | 168口 | **1.25倍** |
| 上位25% | 131口 | 1.60倍 |
| 中央値 | 85口 | 2.46倍 |
| 下位25% | 50口 | 4.19倍 |
| 下位10%（かなり遠い） | 29口 | 7.13倍 |

閾値のすぐ下でも1.2〜1.3倍、中央値なら2倍強、不人気なら3〜5倍。
**「じわじわ増えて越える」経路は存在しない**（E は減る一方なので）。
産駒側で何かが起きて u×m が跳ねないと反転しない。
逆に言えば、**反転が起きるのは「前年ぎりぎりで届かなかった馬」にほぼ限られる。**

## 11-7. 産駒の人気を揃えても、母馬の馬齢が効く

枠外ランクで産駒の一般人気を揃えたうえで、母馬の馬齢で切る（253頭）。

| 枠外ランク（＝一般人気） | 母馬 5〜10歳 | 母馬 11歳〜 |
|---|---|---|
| Ａ | 4/5 = 80% | 3/4 = 75% |
| Ｂ | 5/5 = 100% | 3/11 = 27% |
| Ｃ | 16/21 = 76% | 11/20 = 55% |
| **Ｄ** | **40/68 = 59%** | **4/79 = 5%** |
| Ｅ | 0/15 = 0% | 0/25 = 0% |
| 合計 | 65/114 = 57% | 21/139 = 15% |

**産駒の人気が同じ「Ｄ」でも、母馬が10歳以下なら59%、11歳以上なら5%。12倍の差。**
産駒の人気を揃えても母馬の馬齢はこれだけ効く。

一方、枠外Ａ（一般人気が最上位）まで来ると 80% vs 75% で差が消える。
**一般人気が突き抜けた馬は、母馬が何歳でも枠が埋まる。**

> ※ 母馬優先枠が余ると余剰が一般枠へ回る可能性があり、
> 枠内と枠外のランクは完全に独立ではない。この表は目安として読む。

## 11-8. 反転はどの年齢で起きるか

| 翌年時点の母馬の馬齢 | 前年に余ったペア | うち反転 | 反転率 |
|---|---|---|---|
| 7〜9歳 | 9件 | 4件 | **44%** |
| 10〜12歳 | 26件 | 5件 | 19% |
| 13歳〜 | 37件 | **0件** | **0%** |

**13歳以上の母馬からの反転はゼロ。反転の窓は12歳までで閉じる。**

これは 11-6 の倍率の話と整合する。高齢の母馬はすでに E が大きく削れていて、
必要な倍率が3〜5倍まで跳ね上がっているので、産駒側のブレでは届かない。

## 11-8b. 前年のどこを見れば、翌年の反転を読めるか — 直感と逆だった

前年に枠が余った72組を、前年の**枠外ランク**（＝優先権を持たない層からの人気）で分ける。

| 前年の枠外ランク | ペア | 翌年に反転 | 反転率 |
|---|---|---|---|
| Ｃ（最優先の段階で抽選＝人気） | 3件 | 0件 | 0% |
| Ｄ（一般枠で抽選＝中位） | 50件 | 5件 | 10% |
| **Ｅ（全口確定＝どこも抽選なし＝不人気）** | 19件 | **4件** | **21%** |

**予想と逆。前年の仔が不人気だった馬ほど翌年に反転している。**

読み方はこうなる。

- 前年に**枠外Ｄ以上なのに枠内が余った**＝「産駒には一般の需要があったのに
  母馬優先の層だけが薄かった」。つまり **E が本当に小さい**ことの証拠。翌年も余る。
- 前年に**枠外Ｅ**＝「その年の仔がたまたま外れだった」だけかもしれず、
  E の大小についての情報がほとんど無い。翌年に良い仔が出れば普通に埋まる。

つまり **枠外Ｅからの反転は平均への回帰、枠外Ｄからの余りは本物の枯渇**。

産駒の一般人気が前年からどう動いたかで切っても同じ向きになる。

| 枠外ランクの動き | ペア | 反転 | 反転率 |
|---|---|---|---|
| 1段階以上 改善 | 22件 | 5件 | **23%** |
| 不変 | 42件 | 4件 | 10% |
| 悪化 | 8件 | 0件 | 0% |

## 11-9. 「上の仔が走った」経路は1年では効きにくい（制度カレンダーの制約）

第1次募集の締切は9月上旬。ある年の募集で参照できる「上の仔の成績」は前年産駒の2歳夏まで。

```
2024年度募集（2023年産）… 2024年9月に出資確定
  → 2025年6〜8月にデビュー可能
  → 2025年度募集（2025年9月締切）の判断材料になるのは
     この夏にデビューできた早期組だけ
```

つまり「上の仔が走ったから下の仔に人が集まる」経路は
**早期デビュー組に限って1年で効き、それ以外は2年遅れで効く**。
反転をこの経路で説明するなら、その母馬の1つ上の仔が6〜8月にデビューして
好走しているはず——という検証可能な予測が立つ。

裏を返すと、**1年で反転した9件の多くは「上の仔の成績」では説明できない。**
残る候補は
(a) 種牡馬の格上げ（前年より人気種牡馬がついた）
(b) 母馬の全きょうだい・近親の活躍（上の仔以外）
(c) 募集価格が下がって m が増えた
(d) 前年の落選者が繰り越して申し込んだ（連続落選の優先度が上がる制度効果）
あたり。

とくに **(d) は制度が自動的に生む反転要因**で、無視できない。
前年に枠内で外れた人は翌年も同じ母馬の仔を狙う動機が強く、
落選実績が積み上がるほど当選しやすくなるので、
**「前年ぎりぎりで埋まらなかった馬」に翌年の申込が集まりやすい構造**になっている。

## 11-10. 実務的な結論

1. **前年に余った馬でも12%は翌年に抽選になる。** 「去年余ったから今年も大丈夫」は
   8頭に1頭で外れる
2. **ただし反転が起きるのは母馬12歳まで。** 13歳以上の母馬は5年で1件も反転していない。
   **高齢の母馬の仔は、母馬優先を持っていれば実質確実に通る**
3. **反転の半分近くは「産駒が人気化した」ではなく「優先権者だけが動いた」。**
   募集馬の一般的な人気（雑誌評価・POG人気）を見ていても察知できない
4. **「前年に一般人気も高かったのに枠内が余った母馬」はむしろ安全。**
   直感に反するが、それは E が本当に小さいことの証拠なので翌年も余る（反転率10%）。
   危ないのは逆に **前年にどこも抽選が起きなかった母馬**（反転率21%）。
   前年の結果が悪すぎて E の情報になっていないだけで、良い仔が出れば普通に埋まる
5. **境界付近の母馬（エスティタート型）は毎年振れる。**
   エスティタートは 埋→余→埋→余、プルメリアスターは 埋→埋→余→埋→埋。
   一度の結果で「この母馬は安全」と決めない
6. **前年に枠内で落選した人は翌年も同じ母馬の仔に集まりやすい。**
   落選実績が積み上がるほど当選順位が上がる制度なので、
   これは制度そのものが生む反転要因。11-9 の (d)

## データの弱点

1. **連年ペア103組・反転9件は依然として少ない。** 型の内訳（連動型4/やや連動1/母馬側だけ4）は
   1件動くと印象が変わる
2. **2022年度の残口馬は名簿から補完した推定。**
   一覧に載らない12頭を募集番号順の別表から拾い、母馬がキャロット所属馬名簿にいる5頭を
   母馬優先対象＝枠余りとした。参考ブログは「残口馬11頭」としており1頭ずれる
3. **2021年度には新規入会者枠（現在は廃止）があった。**
   この枠で抽選になった12頭は既存会員の枠が全口確定しているので「余り」扱いにしたが、
   制度が違う年であることは意識しておく
4. **σ=1.0 は members.py と揃えた仮定値。** 11-6 の倍率はこの σ に依存する
5. **テトラコリック相関は「連年ペアがある母馬」だけから計算している。**
   毎年産駒が出る母馬（＝繁殖として順調な母馬）に偏る
