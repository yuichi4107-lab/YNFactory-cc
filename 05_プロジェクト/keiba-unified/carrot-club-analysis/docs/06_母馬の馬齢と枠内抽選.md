# STEP10 母馬の馬齢と「母馬優先枠で抽選になるか」の関係

## 10-1. 何を調べたか

母馬優先枠（400口中200口）が埋まって**母馬優先者どうしの抽選**になるのは、
その母馬の有資格者が多い馬のはず。有資格者は

```
E = S（母馬の出資者実人数） × (1 − 退会率)^t
t = 産駒の募集年度 − 母馬の募集年度 ＝ 母馬の馬齢 − 1
```

なので、**若い母馬ほど枠が埋まりやすい**という予測が立つ。これを実データで検証した。

## 10-2. データの作り方

| 項目 | 出典・方法 |
|---|---|
| 抽選ランク（馬名つき） | クラブ公表の「第１次募集最終集計結果」2024年度・2025年度分 |
| 母馬優先枠が埋まったか | ランクの**数字**が 1〜4 なら埋まった（抽選発生）、5 なら余った |
| 母馬の生年 | 一口馬主DBの「キャロットクラブ所属馬一覧」を年産別（2000〜2021年産）に取得し、母馬名で突合 |

- 対象：**母馬優先対象馬 112頭**（2024年度 59頭＋2025年度 53頭）
- 母馬の生年は 112頭すべて特定できた（うち2頭はJBISで個別確認：ブロンディーヴァ 2017年産／カイカヨソウ 2010年産）
- データ本体：`data/dam_age_rank.csv` ／ 再現スクリプト：`model/dam_age.py`

なお **枠内抽選の割合は2024年度・2025年度とも34%** でぴたりと一致した。
年ごとのブレが小さいので、2年分をまとめて扱う。

## 10-4. 回帰

経過年数 t（＝馬齢−1）でロジスティック回帰すると


## 10-5. 退会率はどこまで読めるか

モデルでは「枠が埋まる ⇔ E×u×m ≧ 200」なので、両辺の対数をとると

```
枠内抽選 ⇔ log u ≧ c + t·λ      λ = −log(1 − 退会率)
log u ~ N(μ, σ) とすると  P(t) = Φ((μ − c − tλ)/σ)
```

つまり**プロビットの傾きが λ/σ** になる。実測では **λ/σ = 0.255**。

| σ（産駒ごとの行使率のばらつき） | 合計の年減衰率 |
|---|---|
| 0.20 | 5.0% |
| 0.30 | 7.4% |
| 0.40 | 9.7% |
| 0.50 | 12.0% |

**ただしこの「合計の年減衰率」は退会率そのものではない。** 交絡が3つある。

1. **産次が進むほど権利行使率が下がる** — 母馬が年を取るほど産駒は3番仔・4番仔になる。
   すでに上の仔に出資している人は下の仔を見送りやすいし、前の仔が走らなければなおさら。
   これは退会とまったく同じ向きに効く
2. **古い母馬ほど S（出資者実人数）が小さい** — 昔は1口価格が安く、1人あたり口数が多かった。
   `docs/02` の推計で2013年度募集 182人 → 2026年度募集 211人。さらに古い世代はもっと少ない
3. **地方馬（100口）が混じる** — 母馬が地方入厩馬だった場合、出資者は中央馬の1/4程度しかいない
   （例：カイカヨソウ 2010年産・南関東）

`docs/05` で別ルートから出した退会率は年3〜6%。
上の表と突き合わせると、**σ ≒ 0.35〜0.5、退会率3〜6%、残りの年3〜7%が行使率の低下**
という分解が整合的で、**観測された減衰の半分程度は「産次が進むことによる行使率の低下」**
とみるのが妥当。

## 10-6. 同じ母馬の連年産駒で見る

S が固定されるので、より厳密な比較になる。2024年度と2025年度の両方に産駒が出た母馬は30頭。

- 枠内抽選になった数：**2024年度 8頭 → 2025年度 6頭**
- 悪化（枠内→枠余り）4頭 ／ 改善（枠余り→枠内）2頭 ／ 変化なし 24頭

1年で正味 −2頭。方向は一致するが頭数が少なく、これ単独では有意とは言えない。
年を重ねてサンプルを増やせば、ここから退会率を直接測れる。

## 10-7. 実務的な示唆

1. **母馬優先を「確実に通したい」なら、高齢の母馬の仔を狙う。**
   母馬14歳以上なら、この2年で26頭中26頭が枠内は全員確定だった
2. **若い母馬（7〜10歳）の仔は、母馬優先を持っていても6割の確率で抽選になる。**
   優先権があるから安心、とは言えない
3. **繁殖入りしそうな牝馬に先行投資するなら、権利の「賞味期限」を意識する。**
   初仔（母馬6〜8歳）の頃がいちばん競争が激しく、
   母馬が12歳を超えるあたりから権利の価値は急速に下がる。
   逆に言えば、**下の仔ほど優先権が効きやすい**
4. **母馬の知名度と、枠が埋まるかは別物。**
   リスグラシュー（2014年産）やマルシュロレーヌ（2016年産）の産駒は
   枠外ではA・Bランク（＝全体としては最上位人気）だが、母馬優先枠は余っている。
   一方で無名に近い母馬でも、若ければ枠が埋まる
