# キャロットクラブ 会員数・退会率・母馬優先有資格者数の推計

一口馬主クラブ「キャロットクラブ」について、
**会員数・年間退会率**、および募集馬の**母馬に出資していた会員（母馬出資者優先の有資格者）が
1頭あたり何人いるか**を、制度の確認から積み上げて推計したもの。

- 作成日：2026-08-20
- 対象：中央入厩予定馬（1頭400口）
- 主な出典：キャロットクラブ公式Q&A／約款PDF／抽選ランク公表（2021〜2025年度）／キャンセル募集公表（詳細は `docs/04_出典.md`）

---

## 結論（先に答え）

### 1. 会員数 ≒ 1万〜1万4千人（中心1万2千人）

「最優先希望枠は必ず1頭だけ選ばなければならない」というルールを使うと、
**全馬の最優先申込人数の合計＝第1次募集の参加人数**になる。
クラブが毎年公表する抽選ランクは「最優先の申込がプール口数を超えたか否か」の
打ち切り観測なので、そこから最優先申込口数の総和を復元できる。

```
Σ最優先申込口数 ≒ 24,000口
N（第1次募集の参加人数） = Σ ÷ m1
   m1=2.5口 → 9,600人   m1=3.0口 → 8,000人
会員数 = N ÷ 参加率(0.75〜0.85) → 約 9,400〜12,800人
```

ネットでよく見る「キャロット2万人」は出典が口コミであって公式発表ではない。
この推計はそれより2〜4割少ない。

### 2. 年間退会率 ≒ 3〜6%（中心4.5%）

3つの独立ルートで挟んだ。

| ルート | 示す値 |
|---|---|
| キャンセル募集の口数（＝退会で戻った口。クラブが明記） | 0.5〜1.2%（**下限**） |
| 定常状態モデル（1998年設立・28年） | 1〜7% |
| 母馬優先枠の申込実測からの逆算 | **3〜6%** |

**約款が強い残留圧力になっている**のが低さの理由。
退会すると出資馬の受益権も分配請求権も全部失って愛馬会法人に無償譲渡され、
中途解約も退会要求事由なので「1頭だけ手放す」ができない。
だから現役出資馬がいる間はまず辞められず、退会は「持ち馬が全部引退したタイミング」に集中する。

### 3. キャンセル募集は「強制退会」の観測窓になっている

クラブの案内文に **「本募集におけるキャンセル口数は、すべて出資者の退会によって生じたものとなります」**
と明記されている。実データは：

| 募集回 | 対象頭数 | キャンセル口数 | 出資確定からの経過 |
|---|---|---|---|
| 2024年度 第1回（2025/01） | 57頭 | 129口 | 約4ヶ月 |
| 2025年度 第1回（2026/01） | 61頭 | 106口 | 約4ヶ月 |
| 2025年度 第2回（2026/04） | 30頭 | 61口 | 約7ヶ月 |

対象が最新世代の馬だけなので、捕捉できるのは「**現役の出資馬を持ったまま辞めた人**」だけ。
全馬引退後に静かに辞める人は返す口を持たないので現れない。
高額馬を分割払いで買って払えなくなった人が、約款どおり
「請求日翌月15日で完納なければ強制退会」となって、ちょうどこのタイミングで出てくる。

### 4. 母馬優先の有資格者は「400人」ではなく100人前後

400口だが、**1人が平均2口前後**持つので、母馬の出資者は最初から **150〜210人程度**しかいない。
そこに7〜10年分の退会が乗る。

**2026年度募集の産駒**の場合（中位＝退会率4.5%）：

| 母馬の募集年度 | 経過 | 母馬が人気馬だった | 並だった | 不人気だった |
|---|---|---|---|---|
| 2016年度 | 10年 | **113人** | 89人 | 38人 |
| 2019年度 | 7年 | **130人** | 103人 | 44人 |
| 2022年度 | 4年 | **151人** | 120人 | 46人 |

幅を取ると38〜190人、**典型は100〜150人**。

### 5. 母馬優先は「使えば必ず通る」ものではない — しかも若い母馬に集中する

2021〜2025年度の5年分（母馬優先対象253頭）で、**34%の馬で母馬優先枠（200口）が埋まり、
母馬優先者どうしの抽選になっている**。

| 募集年度 | 母馬優先対象 | 枠内抽選 | 割合 |
|---|---|---|---|
| 2021年度 | 48頭 | 19頭 | 40% |
| 2022年度 | 44頭 | 17頭 | 39% |
| 2023年度 | 49頭 | 12頭 | 24% |
| 2024年度 | 59頭 | 20頭 | 34% |
| 2025年度 | 53頭 | 18頭 | 34% |
| **合算** | **253頭** | **86頭** | **34%** |

さらに母馬の馬齢で分けると、はっきり偏る。

| 母馬の馬齢 | 対象 | 枠内抽選 | 割合 |
|---|---|---|---|
| 5〜8歳 | 56頭 | 32頭 | **57%** |
| 9〜10歳 | 58頭 | 33頭 | **57%** |
| 11〜12歳 | 58頭 | 15頭 | 26% |
| 13歳以上 | 81頭 | 6頭 | **7%** |

**14歳以上の母馬58頭のうち枠内抽選になったのは3頭だけ（すべて2021年度に集中）。
2022年度以降に限れば45頭中0頭。**
経過年数1年あたりオッズが33%ずつ低下する（→ [`docs/06`](docs/06_母馬の馬齢と枠内抽選.md)）。

なお **2025年度の募集馬91頭のうち53頭（58%）が母馬優先対象馬**だった。

### 5b. 「去年は余ったのに今年は抽選」は12%で起きる

同じ母馬の連年産駒103組を追うと、

```
前年に埋まった → 翌年も埋まる  19/31 = 61%
前年は余った   → 翌年に埋まる   9/72 = 12%   ← 反転
```

有資格者 E は退会で減る一方なので、反転するには産駒側で
**u×m（行使率×口数）が1.25〜2.5倍に跳ねる**必要がある。
だから反転は「前年ぎりぎりで届かなかった馬」にほぼ限られ、
**13歳以上の母馬からの反転は5年で1件もない**。

しかも**反転9件のうち4件は枠外ランクが動いていない**＝産駒の一般人気は前年と同じ。
つまり反転の半分近くは「産駒が人気化した」からではなく、
**母馬優先権を持つ層だけが動いた**結果だった（→ [`docs/07`](docs/07_反転ケースの分析.md)）。

産駒の人気を揃えても母馬の馬齢は効く。枠外ランクＤ（＝一般人気は中位）で切ると
**母馬10歳以下 40/68 = 59% に対し 11歳以上 4/79 = 5%。12倍の差。**

そして直感と逆の結果がひとつ。前年に枠が余った馬の翌年の反転率は、
**前年の産駒が人気だったほど低い**（前年枠外Ｄ 10% ＜ 前年枠外Ｅ 21%）。
「一般人気はあったのに母馬優先枠だけ余った」は E が本当に小さい証拠なので翌年も余る。
逆に「前年はどこも抽選にならなかった」は E の情報になっておらず、良い仔が出れば埋まる。

### 6. ご想定への回答

| ご想定 | 検証結果 |
|---|---|
| 「当初は400口＝最大400人が有資格」 | **成り立たない。** 1人平均2口なので最初から150〜210人 |
| 「退会（強制退会含む）で有資格者が減っている」 | **その通り。** ただし退会率は年3〜6%で、想定より緩やか。7〜10年で3〜4割減 |
| 「キャンセル募集＝強制退会」 | **その通り。** クラブが「すべて退会によって生じたもの」と明記。ただし最新世代しか出ないので退会全体の下限 |
| 「馬代金高騰で複数口申込が減っている」 | **口数は確かに減っている**（1口10.75万→13.22万で平均2.2口→1.9口）。<br>ただし効果は逆向きで、同じ400口を**より多い人数**で分けるので<br>**将来の有資格者は増える**方向（2013年比 +16%） |

## 推計式

```
【会員数】
  N（第1次募集の参加人数） = Σ最優先申込口数 ÷ m1
  会員数 = N ÷ 第1次募集への参加率
  ※ Σ最優先申込口数 は抽選ランクの打ち切り観測から対数正規分布を当てはめて復元

【退会率】
  下限 … キャンセル募集の口数 ÷ 退会者1人あたりの最新世代保有口数
  上限 … N = A × (1 − (1−d)^T) / d を d について解く（A=年間新規入会、T=設立からの年数）
  中心 … 母馬優先枠への申込口数の実測 = E × u × m を u が常識的になる d で解く

【母馬優先の有資格者数】
  E(母馬, 産駒募集年) = S(母馬) × (1 − 退会率)^t × 0.97
    S(母馬) = 400 ÷ m̄      m̄ = 出資者1人あたり平均口数
    t       = 産駒の募集年度 − 母馬の募集年度（初仔で約7年）
```

## 使い方

```bash
python3 model/members.py           # 会員数・退会率の逆算
python3 model/estimate.py          # 母馬別の有資格者数
python3 model/estimate.py --scan   # 母馬募集年度 × 人気度のマトリクス
python3 model/dam_age.py           # 母馬の馬齢別の枠内抽選率
python3 model/reversal.py          # 反転（枠余り→枠内抽選）の分析
```

出力は `data/members_output.txt` / `data/model_output.txt` / `data/dam_age_output.txt` /
`data/reversal_output.txt` に保存済み。

主要パラメータ：

| ファイル | パラメータ | 既定値 | 意味 |
|---|---|---|---|
| `members.py` | `m1` | 2.5 | 最優先希望馬への1人あたり平均申込口数 |
| `members.py` | `join_rate` | 0.75 | 会員のうち第1次募集に参加する割合 |
| `members.py` | `sigma` | 1.0 | 最優先申込口数のばらつき |
| `estimate.py` | `churn` | 0.045 | 年間退会率 |
| `estimate.py` | `budget_median_2025` | 20.0 | 1頭あたり投下予算の中央値（万円） |

## この推計の弱点（正直に）

1. **m1（最優先希望馬への平均申込口数）が効きすぎる。**
   2.0口なら会員1万6千人、3.5口なら9千人と、会員数が倍近く動く。
   ここを詰めれば推計は一気に固くなる（`docs/05` の 9-6 に方法）
2. **第1次募集への参加率も未知。** 0.75と置いたが根拠は「最優先の権利を毎年使わないと
   落選実績が積めず不利になるので参加率は高いはず」という理屈だけ
3. **キャンセル募集は退会全体を捕捉していない。** 最新世代しか対象にならないので、
   これ単独では退会率は出せない。下限としてのみ使っている
4. **抽選ランクは2021〜2025年度の5年分に広げた（253頭）が、会員数の逆算は2025年度1年分だけ。**
   2021〜2023年度は表記体系が違う（全角Ａ〜Ｊの1軸）ため2軸に読み替えている。
   また2021・2022年度は「どこでも抽選が起きなかった馬」が一覧に載らないので、
   2022年度は募集番号順の別表から12頭を補完した（`docs/06` の 10-2）
5. **2022年産以前の募集価格は後方推計。** 全中央クラブ平均の伸び率（年3.3%）を当てたもの
6. **母馬優先枠＝200口 は公式の公開ページでは未確認。** 会員ブログ複数で一致し、
   抽選ランクの記号体系（母馬優先枠／枠外の2本立て）とも整合するが、
   **募集馬カタログのフローチャートで裏を取ってほしい**
