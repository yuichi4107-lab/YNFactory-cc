# キャロットクラブ 母馬優先 有資格者数の推計

一口馬主クラブ「キャロットクラブ」で、募集馬の**母馬に出資していた会員（＝母馬出資者優先の有資格者）**が
1頭あたり何人いるのかを、制度の確認から積み上げて推計したもの。

- 作成日：2026-08-20
- 対象：中央入厩予定馬（1頭400口）
- 主な出典：キャロットクラブ公式Q&A／約款PDF／募集馬リスト（詳細は `docs/04_出典.md`）

---

## 結論（先に答え）

### 1. 出発点が「400人」ではない

400口だが、**1人が平均2口前後**持つので、母馬の出資者は最初から **150〜210人程度**しかいない。
1次募集で抽選になった人気馬でも約185人、売れ残って通常募集まで回った馬なら約60人。

| 母馬の売れ方 | 出資者の実人数 |
|---|---|
| 1次募集で抽選（人気馬） | **約180〜210人** |
| 1次募集で満口（抽選なし） | 約145〜170人 |
| 1.5次・2次募集で満口 | 約100〜120人 |
| 通常募集まで残った | 約60〜75人 |

（1次で抽選になった馬は「6口以上は自動的に5口へ減口」が効くので、**最低でも80人**は確実にいる）

### 2. そこから7〜10年分の退会が引かれる

母馬の募集から産駒の募集まで、**初仔で7年前後、下の仔だと10年前後**空く。
年間退会率を7%とすると、7年で残存6割、10年で残存5割。

### 3. 現実的な有資格者数

**2026年度募集の産駒**を例にすると（中位シナリオ）：

| 母馬の募集年度 | 経過 | 母馬が人気馬だった | 母馬が並だった | 母馬が不人気だった |
|---|---|---|---|---|
| 2016年度 | 10年 | **86人** | 68人 | 29人 |
| 2019年度 | 7年 | **108人** | 86人 | 36人 |
| 2022年度 | 4年 | **135人** | 108人 | 46人 |

幅を取ると **30〜170人、典型的には80〜130人**。
「400人」というイメージに対して、実際は **その1/4〜1/3程度**しか残っていない。

### 4. だから母馬優先はほぼ通る

母馬優先枠は400口中200口とみられる。有資格者100人が全員申し込んでも、
1人平均1.9口なら190口で枠に収まる。
**現実的な行使率（3〜6割）なら、母馬優先枠が埋まることはまずない＝優先権を使えば当選できる。**

母馬優先者どうしの抽選になるのは、
「母馬が最近（4〜6年前）の募集」×「母馬が人気馬」×「産駒が超人気血統」が
重なったごく一部の馬だけ。

### 5. ご想定への回答

| ご想定 | 検証結果 |
|---|---|
| 「当初は400口＝最大400人が有資格」 | **成り立たない。** 1人平均2口なので最初から150〜210人 |
| 「退会（強制退会含む）で有資格者が減っている」 | **その通り。しかもこれが最大の要因。** 7〜10年で4〜5割が消える |
| 「馬代金高騰で複数口申込が減っている」 | **口数は確かに減っている**（1口10.75万→13.22万で平均2.2口→1.9口）。<br>ただし効果は逆向きで、同じ400口を**より多い人数**で分けるので<br>**将来の有資格者は増える**方向（2013年比 +16%） |

つまり「有資格者が減っている」のは価格ではなく**退会が原因**で、
価格高騰はむしろ有資格者を増やす方向に働いている。この2つは打ち消し合う。

| 5 | 馬代金高騰の影響を定量化 | 同上 |

## 推計式

```
E(母馬, 産駒募集年) = S(母馬) × R(t) × P_active

  S(母馬)  = 400 ÷ m̄        m̄ = 出資者1人あたり平均口数
  m̄        = E[ clip(round(予算 ÷ 1口価格), 1, 上限) ]
  R(t)     = (1 − 年間退会率)^t
  P_active = 0.97           （遅延歴2回以上でその年は母馬優先権を行使できない）
  t        = 産駒の募集年度 − 母馬の募集年度（初仔で約7年）
```

## 使い方

```bash
python3 model/estimate.py          # 価格推移・出資者数・有資格者数・母馬優先枠の判定
python3 model/estimate.py --scan   # 母馬募集年度 × 人気度のマトリクス
```

出力例は `data/model_output.txt` に保存済み。

主要パラメータは `model/estimate.py` の `Params` で調整できる。

| パラメータ | 既定値 | 意味 |
|---|---|---|
| `churn` | 0.07 | 年間退会率 |
| `budget_median_2025` | 20.0 | 2025年度時点の1頭あたり投下予算の中央値（万円） |
| `budget_growth` | 0.03 | 予算の年成長率（馬代金の伸びより低いと仮定） |
| `inactive_rate` | 0.03 | 遅延歴などで権利を行使できない会員の割合 |

## この推計の弱点（正直に）

1. **母馬優先枠＝200口 が公式に確認できていない。** 会員ブログ複数で一致しているが、
   公開ページには記載がない。**募集馬カタログのフローチャートで裏を取ってほしい。**
   もしこれが「200口」でなく「上限なし」なら、結論4は変わる
2. **退会率は完全な仮定。** 公開情報がゼロなので5%/7%/10%の3シナリオを置いた。
   ここが推計幅（30〜170人）のほとんどを作っている
3. **2022年産以前の募集価格は後方推計。** 全中央クラブ平均の伸び率（年3.3%）を当てたもので、
   キャロット固有の値ではない
4. **1人あたり予算の分布は仮定。** 対数正規＋制度上の上限、という置き方は妥当だが、
   中央値20万円・σ0.62は当てにいった数字

→ 1と2は、[`docs/03_精度を上げる手順.md`](docs/03_精度を上げる手順.md) の方法で
**会員として取れるデータだけで潰せる**。特に「同じ母馬の1番仔・2番仔・3番仔の
抽選ランクを並べる」やり方は、退会率を直接測れるので効果が大きい。
