# キャロットクラブ出資検討 (2026年度募集)

過去5年(2020〜2024年度募集)の全467頭のデビュー後成績を netkeiba から照会し、
出資検討基準を導出して2026年度募集馬94頭を採点したプロジェクト。

**2026-08-22 に3年276頭→5年467頭へ拡張し、基準を作り直した**（→ [`docs/5年検証.md`](docs/5年検証.md)）。
既存の6点満点スコアは、作成に使っていない2023・2024年度募集ではほとんど効いていなかった。
その後、**血統・母・馬体・価格・人気・厩舎・手法の7方向を並行で洗い直し**、検証を通った
「価格の下限を独立させる」1件を反映して4点満点にしている。

## 成果物

- **キャロット2026検討.xlsx** — メインの検討資料
  - `募集馬一覧`: 確定94頭(2026/8/1確定・8/18測尺反映)。価格・測尺・予定厩舎・母年齢・産駒数・基準スコア(4点満点)・スコア内訳
  - `検討基準`: 過去467頭の分析から導出したスコア基準と厩舎相性・父の傾向
  - `過去募集馬成績`: 2020〜2024年度募集467頭の成績・回収率・スコア(答え合わせ用)

- **キャロット2026_統合検討.xlsx** — 本ディレクトリの分析と、親ディレクトリの
  母馬優先枠の推計を1冊にまとめたもの。「走るか」と「当たるか」を横に並べて見る
  - `統合判断表`: 94頭を1行1頭で。スコア(4点満点)と母馬優先枠が埋まる確率を並べ、
    掛け合わせた判断区分を付けた表。見出しの色が列の出自を表す
    (紺=成績分析／緑=母馬優先枠の推計／茶=統合して足した列)
  - `読み方`: 判断区分の定義・確率の意味・注意点
  - `検討基準`: スコアの定義と過去実績(`キャロット2026検討.xlsx` から)
  - `母馬優先枠の予測`: 母馬優先対象57頭を確率順(親の `data/forecast_2026.csv` から)
  - `過去募集馬成績`: 467頭(`キャロット2026検討.xlsx` から)

### 判断区分

スコア別の実績(走るか)と、母馬優先枠が埋まる確率(当たるか)の掛け合わせ。
確率50%以上を「人気(competitive)」と見なす。母馬優先対象外の37頭は枠の食い合いが
ないので「取りやすい」側に置いている。

| 区分 | 条件 |
|---|---|
| S 最有力 | スコア4 × 枠が埋まりにくい |
| A 有力(人気) | スコア4 × 枠が埋まる見込み |
| A 有力 | スコア3 × 枠が埋まりにくい |
| B 検討 | スコア3 × 枠が埋まる見込み |
| C 見送り寄り | スコア2 |
| D 回避 | スコア1以下 |

2026年度94頭のスコア分布は 4点4頭 / 3点48頭 / 2点29頭 / 1点9頭 / 0点4頭。

回避条件(メス420kg未満)に該当する9頭は、区分とは独立に別列で印を付けている。

### 統合して見えたこと

新スコア4点（満点）は4頭（うち1頭は地方入厩予定で、中央前提の基準の外にある）。

| 馬名 | 父 | 総額 | 予定厩舎 | 枠が埋まる確率 | 区分 |
|---|---|---|---|---|---|
| **ブロンディーヴァの25** | ニューイヤーズデイ | 3,200万 | 高木登 | **32%** | **S 最有力** |
| **コンセッションズの25** | コントレイル | 3,600万 | 寺島良 | 母馬優先対象外 | **S 最有力** |
| ジェムフェザーの25 | マジェスティックウォリアー | 3,200万 | 伊藤大士 | 66% | A 有力(人気) |
| （ジュールヒートの25） | ナダル | 2,500万 | 地方(門別ほか) | 対象外 | 参考 |

旧基準で最上位だったスコア6の3頭（アンフィトリテの25 5,000万・メサルティムの25 4,000万・
ヴィルデローゼの25 4,000万）は、いずれも募集総額4,000万以上で新基準では2点。過去5年の実績では4,000万以上の馬は
「走るが回収が伸びない」（中央勝ち上がり54%・回収が募集額を超えたのは13%）ため。

## スコア基準 (各1点・4点満点)

| 条件 | 根拠(過去467頭。中央400口444頭で検定) |
|---|---|
| 牡馬 | 中央勝ち上がり55%・回収≥1が21% vs メス44%・14%。重賞20頭中15頭が牡 |
| 募集総額 2,500万円以上 | 2,500万未満は31%・15%(113頭)で走らない。5年とも例外なく最下位 |
| 募集総額 4,000万円未満 | 2,500〜3,999万は57%・24%(148頭)。4,000万以上は54%・13%(183頭)で走るが回収が伸びない |
| 募集時馬体重 420kg以上 | 54%・19% vs 420kg未満31%・10% |

価格を下限と上限の2本に割っているのは効き方が違うため。下限は「走るか」に効き、
上限は「回収するか」にだけ効く。入れ子leave-one-year-outで中央勝ち上がりのAUCは
0.611→0.631と5年すべてで改善する（回収側は0.655→0.646とわずかに悪化）。

過去実績: 4点=中央勝ち上がり67%・回収≥1が37%(52頭) / 3点=57%・16%(179頭) /
2点=46%・14%(107頭) / 1点=37%・15%(79頭) / 0点=15%・4%(27頭)

**3年では効いていたが5年では効かなかったので落とした基準**：3〜4月生まれ・ノーザンＦ生産・母年齢8〜11歳。
いずれも年度ダミーを入れたロジスティック回帰で有意でない（z=+0.6〜+0.8、ノーザンＦは−0.2）。

## 注意

- 回収率 = 賞金(中央+地方) / 募集総額。進上金・維持費・メスの繁殖価値は未考慮
- **回収率の分母は募集価格なので、安い馬ほど高く出る**。価格基準の効果にはその分が含まれている
- 「勝ち上がり」は**中央で1勝以上**。netkeibaの通算成績は地方の勝利も含むため、
  出走履歴をレース単位まで見て数え直している（中央未勝利のまま地方で勝った馬が5年で77頭いる）
- 2023年度募集世代は現4歳、2024年度募集世代は現3歳。数値は今後上振れする
- 当たり具合はAUC 0.64(勝ち上がり)／0.61(回収)。でたらめが0.5なので効きは穏やかで、
  スコアは絞り込みの道具であって個別の馬の能力予測ではない
- 2026年度は募集価格が高く（中央値5,000万）、上限基準に当てはまるのは94頭中20頭
- netkeibaのHTMLキャッシュ(`scripts/nk_cache/`・`scripts/src_cache/`)はコミット対象外
- 統合Excelは2つの分析の結合であって、新しい推計をしているわけではない
