# 7方向の洗い直しで使った検定コード（2026-08-22）

「基準が少ないのは見落としがあるからではないか」という問いに答えるため、
血統・母・馬体・価格・人気・厩舎・手法の7方向を並行で洗い直したときの作業ファイル。
各方向に探索役と敵対的検証役を立てて調べた記録で、いずれも使い捨ての検定スクリプト。

- `probe_<切り口>*.py` … 探索側
- `probe_adv_*.py` / `probe_adversarial*.py` … 検証側（候補を潰しにかかった側）

結果のまとめは [`../../docs/5年検証.md`](../../docs/5年検証.md) の7章。
検証を通った1件（価格の下限を独立させる）だけが `../verify_price_floor.py` で再検証され、
`../build_criteria.py` の基準に反映されている。

いずれも panel5.csv だけを読む読み取り専用のスクリプトで、外部への再取得は行っていない。
