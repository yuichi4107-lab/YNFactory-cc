# STEP10 母馬の馬齢と「母馬優先枠で抽選になるか」の関係

## 10-1. 何を調べたか

母馬優先枠（400口中200口）が埋まって**母馬優先者どうしの抽選**になるのは、
その母馬の有資格者が多い馬のはず。有資格者は

```
E = S（母馬の出資者実人数） × (1 − 退会率)^t
t = 産駒の募集年度 − 母馬の募集年度 ＝ 母馬の馬齢 − 1
```

なので、**若い母馬ほど枠が埋まりやすい**という予測が立つ。これを実データで検証した。

## 10-2. データの作り方

| 項目 | 出典・方法 |
|---|---|
| 抽選ランク（馬名つき） | クラブ公表の「第１次募集最終集計結果」2021〜2025年度の5年分 |
| 母馬優先枠が埋まったか | 下の「ランク記号の読み方」参照 |
| 母馬の生年 | 一口馬主DBの「キャロットクラブ所属馬一覧」を年産別に取得し、母馬名で突合 |

- 対象：**母馬優先対象馬 253頭**（2021年度48＋2022年度44＋2023年度49＋2024年度59＋2025年度53）
- データ本体：`data/dam_age_rank.csv` ／ 再現スクリプト：`model/dam_age.py`

### ランク記号の読み方（2つの体系がある）

**2024年度以降**は「数字＋英字」の2軸表記。数字が母馬優先枠の消化段階、英字が枠外の消化段階。
数字が **1〜4 なら母馬優先枠が埋まって抽選**、**5 なら枠が余った**。

**2021〜2023年度**は全角英字Ａ〜Ｊの1軸表記で、両方の軸が1文字に畳み込まれている。
原文のランク定義から2軸に展開すると次のとおり（`model/reversal.py` の `RANK_LEGACY_OUT`）。

| ランク | 枠内（母馬優先枠） | 枠外 | 枠が埋まったか |
|---|---|---|---|
| Ａ・Ｂ | 母馬優先＋最優先の段階で抽選 | Ａ／Ｃ | **埋まった** |
| Ｃ・Ｄ・Ｅ | 母馬優先枠（一般出資枠）内で抽選 | Ａ／Ｂ／Ｃ | **埋まった** |
| Ｉ | 母馬優先枠（一般出資枠）内で抽選 | Ｄ | **埋まった** |
| Ｆ・Ｇ・Ｈ | 母馬優先枠内は全口当選 | Ａ／Ｂ／Ｃ | 余った |
| Ｊ | 母馬優先枠内は全口当選 | Ｄ | 余った |

### 2021・2022年度を扱うときの注意

この体系には「全口出資確定（＝どこでも抽選が起きなかった）」を表す記号が無いため、
**残口馬は一覧に載らない**。そのまま使うと「枠が余った側」だけが欠測して選択バイアスになる。

- **2021年度**は第1次募集で全馬満口だったため欠測なし（90頭すべてに記号がついている）。
- **2022年度**は一覧に載らなかった12頭を募集番号順の別表から拾い、`確定` として補完した。
  うちキャロット所属馬名簿に母馬がいた5頭（ミリッサ・エリティエール・ディーパワンサ・
  ペルレンケッテ・ココファンタジア）を母馬優先対象＝枠余りとして加えている。
- 2021年度にあった**新規入会者枠**（現在は廃止）で抽選になった馬12頭は、
  既存会員の枠は枠内・枠外とも全口確定しているので `確定` 扱いにした。

母馬優先対象かどうかは「母馬がキャロット所属馬名簿にいるか」で判定している。
2021・2022年度の**非対象馬77頭は1頭も名簿に載っておらず**、誤検出はゼロだった。

### 年度ごとの推移

| 募集年度 | 母馬優先対象 | 枠内抽選 | 割合 |
|---|---|---|---|
| 2021年度 | 48頭 | 19頭 | 40% |
| 2022年度 | 44頭 | 17頭 | 39% |
| 2023年度 | 49頭 | 12頭 | 24% |
| 2024年度 | 59頭 | 20頭 | 34% |
| 2025年度 | 53頭 | 18頭 | 34% |
| **合算** | **253頭** | **86頭** | **34%** |

ゆるやかに下がっている。1口価格の高騰で「母馬優先で申し込む人の1人あたり口数 m」が
細るのに対し、有資格者数 E は過去（安かった頃）の口数で決まっているので、
D = E × u × m が目減りする——という向きと一致する。ただし年ごとのブレも大きい。

## 10-4. 回帰

経過年数 t（＝馬齢−1）でロジスティック回帰すると

```
logit(P) = 3.238 − 0.4011 × t
経過年数1年あたりのオッズ比 = 0.670（オッズが年 33% ずつ低下）
```

| t | 母馬の馬齢 | 枠内抽選になる予測確率 |
|---|---|---|
| 5年 | 6歳 | 77% |
| 7年 | 8歳 | 61% |
| 9年 | 10歳 | 41% |
| 11年 | 12歳 | 24% |
| 13年 | 14歳 | 12% |
| 15年 | 16歳 | 6% |
| 18年 | 19歳 | 2% |

2年分112頭で出した前回（オッズ比0.657）とほぼ同じ。5年分253頭でも動かなかった。

## 10-5. 退会率はどこまで読めるか

モデルでは「枠が埋まる ⇔ E×u×m ≧ 200」なので、両辺の対数をとると

```
枠内抽選 ⇔ log u ≧ c + t·λ      λ = −log(1 − 退会率)
log u ~ N(μ, σ) とすると  P(t) = Φ((μ − c − tλ)/σ)
```

つまり**プロビットの傾きが λ/σ** になる。実測では **λ/σ = 0.237**。

| σ（産駒ごとの行使率のばらつき） | 合計の年減衰率 |
|---|---|
| 0.20 | 4.6% |
| 0.30 | 6.9% |
| 0.40 | 9.1% |
| 0.50 | 11.2% |

**ただしこの「合計の年減衰率」は退会率そのものではない。** 交絡が3つある。

1. **産次が進むほど権利行使率が下がる** — 母馬が年を取るほど産駒は3番仔・4番仔になる。
   すでに上の仔に出資している人は下の仔を見送りやすいし、前の仔が走らなければなおさら。
   これは退会とまったく同じ向きに効く。
   **なお2021・2022年度の92頭で産駒数（何番仔）を突き合わせたところ、
   経過年数 t との相関は +0.97 だった**（→ `docs/09` の 13-2b）。
   クラブの繁殖牝馬はほぼ毎年産駒を出すので当然ではあるが、
   これは **「馬齢の効果」と「産次の効果」がこのデータからは原理的に分離できない**
   ということでもある。下の分解は「合計としてこれだけ減衰している」までしか言えない
2. **古い母馬ほど S（出資者実人数）が小さい** — 昔は1口価格が安く、1人あたり口数が多かった。
   `docs/02` の推計で2013年度募集 182人 → 2026年度募集 211人。さらに古い世代はもっと少ない
3. **地方馬（100口）が混じる** — 母馬が地方入厩馬だった場合、出資者は中央馬の1/4程度しかいない
   （例：カイカヨソウ 2010年産・南関東）

`docs/05` で別ルートから出した退会率は年3〜6%。
上の表と突き合わせると、**σ ≒ 0.35〜0.5、退会率3〜6%、残りの年2〜6%が行使率の低下**
という分解が整合的。5年分に広げても結論は変わらない。

## 10-6. 同じ母馬の連年産駒で見る

S が固定されるので、より厳密な比較になる。5年分では **実母馬116頭、
うち2年以上に産駒が募集された母馬72頭、連年ペア103組**。

- 悪化（枠内→枠余り）**12組** ／ 改善（枠余り→枠内）**9組** ／ 変化なし **82組**

正味 −3組。方向は「年を経ると埋まりにくくなる」と一致する。
ただし改善（＝反転）が9組もあることの方が情報量が大きい。
これは **`docs/07` で単独に分析した**。

## 10-7. 実務的な示唆

1. **母馬優先を「確実に通したい」なら、高齢の母馬の仔を狙う。**
   2022年度以降に限れば、母馬14歳以上の45頭は全頭が枠内で確定している
2. **若い母馬（7〜10歳）の仔は、母馬優先を持っていても6割の確率で抽選になる。**
   優先権があるから安心、とは言えない
3. **繁殖入りしそうな牝馬に先行投資するなら、権利の「賞味期限」を意識する。**
   初仔（母馬6〜8歳）の頃がいちばん競争が激しく、
   母馬が12歳を超えるあたりから権利の価値は急速に下がる。
   逆に言えば、**下の仔ほど優先権が効きやすい**
4. **母馬の知名度と、枠が埋まるかは別物。**
   リスグラシュー（2014年産）やマルシュロレーヌ（2016年産）の産駒は
   枠外ではA・Bランク（＝全体としては最上位人気）だが、母馬優先枠は余っている。
   一方で無名に近い母馬でも、若ければ枠が埋まる
