# 販売管理システム

社内の受注〜発注〜納品〜請求業務を管理するシステム。現在は**要件定義・設計フェーズが完了**した状態で、今後このディレクトリで実装を進める。

現行の Excel 運用(受注/発注カード・明細一覧・納品書/請求書発行)のイメージをもとに設計している。

## 概要

- **管理No. を軸に受注と発注を紐付け**、粗利(受注額−発注額)を自動計算
- 締め日は**客先ごとに設定可能**(月末/1〜31日)。締め処理で請求期間を日付単位で算出
- 帳票は**客先単位でまとめて発行**(納品書は案件単位も可)。**A4印刷が基本**(適格請求書対応、PDF化はオプション)
- 案件一覧は日付単位の期間集計・客先別集計・CSVダウンロードに対応

## 運用の前提

- **社内LAN限定**(外部公開なし)・**ランニングコストゼロ**(OSSのみ・クラウド不使用)
- アプリとDB(SQLite)は既存の社内運用サーバー等で稼働し、NAS共有フォルダへ日次バックアップ
- 実装形態: Webアプリ(Python + SQLite + サーバーサイドHTML)。詳細は要件定義書6章
