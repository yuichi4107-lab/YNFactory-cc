# 販売管理システム

社内の受注〜発注〜納品〜請求業務を管理するシステム。要件定義・設計に続き、**初期版(必須機能 F-01〜F-06 / F-08)を実装済み**。オプション機能(F-07 添付管理・F-09 ログイン)は要件定義書 4.11 の代替運用のまま。

現行の Excel 運用(受注/発注カード・明細一覧・納品書/請求書発行)のイメージをもとに設計している。

## 概要

- **管理No. を軸に受注と発注を紐付け**、粗利(受注額−発注額)を自動計算
- 受注は**案件ヘッダ + 受注明細の親子構造**で保持する。初期版の運用は1受注=1品目のままだが、将来の複数品目・分納・部分請求でテーブルを作り直さずに済む
- 締め日は**客先ごとに設定可能**(月末/1〜31日)。締め処理で請求期間を日付単位で算出
- 帳票は**客先単位でまとめて発行**(納品書は案件単位も可)。**A4印刷が基本**(適格請求書対応、PDF化はオプション)
- 案件一覧は日付単位の期間集計・客先別集計・CSVダウンロードに対応

## 運用の前提

- **社内LAN限定**(外部公開なし)・**ランニングコストゼロ**(OSSのみ・クラウド不使用)
- アプリとDB(SQLite)は既存の社内運用サーバー等で稼働し、NAS共有フォルダへ日次バックアップ
- 実装形態: Webアプリ(Python + SQLite + サーバーサイドHTML)。詳細は要件定義書6章

## 使い方

```bash
pip install -r requirements.txt
python scripts/seed_demo.py     # 動作確認用のデモデータ(任意)
python run.py                   # http://<このPCのIP>:8080
```

- DBは `data/sales.db`(アプリ稼働マシンのローカルディスク)。`SALES_DB_PATH` で変更できる。**NAS共有フォルダへ直接置かないこと**(ファイルロックが効かず破損する)
- ポートは `SALES_PORT`(既定8080)、待ち受けは `SALES_HOST`(既定0.0.0.0=社内LANの他PCから接続可)
- 日次バックアップ: `python scripts/backup.py "\\NAS\販売管理\backup"` をタスクスケジューラで毎日実行(7世代保持)
- 初回に**マスタ → 自社情報**で社名・登録番号・振込先を実値へ設定する(帳票に印字される)
- テスト: `python -m pytest tests/ -q`
