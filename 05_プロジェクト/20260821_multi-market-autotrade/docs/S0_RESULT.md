# S0 検証結果 — CR-33 ターン・オブ・ザ・マンス効果

- 実施日: 2026-08-21
- 問い: **「ターン・オブ・ザ・マンス効果は2022年以降も効いているのか」**
- 結論: **効いていない。符号が反転している。**
- 判定: **D-3 発動 → MVP-0 中止**

---

## 1. 結論

**OOS（2022-08〜2026-08）で、探索した9通りすべてが赤字。** コスト1.0倍でも赤字である。

| 条件 | 年率がプラスの組合せ |
|---|---|
| OOS・コスト1.0倍 | **0 / 9** |
| OOS・コスト1.5倍 | **0 / 9** |
| OOS・コスト2.0倍 | **0 / 9** |

OOS・コスト2.0倍の年率は **−8.15% 〜 −13.50%**（中央値 −10.89%）。
同期間のバイ・アンド・ホールドは **年率 +40.92%**。

`docs/MVP0.md` §6 の中止条件 **D-3「S0 の OOS でコスト2.0倍が赤字 → 中止」に該当する。**

## 2. 実装バグでないことの確認

戦略コードを一切通さず、**日次リターンを「TOM窓の中」と「外」に分けて集計するだけ**の検算を行った。

| 期間 | TOM窓の中 | TOM窓の外 |
|---|---|---|
| IS（2018-09〜2022-07） | 187日 / **1日あたり +0.5475%** | 1238日 / 1日あたり +0.0312% |
| OOS（2022-08〜2026-08） | 196日 / **1日あたり −0.1386%** | 1287日 / 1日あたり +0.1262% |

**IS では窓の中が窓の外の17倍稼いでいた。OOS では窓の中だけがマイナスに転じ、窓の外が稼いでいる。**

これは戦略ロジックを介さない生データの集計なので、バックテストの実装とは無関係である。
**アノマリーが消滅し、さらに符号が反転した**というのが事実である。

Coinbase Research が2025年9月に「歴史的に正しく見えた季節性の前提が2023年・2024年には
成立しなかった」と報告していた内容と一致する。

## 3. IS では何が見えていたか

| | 戦略（N=3,M=5） | バイ・アンド・ホールド |
|---|---|---|
| IS 年率 | +43.41% | +43.54% |
| IS 最大DD | 26.82% | 68.43% |

**IS ですら、リターンでB&Hを上回っていない。** 上回っていたのはDDの小ささだけである。
論文が主張していた「B&H比で年 +21.77%」は、この期間・このデータでは再現しなかった。

もし IS の数字だけを見て「DDが小さくて年率43%」と判断していたら、
OOS で年率 −10% の戦略に実弾を入れていた。**IS/OOS を分けたことがそのまま防御になった。**

## 5. 費やした時間

**約1時間。** 見積りは8時間だった。

`docs/MVP0.md` はこう書いていた——「S0 で赤字が出たら、それは失敗ではない。8時間で
『やらなくていい』と分かったということである。旧システムは同じ判断に4か月かけて到達できなかった」。

**実際には1時間で分かった。**

## 6. これからしないこと

**別の戦略に乗り換えない。** D-3 と D-5 が明示的に禁じている。

乗り換えたくなるのは自然である。推奨候補は他に13件あり、CR-01（時系列モメンタム）は
評価が最も高かった。だが**「次に調べた戦略の方が良さそうに見える」で乗り換え続けた結果が、
4か月で3回の方針転換と全停止だった**（FP-013）。

D-5 は「戦略の乗り換えが1回発生した時点で中止」と定めている。着手前に決めたルールである。

CR-33 は「**検証コストが最も低く、白黒が最も早くつく**」という理由で選んだ候補だった。
