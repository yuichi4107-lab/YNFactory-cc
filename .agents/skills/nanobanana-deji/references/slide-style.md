## ■ 全スライド共通の設計原則

### デザイン基本ルール
| 項目 | 仕様 |
|------|------|
| 背景 | 純白（#FFFFFF）のみ |
| タイトル | 最上部・左揃えまたは中央揃え・超大・太字・黒（背景帯なし） |
| フォント | ゴシック体（Noto Sans JP Bold相当）・太字多用・日本語明瞭 |
| パンチライン | **最下部・全幅黄色帯（#FFD700）・画像高さの12〜15%・画像中で最大フォント・黒文字・極太** |
| スマートフォン | フラットデザイン・グレーまたはカラー・**中央配置・画像高さの50〜60%を占めるサイズ** |
| アクセントカラー | 青（#1565C0〜#2196F3）・オレンジ（#FF6F00）・黄（#FFC107）・赤（×用）・緑（✅用） |
| 矢印 | 右向き→または↓・太め・グレーまたは黒 |
| テキストラベル | 各要素は2〜8文字・短く・太字・スマートフォンより必ず小さく |
| アイコン | フラット2Dベクター・Material Designスタイル・グラデーションなし・影なし |

### 各プロンプト冒頭に必ず書く禁止事項宣言
```
【スタイル指定】教育用インフォグラフィック／解説イラスト風。
コーポレートプレゼン風・箇条書きレイアウト・グラデーション背景・全幅カラー帯ヘッダー・3Dエフェクト・影は禁止。
```

### 絶対にやらないこと
- 全幅カラー帯のヘッダー・フッター（コーポレートPPT感が出る）→ パンチライン帯のみ例外
- 「または」「もしくは」の選択肢をプロンプトに入れる（曖昧さを排除・一意に決める）
- 「大きく」「小さく」など相対表現のみ（必ず%・px・比率で補足する）
- 「プロフェッショナル」「フォーマル」「ビジネス」という単語
- アイコンだけ並べたリスト型（スマートフォン図やフロー図を必ず使う）

### パンチライン帯の必須仕様（全スライド共通）
```
【パンチライン帯・必須ルール】
画像の最下部に、画像幅いっぱいの黄色い帯（背景色: #FFD700）を配置すること。
帯の高さは画像全体の約12〜15%。
帯の中に日本語のパンチライン1文のみ配置。
フォントは画像中で最大・極太（extra bold）・文字色は黒（#000000）。
この帯より下には何も配置しないこと。
```
