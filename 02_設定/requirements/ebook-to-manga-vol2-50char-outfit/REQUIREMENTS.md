## ゴール

vol2 の現行 CSV（4列・30字 hard limit・181ページ）を、vol3/vol4 と同方式の「50字 soft limit + 5列（outfit_id 付き）」フォーマットに再構築し、ページ数を約30%削減（目標 120〜140ページ）した新 CSV を `comicle_output.csv` として上書き保存する。

### 確定済み方針

1. **50字は目安（soft limit）**: hard limit ではなく、平均的に収まればOK。超過率10%未満を望ましい水準とする
2. **目標ページ数120〜140**: 50字緩和による自然なコマ統合でページ数を削減する
3. **outfit_presets は character_defs.json 確定済み**: vol3/vol4 向けに 2026-04-29 に確定した 8プリセット（misaki_casual / misaki_work_home / misaki_formal / takuya_zoom_mentor / takuya_casual / kenta_work_casual / kenta_casual / yamada_suit）をそのまま流用する。**追加定義・オーナー確認は不要**
4. **vol2 は独立した出力先**: Codex バンドルフォルダ（queue/）は存在しない。再構築後の CSV は `panels/comicle_output.csv` に直接上書きする
5. **vol2 の章構成**: 第3章「産後の海に飛び込む」+ 第4章「はじめての師匠」を収録（vol3 が第5章〜のため章境界に注意）
6. **EPUB再生成・画像再生成は本要件の対象外**: CSV整備のみで完結する

- 現行 `comicle_output.csv`（4列・181P）を `comicle_output_pre_50char_redesign.csv` としてバックアップ退避

- `pages/` 内の生成済み PNG への変更

## CSVフォーマット変更点（新旧対比）

| 項目 | 旧（30字 hard limit・4列） | 新（50字 soft limit・5列） |
|---|---|---|
| 列数 | 4列 | 5列 |

| 列名 | 内容 |
|---|---|
| ページ番号 | 整数 |
| 使用するコマ割りテンプレ | `テキストページ` または `テンプレ1`〜`テンプレ7` |
| 漫画作成のプロンプト | 画像生成プロンプト（◆ブロック形式） |
| コマ別テキストJSON | OCR用JSON配列（`outfit_id` は含まない） |
| outfit_id | そのページで適用するプリセットID。テキストページは空文字 |
