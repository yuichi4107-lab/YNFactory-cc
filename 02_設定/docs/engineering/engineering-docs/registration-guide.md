# Gems / GPTs 登録ガイド

## Part 1: Gemini Gems の登録手順

### アクセス方法
1. ブラウザで **gemini.google.com** を開く
2. クライアントから共有されたGoogleアカウントでログインする

### Gem の新規作成
3. 左メニューの **「Gem マネージャー」** をクリック
4. **「新しい Gem を作成」** をクリック

### 入力する場所（全3箇所）

#### ① 名前（Name）
- **場所:** 画面上部の「名前を付ける」テキストボックス
- **コピペするもの:** プロンプト集の **「名前:」** の部分
- **例:** `社内メールアシスタント`

#### ② アイコン（任意）
- **場所:** 名前の左側にある丸いアイコン
- **操作:** クリックすると絵文字を選べる。テーマに合った絵文字を選ぶ
- **おすすめ絵文字の例:**
  - メール系 → ✉️📧
  - 会議系 → 📋🗓️
  - 報告書系 → 📝📄
  - タスク系 → ✅📊
  - 分析系 → 🔍📈
  - Excel系 → 📊💻
  - アイデア系 → 💡🧠
  - 人事系 → 👥🤝
  - 契約系 → 📑✍️

#### ③ 指示（Instructions）
- **場所:** 「指示」と書かれた大きなテキストエリア
- **コピペするもの:** プロンプト集の **``` ``` で囲まれた部分（```の行自体は含めない）**
- **例:** テーマ1なら「あなたは、社内メールを一緒に作ってくれるアシスタントです。…」から最後まで

### 保存
5. 右上の **「保存」** ボタンをクリック
6. → 完了！Gemの一覧に追加される

### 動作確認
7. 作成したGemをクリックして開く
8. テスト入力してみる（例：「上司に休暇申請のメールを書きたい」）
9. 正常に動作すればOK

## Part 2: ChatGPT GPTs の登録手順

### アクセス方法
1. ブラウザで **chatgpt.com** を開く
2. クライアントから指定されたアカウントでログインする

### GPT の新規作成
3. 左メニューの **「GPTを探す」** をクリック
4. 右上の **「+ 作成する」** をクリック（または「GPTを作成する」）
5. 上部のタブで **「構成する」** を選択（※「作成する」タブではない）

### 入力する場所（全5箇所）

#### ① 名前（Name）
- **場所:** 「名前」テキストボックス
- **コピペするもの:** プロンプト集の **「名前:」** の部分
- **例:** `社内メールアシスタント`

#### ② 説明（Description）
- **場所:** 「説明」テキストボックス
- **コピペするもの:** 以下のような1行説明を自分で書く
- **例:** `社内向けのビジネスメールを、用件を伝えるだけで作成します`
- **※ 解説資料の冒頭1行をコピペしてもOK**

#### ③ 指示（Instructions）
- **場所:** 「指示」の大きなテキストエリア
- **コピペするもの:** プロンプト集の **``` ``` で囲まれた部分（```の行自体は含めない）**
- **※ Gemsと同じプロンプトをそのまま使ってOK**

#### ④ 会話スターター（Conversation starters）
- **場所:** 「会話スターター」の入力欄（4つまで設定可能）
- **コピペするもの:** ユーザーが最初にクリックできる質問例
- **各テーマの例は下記「会話スターター一覧」を参照**

#### ⑤ 機能（Capabilities）
- **場所:** チェックボックス（ウェブブラウジング / DALL-E / コードインタープリター）
- **設定:** 基本的にすべて **OFF** でOK（テキスト生成のみで十分）
- **例外:** Excel系のテーマ（#33〜37）は **「コードインタープリター」をON** にすると良い

### 保存
6. 右上の **「作成する」** または **「更新する」** をクリック
7. 公開範囲を選ぶ：
   - **「リンクを持つ人」** を選択（クライアントの指示に従う）
8. **「保存」** をクリック
9. → 完了！

### 動作確認
10. 作成したGPTを開く
11. テスト入力してみる
12. 正常に動作すればOK

## 効率的な量産のコツ

1. **Gems → GPTs の順にやると効率的**
   - Gemsの方が入力項目が少ない（名前 + 指示の2箇所）
   - まずGemsを50本一気に登録し、その後GPTsに取り掛かる

2. **カテゴリ単位でまとめて作業する**
   - メール系7本 → 会議系6本 → … とカテゴリごとに進める
   - 似たテーマを連続で登録すると手が慣れて速くなる

3. **プロンプトファイルをブラウザで開いておく**
   - プロンプト集のファイルを別タブで開き、コピペを繰り返す

4. **テスト入力は定型文を使い回す**
   - メール系なら「上司に報告メールを書きたい」
   - 会議系なら「1時間の定例会議」
   - すべてに対して同じ定型文でテストすると速い
