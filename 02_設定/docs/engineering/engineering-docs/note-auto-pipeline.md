# note記事 全自動パイプライン設計書

## 概要
note記事の作成から公開までを全自動化する。
週3本（月・水・金 7:00公開）を継続的に回す。

## パイプライン全体像

```
┌─────────────────────────────────────────────────┐
│  Step 1: 反応分析（毎週日曜）                      │
│  → noteのPV・スキ・コメントを確認                   │
│  → どのテーマが刺さっているか分析                    │
└────────────────────┬────────────────────────────┘
                     ▼
┌─────────────────────────────────────────────────┐
│  Step 2: トピック選定（毎週日曜）                    │
│  → 反応データ＋戦略マトリクスから次週3本を決定        │
│  → ココナラ3サービスへの導線を考慮                   │
└────────────────────┬────────────────────────────┘
                     ▼
┌─────────────────────────────────────────────────┐
│  Step 3: 記事生成（毎週日曜）                       │
│  → Manus / Claude に記事生成プロンプトを投入         │
│  → 3本分の記事を一括生成                            │
└────────────────────┬────────────────────────────┘
                     ▼
┌─────────────────────────────────────────────────┐
│  Step 4: 予約公開（毎週日曜）                       │
│  → Manusで月・水・金 7:00に予約公開設定              │
└─────────────────────────────────────────────────┘
```

## Step 1: 反応分析ロジック

毎週日曜日に以下を確認：
- noteダッシュボードでPV・スキ数を取得
- 記事ごとのパフォーマンスをランキング化
- 高パフォーマンス記事の共通点を抽出（テーマ、切り口、長さ、タイトル形式）

### 分析テンプレート（Manusに投げるプロンプト）

```
以下のnote記事のパフォーマンスデータを分析して、次週の記事戦略を提案してください。

【公開済み記事のパフォーマンス】
| # | タイトル | PV | スキ | コメント | 公開日 |
|---|---------|-----|------|---------|--------|
| 1 | {タイトル} | {PV} | {スキ} | {コメント数} | {日付} |
| 2 | ...     |     |      |         |        |

【ココナラサービス（集客先）】
1. AIチャットボット構築
2. AI業務自動化
3. AI導入コンサル（60分Zoom）

【分析してほしいこと】
1. どのテーマ・切り口がPV/スキが高いか
2. タイトルのパターン（数字入り、疑問形、How to等）で反応の違い
3. 次週おすすめの3テーマ（月・水・金）とその理由
4. 各テーマがどのココナラサービスに導線するか
```

## Step 2: トピック選定 — 戦略マトリクス

### コンテンツカテゴリ（ローテーション）

| カテゴリ | 説明 | 導線先 |
|---------|------|-------|
| A. AI活用事例 | 「こんな業務がAIで自動化できる」系 | 業務自動化サービス |
| B. チャットボット | 「AIチャットボットでこう変わる」系 | チャットボット構築 |
| C. AI導入入門 | 「AI初心者でも始められる」系 | AI導入コンサル |
| D. 業界別AI | 「〇〇業界のAI活用」系 | 全サービス |
| E. ツール紹介 | 「このAIツールがすごい」系 | コンサル / 自動化 |
| F. 失敗談・注意点 | 「AI導入で失敗しないために」系 | コンサル |

### ローテーションルール
- 週3本は異なるカテゴリから選ぶ
- 3サービスへの導線が偏らないよう、2週間単位でバランスを取る
- 反応が良いカテゴリの比率を徐々に上げる

## Step 3: 記事生成プロンプト

### Manus / Claude 用 記事生成プロンプト

```
あなたはAI活用の専門家で、noteで記事を書いています。
以下の条件で記事を1本作成してください。

【筆者プロフィール】
- AI技術を活用したフリーランスエンジニア
- ココナラでAIチャットボット構築・業務自動化・AI導入コンサルを提供
- 実践的でわかりやすい解説が得意

【記事条件】
- テーマ: {テーマ}
- カテゴリ: {A〜Fのカテゴリ}
- 導線先サービス: {対象ココナラサービス}
- 文字数: 2,000〜3,000字
- トーン: 専門的だが親しみやすい。難しい用語は噛み砕いて説明する

【構成】
1. 読者の悩み・課題に共感するリード文（3行程度）
2. 本文（見出し3〜5個、具体例を必ず入れる）
3. まとめ（ポイント3つ箇条書き）
4. CTA（ココナラサービスへの自然な導線）

【CTA例】
「もしAIで{課題}を解決したいとお考えでしたら、お気軽にご相談ください。
ココナラで{サービス名}を提供しています。→ {ココナラURL}」

【注意事項】
- 煽りすぎない、誠実なトーン
- 具体的な数字や事例を入れる（「8割削減」「月20時間節約」等）
- SEOを意識したタイトル（検索されやすいキーワードを含む）
- ハッシュタグ5つ提案（#AI #業務自動化 など）

【出力形式】
タイトル:
本文: （マークダウン形式）
ハッシュタグ:
```

## Step 4: 予約公開（Manus用プロンプト）

```
以下のnote記事を予約公開してください。

【記事1】月曜 7:00公開
タイトル: {タイトル}
本文: {本文}

【記事2】水曜 7:00公開
タイトル: {タイトル}
本文: {本文}

【記事3】金曜 7:00公開
タイトル: {タイトル}
本文: {本文}

手順:
1. note.com にログイン
2. 各記事を新規作成
3. 予約公開設定で指定日時の7:00にセット
4. ハッシュタグを設定
5. 完了したら公開URLを報告
```
