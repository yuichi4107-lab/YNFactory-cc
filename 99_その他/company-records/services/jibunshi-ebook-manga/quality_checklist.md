# 品質チェックリスト

## 注文フォルダ

- [ ] `project.md` がある
- [ ] `input/intake_answers.md` がある
- [ ] `input/consent_checklist.md` がある
- [ ] `production/brief.md` がある
- [ ] `qa/privacy_check.md` がある
- [ ] `delivery/README_納品対象.md` がある

## 完全文字版

- [ ] 漫画ページが入っていない
- [ ] 章末漫画、漫画パートが入っていない
- [ ] 本人の語り口が残っている
- [ ] 時系列が破綻していない
- [ ] 実名・地名・会社名の扱いが確認済み
- [ ] 家族が読んで不必要に傷つく表現がない
- [ ] EPUB/PDFまたは制作対象ファイルが揃っている

## 完全漫画版

- [ ] 文字版の承認済み内容だけを使っている
- [ ] 全編漫画として独立して読める
- [ ] キャラクター定義が個人情報ポリシーに合っている
- [ ] 実在人物の顔・制服・住所などが必要に応じて抽象化されている
- [ ] コマ内テキストが読める
- [ ] 表紙、EPUB/PDF、KDPメタデータ案が揃っている

## プライバシー

- [ ] 主役本人または正当な代理者の同意がある
- [ ] 写真利用の可否が記録されている
- [ ] 第三者の実名公開が避けられている
- [ ] 公開/KDPにする場合の明示承認がある
- [ ] 納品対象に未確認素材が入っていない

## LP/QR

- [ ] QRの参照URLが `QR_LP_URL.txt` と一致している
- [ ] LPに個人情報の扱いが書かれている
- [ ] 本番公開URLは公開前にオーナー承認を取る

## 合格基準

100点満点で85点以上。85点未満の場合は、該当項目を修正して再チェックする。
