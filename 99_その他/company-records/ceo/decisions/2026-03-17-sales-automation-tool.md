# 意思決定: 営業自動化ツール開発プロジェクトの立ち上げ

## 背景
オーナーから営業自動化ツールの開発依頼。企業リスト生成、HP巡回・メール抽出、営業メール自動送信、お問い合わせフォーム営業、簡易CRM、営業スコアリング、CSV出力、ダッシュボードの9機能を持つWebアプリ。将来的にSaaS化も視野に入れた拡張性のある設計が求められている。

技術要件: Python / スクレイピング / DB / 管理画面（Flask/Django）
開発期間: 約1ヶ月
予算: 5万円

## 判断内容
本プロジェクトを正式に立ち上げ、以下の4部署に振り分ける。

## 振り分け先
| 部署 | 指示内容 |
|------|---------|
| PM | プロジェクト立ち上げ。9機能を4フェーズに分割したマイルストーン策定 |
| 開発 | 技術設計書作成。アーキテクチャ・技術選定・DB設計 |
| リサーチ | 法的リスク調査（スクレイピング、自動メール送信の法規制） |
| 営業 | 案件情報の記録（SaaS化に向けた市場ポジショニング） |

## 理由
- 9機能は依存関係があるため、フェーズ分割で段階的に開発するのが最も効率的
- 自動メール送信・スクレイピングには法的リスクがあるため、リサーチを並行して進める必要がある
- SaaS化の可能性を考慮し、初期設計段階から拡張性を意識する
