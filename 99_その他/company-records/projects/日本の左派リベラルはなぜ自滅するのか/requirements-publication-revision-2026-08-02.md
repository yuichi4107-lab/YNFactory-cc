# 出版パッケージ追加修正 要件定義書

- 確定日: 2026-08-02
- 対象: 『日本の左派・リベラルは、なぜ自滅するのか』KDP用派生原稿・EPUB生成処理

## ゴール

電子書籍の可読性と公開用出典一覧を調整し、全78節を新しいページから始めるとともに、内部制作資料S001・S002を末尾の出典一覧からのみ除外する。正本原稿と研究台帳は変更せず、将来の再生成でも同じ結果を得られるようにする。

## スコープ

### 実施すること

1. EPUB生成時、全H2節見出しへ専用クラスを付与する。
2. CSSへ `break-before: page;` と `page-break-before: always;` を設定する。
3. 出版用原稿とEPUB用原稿の末尾出典一覧から、S001・S002の表行だけを除外する。
4. 本文中のS001・S002を含む出典ID表記は保持する。
5. `publication/build_publication.py` の再実行時にも同じ派生原稿を生成する。
6. 出版時点再確認レポートを、正本との差分が2表行だけである記述へ更新する。

### 実施しないこと

- `manuscript/日本の左派リベラルはなぜ自滅するのか.md` の変更。
- `sources/` 配下の研究台帳・証拠マトリクスの変更。
- 本文、章節タイトル、本文中の出典ID、S003〜S070の出典表行の編集。
- EPUB本体の生成、KDPへのアップロード・公開。

## 完了条件

- [ ] `publication/出版用原稿.md` と `epub/manuscript.md` がバイト単位で一致する。
- [ ] 派生原稿は正本からS001・S002の出典一覧2行だけを除いた内容と一致する。
- [ ] 派生原稿の出典一覧がS003〜S070の連番68件である。
- [ ] 本文中にはS001とS002の参照が残る。
- [ ] H1が17件（書名1＋本文16部）、H2が78件のまま維持される。
- [ ] EPUB生成HTMLの78個のH2すべてに `section-start` クラスが付く。
- [ ] `stylesheet.css` に新旧両方の改ページ指定がある。
- [ ] 正本原稿と研究台帳のハッシュ・内容を変更しない。
