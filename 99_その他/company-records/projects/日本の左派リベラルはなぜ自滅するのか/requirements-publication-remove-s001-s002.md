# 出版用派生原稿 S001・S002完全除外 要件定義書

- 確定日: 2026-08-02
- 対象書籍: 『日本の左派・リベラルは、なぜ自滅するのか』
- 対象成果物: KDP用出版原稿・EPUB用原稿

## ゴール

内部制作資料であるS001・S002を、KDPへ渡す2つの派生原稿から完全に除外する。正本原稿・研究台帳・草稿は変更せず、`publication/build_publication.py` を将来再実行してもS001・S002が派生原稿へ復活しない状態にする。

## スコープ

### 実施すること

1. 末尾の出典一覧からS001・S002の表行を除外する。
2. ASCII角括弧 `[ ]` と全角角括弧 `［ ］` の出典引用を解析し、S001・S002だけを除外する。
3. 複合引用に公開出典IDが残る場合、そのIDと引用括弧を保持する。
4. S001・S002の除外後に引用IDが空になる場合、空の引用括弧ごと削除し、前後の本文・句読点を自然につなぐ。
5. `publication/出版用原稿.md` と `epub/manuscript.md` を同じ変換結果から生成する。
6. 出版時点再確認レポートを新しい除外仕様へ更新する。

### 実施しないこと

- `manuscript/日本の左派リベラルはなぜ自滅するのか.md` の変更。
- `sources/` 配下の研究台帳・証拠マトリクスの変更。
- `drafts/` 配下の草稿の変更。
- S003〜S070、本文、章節タイトル、構成、改善案の編集。
- EPUB本体のビルド、KDPへのアップロード・公開。

## 完了条件

- [ ] `publication/build_publication.py` が引用内の出典IDを個別に解析する汎用処理を持つ。
- [ ] 複合引用ではS001・S002だけが除かれ、それ以外のIDが保持される。
- [ ] 除外後に空になる半角・全角の引用括弧が残らない。
- [ ] `publication/出版用原稿.md` と `epub/manuscript.md` がバイト単位で一致する。
- [ ] 両派生原稿に文字列 `S001` と `S002` が0件である。
- [ ] 末尾の出典一覧がS003〜S070の連番68件である。
- [ ] H1が17件、H2が78件で、節改ページ対象78件を維持できる。
- [ ] 正本原稿、`sources/`、`drafts/` を変更していない。
- [ ] 再生成を2回行っても派生原稿のSHA-256が変化しない。
