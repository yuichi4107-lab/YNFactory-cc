# 執筆実務規約

## 1. 適用範囲と優先順位

本規約は『日本の左派・リベラルは、なぜ自滅するのか』の章別初稿、統合原稿、注記、レビューに適用する。判断が衝突する場合は次の順で従う。

1. Notion正本2ページ
2. `requirements.md`
3. `BOOK_OUTLINE.md`
4. `sources/source-ledger.md`
5. `sources/section-evidence-matrix.md`
6. 本規約

書名、サブタイトル、著者名、全16部の順序、固定78節のタイトルは変更しない。見出しが強い断定形でも、本文では検証結果に応じて問い・条件付き評価・反証を示す。

## 2. 各節の必須構造

各節は次の順序を基本とし、要素の欠落を章レビューで検査する。

1. **問題提起**: 見出しが何を問うか、誤解しやすい点は何かを1〜2段落で示す。
2. **前提整理**: 比較単位、用語、対象時点、事実と印象の境界を置く。
3. **確認できる事実・具体例**: 出典IDと結び付く事実だけを書く。
4. **政党側／当事者側説明**: 党が何を理由・正当化根拠として示したかを書く。
5. **反対意見・別の合理的解釈**: 比較不能、別因果、制度上の必要等を示す。
6. **分析**: 事実と別解を踏まえ、本書がどこまで評価できるかを示す。
7. **有権者からの見え方**: 事実認定でなく印象分析として限定表現する。
8. **中心結論**: `BOOK_OUTLINE.md` の一文から逸脱せず、節内の問いへ答える。
9. **節末改善案**: 批判内容に直接対応し、主体・行動・公開物・確認方法が分かる提案で終える。

## 3. 事実・評価・推測・別解のラベル運用

本文では括弧付きラベルを乱用せず、文頭表現と段落分けで種類が判別できるようにする。レビュー用原稿では必要に応じて次のコメントラベルを付けてよい。

| 種類 | 定義 | 推奨表現 | 禁止される混同 |
|---|---|---|---|
| 事実 `[FACT]` | 一次資料または明示した補助資料で確認できる日時、発言、決定、数値、制度 | 「資料は〜と記す」「党は〜を決定した」「調査では〜だった」 | 党の自己評価を中立的な因果事実として書く |
| 当事者説明 `[PARTY]` | 政党・本人が示した理由、反論、自己評価、政策効果 | 「党は〜と説明した」「本人側は〜と反論する」 | 「説明した」を「証明した」に言い換える |
| 本書の評価 `[ASSESSMENT]` | 事実・説明・別解を踏まえた規範的判断 | 「本書は〜と評価する」「少なくとも〜は不十分である」 | 評価を無出典の事実として置く |
| 推測・仮説 `[HYPOTHESIS]` | 因果、心理、印象形成等、未確定の説明候補 | 「可能性がある」「仮説として検証する」「資料だけでは確定できない」 | 「恐れた」「見下した」「隠した」等の内心断定 |
| 別解 `[ALTERNATIVE]` | 同じ事実を説明できる別の合理的解釈 | 「他方で」「別の説明も成り立つ」「〜とは限らない」 | 反証を形式的に一文置くだけで分析から無視する |
| 印象 `[PERCEPTION]` | 有権者・読者からどう受け取られ得るか | 「〜と映り得る」「〜との印象を生み得る」 | 「見える」を確認事実や国民全体の心理にする |
| 未確認 `[UNVERIFIED]` | 取得不能、更新待ち、司法未確定、定量比較未実施 | 「本調査では確認できない」「執筆時点で再確認する」 | 空白を常識・推測で補う |

### 段落例

> 党は2026年度方針で、意思決定と説明の不足を認めた［S008］。これは党自身の自己評価であり、選挙敗因を独立に確定するものではない。短期解散や競合党などの別解も残る。それでも、党が制御可能な問題を公式記録へ残した点は、自己点検の具体例と評価できる。

## 4. 出典表記

- 本文の事実主張には原則として文末に全角角括弧で統合IDを付ける。例: `［S008］`、複数は `［S008, S011］`。
- 同じ段落に複数の事実がある場合、どの出典がどの事実を支えるか分かる位置にIDを置く。
- 章末または統合原稿末に、IDから `source-ledger.md` の書誌へ戻れる出典一覧を置く。
- 元A/B番号は本文・注記へ持ち込まない。工程2以後はS001〜S070だけを使う。
- 二次資料は一次資料の代替として黙って使わず、「研究」「報道」「書誌」等の種別を本文で示す。
- 一次資料と報道・当事者説明が食い違う場合、双方の内容、相違点、確定不能部分を同じ箇所に書く。
- S022は第9章第3節に割り当て、政府案批判と共同修正案提出が両立した反証として使う。

## 5. 引用規則

- 原文引用は論証に必要な最小限とし、原則は要約する。
- 引用符内は原文を改変しない。省略は意味を変えず、必要なら「中略」を明示する。
- 発言の強い一語だけを切り出さず、前後の質問、訂正、党対応を確認する。
- 会見動画しかない場合は時刻を記録する。逐語録でない会見リポートを発言全文として引用しない。
- 政党公式文書からの要約は「党がそう説明した」ことの証拠で、政策効果や因果の独立証明ではない。
- 引用文と著者の評価を同じ引用符・同じ文に混在させない。

## 6. 時点・固有名詞・数値

- 政党名、役職、会派、選挙結果、法案審議は事例年月を併記する。現在形へ直す前に執筆基準日で再確認する。
- 2026年再編前後の立憲民主党、中道改革連合、会派を混同しない。
- 選挙数値は総務省等の公的結果を優先し、党声明の数値は照合する。
- 世論調査は調査時期、質問対象、方法、有効回収数を可能な範囲で併記する。
- 割合は母数と選択肢を示す。「国民の9割」等へ一般化しない。
- 「最新」「現在」は基準日を併記できる場合だけ使う。
- 相対日付は使わず、年月日へ変換する。

## 7. 事例比較の規則

ダブルスタンダード、処分差、説明責任を比較するときは、最低限次の項目をそろえる。

| 比較項目 | 確認内容 |
|---|---|
| 行為類型 | 発言、政治資金、公選法、ハラスメント、党規違反等を混同しない |
| 法的段階 | 疑惑、党調査、捜査、起訴、判決、確定を分ける |
| 役職 | 閣僚、党幹部、一般議員、党員等の権限差を示す |
| 組織関与 | 単独、監督可能、複数人、長期反復を分ける |
| 故意・過失 | 資料上確認できる場合のみ書く |
| 措置 | 注意、役職辞任、資格停止、除名等と自主辞任を分ける |
| 判断理由 | 党が示した加重・軽減事情、適正手続を併記する |
| 後続結果 | 追加説明、再審、司法判断、再発防止を追う |

完全同型でない事例は「同じ」「同様」と断定せず、「比較可能な点」「比較できない点」を先に書く。

## 8. 政党側説明・反対意見の扱い

- 具体的事例には必ず政党側または当事者側の説明を置く。
- 反論を確認できなかった場合は、確認範囲と「確認できなかった」ことを書く。
- 反対意見は最も弱い反論でなく、資料と整合する最も強い合理的別解を置く。
- 別解を示した後、本書がなお評価できる範囲を限定して述べる。
- 党側説明の要約は党の用語を尊重しつつ、長い宣伝文を転載しない。
- 保守側にも同型問題が起こり得ることを章ごとに必要な範囲で示すが、別の保守批判書へ逸脱しない。

## 9. 「有権者からの見え方」の規則

- 世論調査がない場合、「有権者は〜と思う」と断定しない。
- 推奨形は「理由が示されなければ、身内に甘いと受け取られ得る」である。
- 印象形成の主体を「国民全体」にせず、「一部の有権者」「資料に接した読者」等へ限定する。
- 印象の原因として、党発信だけでなく報道、SNS切り取り、受け手の事前態度という別解も置く。
- 誤った印象は事実で訂正し、印象が存在することを事実の代用にしない。

## 10. 禁止表現・禁止論法

次の表現は引用を批判的に検討する場合を除き使用しない。台帳に残る語も本文へ自動転記しない。

- 「工作員」「外国の手先」「反日」「売国」等、裏付けのない忠誠・外国関係の断定
- 「左派は皆」「支持者は全員」「国民は誰も」等の全称一般化
- 「怖かったから」「プライドが高いから」「隠したかったから」等の内心・動機断定
- 人格、容姿、私生活、病歴、家族を政策・組織評価へ結び付ける表現
- 一般市民、無名SNS利用者、活動家個人の投稿を党組織の本質の証拠にすること
- 「ブーメランだから終わり」「偽善者」等、比較条件を省いた嘲笑
- 選挙敗北だけから政策・理念・組織行動の単一因果を確定すること
- 政党公式説明を中立的事実へ変換すること
- 一事例から党全体、思想全体、支持者全体へ一般化すること
- 反対意見を形式的に置き、結論では無視すること

## 11. 文体

- 落ち着いた専門書風で、一般読者が一度で理解できる日本語を使う。
- 一文は原則60字程度を目安とし、主語と評価主体を明確にする。
- 専門語は初出で短く定義し、同じ概念へ複数の言い換えを乱用しない。
- 「しかし」「一方で」「少なくとも」を使い、断罪でなく論証の範囲を示す。
- 皮肉、煽り、敵味方の二分法、勝利宣言を避ける。
- 同じ事例を章間で再利用するときは、新しい分析軸を明示し、事実説明を長く重複させない。
- 読者へ結論を押し付けず、出典と判断過程を示して再検証可能にする。

## 12. 節末改善案の合格条件

各節末の改善案は次の5問へ答える。抽象的な「対話を深める」「説明を丁寧にする」だけでは不合格とする。

1. 誰が実行するか（党執行部、倫理委員会、広報、地方組織等）
2. 何を変えるか（規則、公開台帳、会見手順、調査、政策文書等）
3. 何を公開するか（基準、件数、理由、進捗、指標等）
4. いつ確認するか（案件後、90日、半年、年次等）
5. 成功を何で測るか（回答率、処理期間、再発率、理解度等）

改善案は思想変更や支持者排除でなく、意思決定、説明、異論、訂正、処分、政策実装の改善へ置く。

## 13. 章別重複の管理

- 第1章は選挙総括と内部学習、第2章は理念と行動、第3章は異論、第4章は訂正・謝罪に限定する。
- 第5章は比較可能な二重基準、第6章は弱者性と組織権力、第7章は外交・国益の印象、第8章は国家概念と象徴を扱う。
- 第9章は監視から統治準備、第10章は支持基盤と外部到達、第11章は正義と対話、第12章は制度提案へ進める。
- 終章は新事例を大量投入せず、反証と改善策を統合して再生へ着地する。
- 同一事例を再登場させる場合、「前章ではXを見た。ここではYを検証する」と役割を一文で示す。

## 14. 執筆前・章レビュー・最終レビュー

### 執筆前

- `source-ledger.md` 冒頭の追加確認リストを更新する。
- 使用IDのURL、公開日、役職、最新後続結果を確認する。
- 完全同型比較でない事例は比較表を作る。

### 章レビュー

- 固定見出しと順序が一致している。
- 全節に中心結論が一つだけある。
- 必須構造9要素と節末改善案がある。
- 全具体事実に出典IDがある。
- 政党側説明、最強の別解、未確認事項が反映されている。
- 章の目標字数8,000〜12,000字（はじめに、序章、終章、あとがきは個別配分）に収まる。

### 最終レビュー

- 78節と16部、総本文12万〜16万字を機械確認する。
- 固有名詞、日付、数値、処分、引用を台帳と照合する。
- 禁止表現、内心断定、外国関係断定、全称一般化を検索する。
- 章間重複、用語揺れ、出典切れ、未解決プレースホルダーを除く。
- 終章・あとがきが排除でなく再生、反論歓迎、訂正可能性へ着地していることを確認する。
