# Claude Code活用 営業活動計画書

## エグゼクティブサマリー

Claude Codeの強みを活かし、**4つのチャネル**で営業活動を展開する。
短期は既存プラットフォームでの実績構築、中期はSNS・note経由の集客強化、
長期は直営業による高単価案件の獲得を目指す。

## 2. チャネル別戦略

### チャネルA: ココナラ（実績構築フェーズ）

**現状の課題**: 3サービス出品済みだが受注ゼロ

**改善アクション**:

1. **タイトルを課題提起型に変更**
   - 現: 「AIチャットボット構築」
   - 改: 「AI導入！あなた専用チャットボットを構築します」

2. **説明文の構成を最適化**
   - 冒頭3行で課題を明示（「こんなお悩みありませんか？」）
   - 具体的な利用場面を5つ列挙
   - 使用技術の明示（Claude Code, ChatGPT API, Dify等）
   - FAQ形式で不安を解消

3. **価格戦略**
   - AI導入コンサルを**3,000円お試し価格**に設定
   - 実績5件たまるまでモニター価格を維持
   - 実績後に段階的に正規価格へ

4. **更新頻度**
   - 週1回はサービス説明文を微修正（検索アルゴリズム対策）

### チャネルB: クラウドワークス・ランサーズ（案件獲得フェーズ）

**戦略**: 毎日1-2件応募、提案文はカスタマイズ必須

**提案文テンプレート（カスタマイズベース）**:
```
はじめまして。AI業務自動化を専門としております○○です。

ご募集内容を拝見し、[具体的な課題への言及]について
お力になれると考え、ご提案させていただきます。

【対応内容】
・[案件に合わせた具体的な対応1]
・[案件に合わせた具体的な対応2]
・納期：ご依頼から○日以内に初版納品

【関連スキル・実績】
・Claude Code / ChatGPT API / Python / GAS
・[類似の取り組み or デモURL]

ご不明点がございましたらお気軽にご質問ください。
```

**狙うカテゴリ**:
- ChatGPT/AI活用の業務効率化
- GAS/Pythonによるデータ処理自動化
- AIチャットボット構築
- プロンプトエンジニアリング

**KPI**: 週5-10件応募 → 月2-3件受注を目標

### チャネルC: note + SNS（集客導線フェーズ）

**note記事の改善**:
- 既存3本の記事末尾にココナラへの導線を追加
- 「詳しいご相談はこちらで承っています」の自然な誘導文
- SEOキーワード: 「AI 業務効率化」「チャットボット 導入」「Claude Code 使い方」

**note新規記事（月2本ペース）**:
1. 「Claude Codeで業務時間を50%削減した実例」
2. 「中小企業がAIを始める前に知っておくべき5つのこと」
3. 「ノーコードでAIチャットボットを作る方法」
4. 「Excel業務をAIで自動化するステップガイド」

**X（Twitter）新規アカウント開設**:
- アカウント名: 「○○｜AI業務自動化の専門家」
- 投稿: 1日1-3回、AI活用Tipsを中心に
- 画像/動画付き投稿でアルゴリズム優遇を狙う
- URLはリプライに貼る（本文はアルゴリズム減点対象）
- **3-6ヶ月の継続が必要**（長期投資と捉える）

### チャネルD: 直営業（高単価獲得フェーズ）

**ターゲット**: AI未導入の中小企業（飲食・不動産・士業など業界特化）

**アプローチ方法**:
1. 企業HPの問い合わせフォームから営業メール送信
2. 地域の商工会議所・ビジネス交流会への参加
3. LinkedIn等のビジネスSNS活用

**営業メールテンプレート**:
```

【ご提案内容】
・AIチャットボットによる問い合わせ自動応答
・業務データの自動集計・レポート生成
・社内FAQ AIの構築

まずは30分の無料相談で、具体的にご説明できればと思います。
ご興味がございましたらお気軽にご返信ください。
```

**KPI**: 月10社にアプローチ → 1-2社アポ → 月1件受注を目標

## 4. Claude Codeを営業活動自体に活用する方法

Claude Codeは営業の「道具」であると同時に、営業活動そのものを効率化できる:

1. **提案書の高速作成** — 案件ごとにカスタマイズした提案書をClaude Codeで生成
2. **デモ・サンプルの即時作成** — 提案時に「こんなものが作れます」とその場でデモ
3. **ポートフォリオサイトの構築** — Claude CodeでLP/ポートフォリオを高速構築
4. **note記事の効率的な執筆** — Claude Codeでリサーチ→執筆→校正を一気通貫
5. **営業メールの一括生成** — ターゲットリストからカスタマイズメールを自動生成
