## 1-3. 本命 vs 相手の切り分け診断（三連複・最重要）

各賭けレースで「軸＝全買い目に含まれる本命」を特定し、実着順とファネルで突き合わせ（取消・除外馬は3着内判定から除外、3着同着等の非標準レースは除外）:

| 段階 | morning（147R） | live（129R） |
|---|---|---|
| 平均相手頭数 / 買い目 | 5.7頭 / 8.1点 | 5.7頭 / 8.0点 |
| **① 本命（軸）が3着内** | **74.1%** | **75.2%** |
| **② 軸が来た中で相手2頭も揃った** | **67.0%** | **70.1%** |
| ③ 揃った中で実際にその買い目を買えていた | 78.1% | 76.5% |
| ＝最終的中率（①×②×③） | 38.8% | 40.3% |

**取りこぼした相手（軸は来たが相手に居なかった3着内馬・計68頭）の人気分布:**

| 人気 | 割合 |
|---|---|
| 1〜3番人気 | 0.0% |
| 4〜6番人気 | 11.8% |
| 7〜9番人気 | 44.1% |
| 10番人気以下 | 44.1% |

**結論：ボトルネックは「相手の中穴カバー」と「買い目の間引き」。軸（本命）は優秀。**

- **① 軸は強い**：74〜75%が3着以内。問題なし＝システムの強み。触らない。
- **② ボトルネック1＝相手が中穴〜大穴を取りこぼす**：軸が来ても相手が揃うのは67〜70%。取りこぼした相手の**88%が7番人気以下**で、**人気馬の取りこぼしはゼロ**。相手リストが人気サイドに寄りすぎ、3着に突っ込む中穴を拾えていない。
- **③ ボトルネック2＝買い目の間引き**：相手に正解がいても8点に絞るため、22〜24%の的中組合せを買えていない（各16R）。
- morning ≈ live に収束（朝が極端に弱いわけではない）。
- 馬連は的中率42〜57%と悪くないが、低配当で回収率割れ＝**妙味不足（別問題）**。

→ 改善は「軸」ではなく **①相手を中穴方向（7〜12番人気の好走候補）に厚くする ②買い目間引きを緩める** に投下すべき。取りこぼしが高配当の中穴なので、**的中率だけでなく回収率の改善に直結**する。

## 1-4. 朝予想 vs ライブ予想の違い（実払戻決済）

| 指標 | 🌅 朝予想 morning | ⏱ ライブ live |
|---|---|---|

| 三連複 本命の人気 | 1.56番人気（やや冒険） | 1.09番人気（ほぼ1番人気・手堅い） |

| X投稿 | 多ページ→403で42%成功 | 単発→96%成功 |

**違いの要点:**
1. **ライブはほぼ1番人気を本命にする（手堅い）**。朝は1.5番人気とやや冒険的。
2. **的中率はライブがやや上**（特に馬連 63% vs 49%）＝当てに行く設計。

5. **黒字化の主役は朝**：≥0.86で朝+69,510円/ROI136%、ライブ+1,110円とほぼトントン。

→ **朝＝妙味を取る本体／ライブ＝直前で手堅く当てに行く補完**。閾値0.86化は両方に効くが利益エンジンは朝。ライブは資金配分を均等寄りに見直すと改善。

## 3. 運用安定性

| 項目 | 状態 | 備考 |
|---|---|---|
| cron稼働 | ◎ | 土日 morning 7:00 / live 9:30 / results 17:30 / morning_retry 9:00 / monthly 1日 |
| Telegram配信 | ◎ | 安定。予想・結果速報とも届いている |
| X投稿（ライブ・単発） | ○ | 成功851 / 403=37 ≈ **96%** |
| **X投稿（朝・多ページ）** | **△** | 成功26 / 403=36 ≈ **42%** ＝スパムフィルタ403 |
| 防御スキップ | ◎（正常） | 04-05・04-12・05-03はオッズ0で見送り＝想定どおりの挙動 |
| データ整合性 | △ | `daily_summary` と `prediction_results` の収支が乖離（下記） |

- **朝X投稿の403**: 既知のXスパム判定（同型チャンクの連投）。Telegramは正常なので致命的ではないが、X集客を狙うなら要対策（チャンク数削減／投稿間隔延長／各チャンクに差分付与）。
- **データ二重帳簿（要是正）**: 同じ本予想で
  - `prediction_results`基準 = -17,560円（ROI98.4%・249点）
  - `daily_summary`基準（¥5,000/レース・配信全レース）= **-156,670円（ROI約89.5%・340レース）**

  乖離は 2026-03-22 以降に発生。`daily_summary`は配信した全推奨（低信頼の0.80–0.85帯含む）を均等買い、`prediction_results`は確定サブセット、という二系統の集計が併存している。**回収率評価がブレるため、計測ロジックの一本化が必要。** なお両者の差（低信頼レースの負け）は §2の閾値引き上げで縮小する。

## 4. 収益・コスト

- 本システムは**予想配信サービス**であり、上記の損益は**モデル評価用の仮想（紙上）収支**。実ベットしていなければ実損ではない。
- 実コスト: ConoHa VPS（JRA＋ばんえい＋他システムで共有）＋ Gemini API（X投稿の文章リライト）＋ X API（無料枠）。月**数百〜千円規模**で軽微。
- 判断材料: 「実際に賭けるか／配信コンテンツとして運用するか」で意思決定が変わる。
  - **配信運用なら**: 的中率・ROIは「コンテンツの質」。≥0.85集中で「当たる予想」を打ち出せる。
  - **実ベット運用なら**: ≥0.85・三連複集中で期待値プラス圏。穴ワイドは縮小/停止が合理的。
