# 追加フィルター条件候補

## サマリー
寄り前気配の売買比率＋板厚みだけでは偽陽性が多いため、6〜8種類の追加フィルターで絞り込みが必須。GAP率（前日比+3〜+8%）、前日出来高（100万株以上）、気配前日比変化、材料フラグ（適時開示）、時価総額（100〜1,000億円）、直近ボラ、空売り残高の7フィルターを組合わせる戦略を提案。無料データ（kabu API + 株探スクレイプ + J-Quants）で大半取得可能。

## 調査結果

### フィルター候補7種と取得手段

#### 1. 前日終値ギャップ率（GAP率）
- **定義**: `(寄付前の買気配値 - 前日終値) / 前日終値 × 100`
- **推奨レンジ**: +3〜+8%（+3%未満は動意薄、+10%超は寄り天リスク過大）
- **根拠**: Gap and Go戦略の基本条件（米国は+4%以上）、日本株では+3%が実質的な最低ライン
- **取得**: kabu API `/board/{symbol}@1` の `CalcPrice` と `PreviousClose` から算出
- **難易度**: ★☆☆ 簡単
- **要検証**: 日本株の最適GAP閾値は統計的に未確定、自前バックテストで最適化すべき

#### 2. 前日出来高（流動性フィルター）
- **定義**: 前日の売買代金 or 出来高
- **推奨レンジ**:
  - 出来高: **100万株以上**（デイトレで最低限の流動性）
  - 売買代金: **10億円以上**（小型株でも十分な回転）
- **根拠**: 松井証券デイトレ適性ランキングも売買代金ベース、板が薄すぎるとスリッページ過大
- **取得**: kabu API `/board` の `TradingVolume` は当日分のみ → 前日分はJ-Quants `/prices/daily_quotes` または 株探スクレイプ
- **難易度**: ★★☆ 中（前日データは別ソース必要）

#### 3. 前日比気配変化（気配強度）
- **定義**: 寄り前気配が前日終値より高いか、段階的に切り上がっているか
- **具体ルール例**:
  - 8:59時点の買気配 > 前日終値 +5%
  - 8:00→8:59の気配値変化率が＋傾斜
- **根拠**: 寄り前に買い気配が継続上昇 = 強い買意向、一方で途中で失速するとダマシの可能性大
- **取得**: kabu API PUSH経由で8:00〜8:59の気配履歴を自前保存→特徴量化
- **難易度**: ★★★ 高（自前での時系列データ蓄積必須）

#### 4. 材料フラグ（カタリスト）
- **定義**: 当日朝〜前日夜に適時開示（IR）があった銘柄
- **重要カテゴリ**:
  - **業績予想修正**: 売上±10%超 or 利益±30%超で開示義務（最も株価直結）
  - 決算発表（予実乖離が大きい）
  - 自社株買い（特に発行株数の5%以上）
  - 業務提携、M&A、大型受注
  - バイオの治験進捗、新薬承認
  - 指数採用（JPX日経400、TOPIX500、日経225等）
  - PO（公募増資）/株式分割
- **取得**:
  - **TDnet（JPX適時開示情報伝達システム）**: 公式、当日分HTMLスクレイピング可
  - **株探 適時開示**: https://kabutan.jp/disclosures/ （リアルタイム配信、種類別に整理）
  - **株予報Pro**: 企業別のIRカテゴリ分け
- **難易度**: ★★☆ 中（スクレイプとカテゴリ分類が必要）
- **要検証**: どのカテゴリの材料が+5〜10%デイトレと相性が良いかは自前バックテストで判定

#### 5. 時価総額レンジ（小型株フィルター）
- **定義**: 時価総額
- **推奨レンジ**: **100〜1,000億円**
  - 100億円未満: 流動性不足、仕手化リスク
  - 1,000億円超: 値動き%が小さくなりデイトレ向きでない
- **根拠**: 東証グロースの中核 + 東証プライムの中小型に該当、値動きと流動性のバランス良
- **取得**: kabu API `/board` の `TotalMarketValue`、または J-Quants `/listed/info`
- **難易度**: ★☆☆ 簡単

#### 6. 直近ボラティリティ（日中値幅率）
- **定義**: 直近5〜20営業日の平均日中値幅率 `(High - Low) / Close`
- **推奨レンジ**: **5%以上**（+5〜10%利確が現実的な値動きを持つ銘柄のみ）
- **根拠**: デイトレ利確目標と整合性のある母集団に絞る
- **取得**: J-Quants日足データ or yfinance、ローカルで20日移動平均
- **難易度**: ★★☆ 中

#### 7. 空売り残高比率
- **定義**: 発行済株式数に対する空売り残高の比率（%）
- **解釈**:
  - **高比率（5%超）**: 踏み上げ相場候補（上昇時に空売り買戻しで加速）、ただし下落時の売り圧も
  - **低比率（1%未満）**: 株価上昇にブレーキがかからない構造
- **取得**:
  - 日証金（日本証券金融）の貸借残高データ
  - JPX公表の空売り残高情報（個別残高報告は0.5%超で週次開示）
  - 一部情報は無料（JPX公式）、詳細データは有料ベンダー
- **難易度**: ★★★ 高（無料データは遅延・限定的）
- **優先度**: 低〜中（+5〜10%戦略ではなくても機能する）

#### 8. PTS夜間取引の上昇率（オプション）
- **定義**: 前日夜のPTS取引（SBI・SBIジャパンネクスト等）での終値と東証前日終値の乖離
- **推奨レンジ**: PTS+3%以上
- **取得**: ジャパンネクスト証券PTS、SBI PTS（スクレイピング or 有料API）
- **難易度**: ★★☆ 中

### 実績ある組合せ事例

**事例A: ギャップアップ＋材料銘柄戦略**（mane-labo等の手法）
- 条件: GAP率+5%以上 AND 当日朝に適時開示あり AND 出来高100万株以上
- 注意: 「寄り天」回避のため、寄付き直後5分のローソク実体で判断、陰線なら見送り

**事例B: 小型株ボラティリティ戦略**（IT-daytrading）
- 条件: 時価総額100〜1,000億円 AND 日中値幅率直近5日平均5%以上 AND 出来高5万株以上
- 場中リアルタイムでの抽出をベースに、寄付き戦略にも応用可

**事例C: 適時開示ドリブン**（株探・株予報Pro利用者）
- 条件: 業績予想上方修正 + 前日引け後〜当日寄付き前の開示 + 小型株（時価総額1,000億円以下）
- 寄り付き前の売買代金ランキング上位に来やすい

### kabu APIだけで取れるか？

| フィルター | kabu API単体 | 要追加データソース |
|---|---|---|
| 1. GAP率 | ○ | — |
| 2. 前日出来高 | △（当日のみ） | J-Quants or 株探 |
| 3. 気配変化 | ○（要自前保存） | — |
| 4. 材料フラグ | × | TDnet or 株探スクレイプ |
| 5. 時価総額 | ○ | — |
| 6. 直近ボラ | ×（日足データなし） | J-Quants |
| 7. 空売り残高 | × | JPX or 日証金 |

**結論**: kabu API単体では4つ取得可、残り3つは無料の外部データ（J-Quants・TDnet・JPX）で補完可能。**全フィルター無料で構築可能**。

### 推奨フィルター組合せ（第一版）

**JP-DAYTRADE-v1 初期スクリーニング条件**:
```
AND条件:
  1. 株価 ≤ 3,000円 かつ 単元代金 ≤ 30万円
  2. 時価総額 100〜1,000億円
  3. 直近5日日中値幅率 ≥ 5%
  4. 前日出来高 ≥ 100万株
  5. GAP率（8:59時点の買気配 / 前日終値 - 1）≥ +3%
  6. 寄り前売買比率: 売気配累積 / 買気配累積 ≤ 0.8（買い優勢）
  7. 板厚み（上下10本累積）≥ 10,000株（流動性確保）

追加加点（any）:
  + 当日/前日夜の適時開示（業績予想修正 or 上方サプライズ）: +1点
  + PTS +3%以上: +1点
  + 空売り残高比率 ≥ 5%: +1点
```

## 結論
- 寄り前気配比率＋板厚みは必要条件だが十分条件ではない。**7フィルターの組合せ** が必要。
- 最重要フィルターは **GAP率・前日出来高・時価総額・日中値幅率・材料フラグ** の5つ。
- 材料フラグ（適時開示）は非構造データなので、TDnet/株探のスクレイプ＋カテゴリ分類を事前に構築。
- 空売り残高は無料データでは粒度不足、第二段階で検討。
- 全フィルターが **無料データで実装可能** （kabu API + J-Quants + TDnet/株探スクレイプ）。
- まずは7フィルター組合せで **「候補銘柄が朝8:59時点で1〜10個に絞れる」** を目標にスクリーニングを設計。
